## 一句话概括

**你从一簇篝火旁的采集者起步，亲手把人类文明从蒙昧推向星海。**

不是"升级数值"，而是"重走文明史"——每个时代引入一套**全新的动词**，让跃迁真正换一种玩法。

## 时代划分（2026-09-12 按方案 B 重排）

划分方法：**从通用技术史反推**——先列真实文明的通用目的技术（GPT），
再按每项的"新动词 + 新瓶颈"折叠成时代。三条规则：
① 核心科技必须是**通用目的技术**（制度型技术如「法典」不计入，但仍为该代骨架）；
② **门槛科技 = 下一代核心科技**；③ 每代头部标注「材料 / 能源 / 信息刻度」。

## 四层循环

| 层级 | 内容 | 玩家决策 |
|---|---|---|
| 微观 | 分配人手 | 人往哪放 |
| 中观 | 建造 / 研究 | 先发展什么 |
| 宏观 | 时代跃迁 | 何时跃迁 |
| 元循环 | 重启 | 怎么重来 |

## 三层重置

| 层级 | 名称 | 解锁 | 收益 |
|---|---|---|---|
| P1 | 文明重启 | 首次跃迁到 E4 后 | 遗产点（+3% 全局产出/点） |
| P2 | 平行文明 | 通关一次后 | 选择起源（河谷/草原/海洋），不同路线 |
| P3 | 星际播种 | 通关星海时代后 | 多星球并行、真结局 |

## 核心设计铁律

1. 每个时代必须引入**新动词**，不能只是数值放大
2. 跃迁必须是玩家**主动决策**，不能自动触发
3. 旧内容**降权而非作废**，避免跃迁变成惩罚
4. **四层循环同时活跃**，挂机回来必须有事可做
5. **离线收益有上限**（8 小时），防止失控
6. 所有数字**可解释**，悬停能看到"为什么是这个数"
