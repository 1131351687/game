# 第一部分 · 核心设计原则

## 1.1 一时代，一核心科技

**每个时代有且仅有一项核心科技。** 它是该时代一切发展的依托：

| 核心科技的作用 | 说明 |
|---|---|
| **定义发展方式** | 玩家在这个时代"优化什么"由它决定 |
| **统摄其他内容** | 该时代的岗位、建筑、次级科技都围绕它展开、为它服务 |
| **构成主要矛盾** | 该时代玩家要解决的核心问题由它产生 |
| **作为跃迁钥匙** | 通常与门槛科技同源或直接相关 |

**为什么这样设计**：放置游戏的通用问题——后期内容会退化成"同样的东西数字更大"。用"一时代一核心科技"强制每个时代换一套**优化对象**，玩家在 E1 琢磨"怎么维持火种"、在 E6 琢磨"怎么把煤变成电"，虽然底层框架相同，但**决策内容彻底不同**。

## 1.2 核心科技决定发展方式的差异

七个时代的发展方式递进关系：

| 时代 | 核心科技 | 发展方式 | 玩家优化什么 |
|---|---|---|---|
| E1 | **火** | 维持型 | 怎么让火不灭 |
| E2 | **农业** | 周期储备型 | 怎么攒够过冬的粮 |
| E3 | **文字** | 记录交换型 | 怎么让知识与物资流动起来 |
| E4 | **法典** | 规模治理型 | 怎么在扩张与维稳间平衡 |
| E5 | **印刷术** | 知识复利型 | 怎么让研究滚雪球 |
| E6 | **蒸汽机** | 能量转换型 | 怎么把煤转成生产力 |
| E7 | **计算机** | 信息自动化型 | 怎么把自己从微观操作中解放出来 |

**七个时代，七种完全不同的优化目标。** 这是本作区别于普通放置游戏的核心。

## 1.3 减弱机制：不废弃，只降权

> **设计约束（已定）**：进入新时代时，旧核心科技**不能被完全放弃，只能减弱**。

### 1.3.1 旧核心科技的三个阶段

| 阶段 | 时期 | 作用 |
|---|---|---|
| **主引擎期** | 所属时代 | 它是增长的主要来源，加成 ×1.0 |
| **地基期** | 后续时代 | **仍然生效并持续提供加成**，但效果随时代距离衰减 |
| **前置期** | 永远 | 作为后续科技的解锁前置，保持"必需"地位，不可跳过 |

### 1.3.2 衰减规则（【待定】具体数值）

```
时代距离 d = 当前时代序号 − 核心科技所属时代序号
加成系数 = max(下限, 衰减率 ^ d)
```

参考取值：

| 距离 d | 系数（衰减率 0.6） | 说明 |
|---|---|---|
| 0（当代） | ×1.00 | 主引擎 |
| 1 | ×0.60 | 刚换代，仍是重要助力 |
| 2 | ×0.36 | 转为基础支撑 |
| 3 | ×0.22 | 背景加成 |
| ≥4 | **×0.20** | **触底，永不归零** |

**下限 20% 是硬性保证**：即使打到 E7，E1 的火种仍在提供 20% 加成。这就是"不能完全放弃"的机制化表达。

### 1.3.3 关键：旧核心提供"质"的加成，不只是"量"

单纯数值衰减会让旧核心变成"聊胜于无的零头"，玩家情感上仍是放弃。因此旧核心科技还应提供**不可替代的功能性作用**：

| 旧核心 | 衰减后的"质"作用 |
|---|---|
| 火 | 提供人口舒适度底线（无火则人口增速受限） |
| 农业 | 提供粮食安全底线（不依赖外来供给） |
| 文字 | 提供研究的基础斜率（无文字则研究效率大减） |
| 法典 | 提供维稳成本的固定化（无法律则扩张惩罚加剧） |
| 印刷术 | 提供知识的跨时代保留率 |
| 蒸汽机 | 提供能源的冗余备份（电网故障时仍可运转） |

**设计意图**：即使加成降到 20%，玩家仍然"需要"它，而不是"懒得关掉"它。

## 1.4 科技树形态

> **定位修正**：本作是"**点科技树**"的游戏 —— **科技树是主菜**，资源/岗位/建筑都是服务于解锁科技的机器。
> 因此科技树不是配角，它需要独立的结构设计与可视化设计。

### 每代结构：1 主干 + 3 分支 + 汇聚

```
                     ┌─────────────────┐
                     │   门槛科技       │ ← 通往下一时代
                     └────────▲────────┘
                              │
      ┌───────────────────────┼───────────────────────┐
      │                       │                       │
 【分支 A】              【分支 B】              【分支 C】
  （6 项）                （6 项）                （6 项）
      │                       │                       │
      └───────────────────────┼───────────────────────┘
                              │
                     ┌────────▼────────┐
                     │   核心科技       │ ← 起点，必经
                     └─────────────────┘
```

| 层级 | 每代数量 | 作用 | 是否必经 |
|---|---|---|---|
| **核心科技** | 1 项 | 定义发展方式、开启新机制 | ✅ 必经 |
| **分支科技** | 3 × 5–8 项 | 每条分支代表一种发展路线 | 走通 1–2 条 |
| **门槛科技** | 1 项 | 通往下一时代 | ✅ 必经 |

**三分支必须汇聚到门槛科技** —— 玩家至少走通一条分支才能跃迁，但**经验不够走通全部三条**，形成路线选择。

### 科技内容配比（硬性规范）

| 类型 | 占比上限 | 玩家感受 |
|---|---|---|
| **解锁型**（开新东西） | ≥ 40% | "多出个新东西" |
| **质变型**（改规则） | ≥ 25% | "规则变了" |
| **数值型**（纯加成） | **≤ 25%** | "数字大了" |

> 玩家点科技时的期待是"开出新东西"，不是"数字又大了"。纯数值科技超过 25% 就是在灌水。

### 科技规模

| 时代 | E1 | E2 | E3 | E4 | E5 | E6 | E7 | 合计 |
|---|---|---|---|---|---|---|---|---|
| 科技数 | 20 | 30 | 45 | 60 | 75 | 90 | 100 | **约 420** |

平均 **4 分钟点亮 1 个节点** —— 挂机回来一次能看到好几个新东西，这是长线留存的关键。

**【待定】**：分支之间是否允许"互斥选择"（点了 A 就不能点 B）？
> 倾向**允许少量互斥节点**，可大幅提升重玩价值。

## E1 · 蒙昧时代（旧石器）

### 🔥 核心科技：火

> 掌握火，是人类第一次支配自然力。

| 维度 | 内容 |
|---|---|
| **发展方式** | **维持型**——你的首要任务不是"增长"，而是"别让火灭了" |
| **核心矛盾** | 火要木材、人口要人力、武器要石头 —— **三者争夺同一份人力** |

### 1. 火种系统（核心机制）

**火种值**：0–100 的动态数值，投入木材上升，随时间自然衰减。

| 火种阶段 | 区间 | 状态 |
|---|---|---|
| 熄灭 | 0 | 全部加成失效，人口开始下降 |
| 微弱 | 1–33 | 部分加成 |
| 稳定 | 34–66 | 完整基础加成 |
| 旺盛 | 67–100 | 触发额外效果（如夜间活动时间延长） |

**火提供三层作用**：

| 作用 | 效果 | 机制 |
|---|---|---|
| **熟食** | 食物能量转化率↑ | 影响食物产出的**有效值** |
| **取暖** | 生存环境改善 | 提升**火源因子** → 人口增长率↑（见第 2 节） |
| **驱兽** | 损失事件↓ | 降低野兽袭击的损失 |

**衍生科技**：取火术、火塘、燧石、烤肉、火把、火硬化木矛

### 2. 人口模型（群体尺度）

> **设计原则**：本作是**文明游戏**，人口按**群体**建模 —— **不模拟个体**的生育、死亡、寿命、哺乳期。

**人口增长采用逻辑斯蒂模型**（Logistic Growth）：

```
人口增长速率 = r × P × (1 − P / K) × 食物因子

P = 当前人口
K = 人口上限（由房屋决定）
r = 基础增长率 × 火源因子
```

**三个限制来源**：

| 限制 | 模型中体现 | 玩家如何突破 |
|---|---|---|
| **房屋** | `K` —— 人口硬上限 | 建造更多住所 |
| **火源（环境）** | `r` 中的火源因子 | 把火种维持在更高档位 |
| **人口自身** | `P × (1 − P/K)` 项 | 人多增长越快，接近上限时自然放缓 |
| **食物** | 食物因子 | 保证食物产出 > 消耗 |

**为什么用逻辑斯蒂**：它天然同时表达"人口越多增长越快"和"接近上限时增长停滞"——**一个公式就把人口自身的限制作用表达完了**，不需要额外编造规则。

**火源因子**（火作为环境如何影响增长）：

| 火种档位 | 火源因子 |
|---|---|
| 熄灭 | 0（且人口转为下降） |
| 微弱 | 0.5 |
| 稳定 | 1.0 |
| 旺盛 | 1.25 |

**食物因子**：

| 食物状况 | 因子 |
|---|---|
| 充裕（产出 > 消耗 × 2） | 1.0 |
| 正常 | 0.8 |
| 紧张（产出 < 消耗） | 0（停止增长） |
| 饥荒（储备耗尽） | 负值（人口下降） |

**人口的作用**：

- 人口 = **人力上限**，是全部岗位的燃料（**群体尺度的劳动力**）
- 人口 = **经验来源**（人多 → 学得快 → 科技解锁快）

> ⚠️ **已废弃的旧设计**：早先版本曾用"火 → 缩短生育间隔 → 人口跃升"建模（含哺乳期、婴儿死亡率等参数）。
> 该方向过于个体化，不符合本作"从群体出发"的定位，已改为上述环境因子模型。

### 3. 承载力与选址

> **设计依据**：狩猎采集者人口密度 0.01–1 人/km²，但沿海/富集区可达 1–10 人/km² —— **相差 100 倍**。

**机制**：开局选址决定 **K 的基础值**（可容纳人口）与**资源偏向**。

| 选址 | 基础上限 | 特点 |
|---|---|---|
| 内陆草原 | 低 | 猎物多，狩猎路线 |
| 河谷 | 中 | 采集稳定，人口路线 |
| 沿海 | 高 | 上限最高，但依赖水产 |

**同时是后续 P2「平行文明」起源系统（河谷/草原/海洋）的雏形**。

### 4. 工具世代（群体尺度）

> **设计原则**：工具**不做个体层面的追踪** —— 不模拟"每个猎人配几把矛、矛会不会磨损"。
> 它是**文明级的技术世代**，代表整个群体掌握的工具水平。

**工具世代阶梯**（据考古实证）：

| 世代 | 工具 | 年代锚点 | 群体效果 |
|---|---|---|---|
| 0 | 无 | — | 猎人岗位不可用 |
| 1 | 削尖木矛 | Schöningen 矛（德国），约 **40 万年前**，重心靠前＝可投掷 | 解锁猎人岗位 |
| 2 | 装柄石矛 | 燧石尖＋赭石树脂黏合剂（6–3.5 万年前） | 狩猎效率 **+40%** |
| 3 | 投矛器 atlatl | 约 **2.1–1.7 万年前**（法国洞穴） | 狩猎效率 **+40%** |
| 4 | 弓箭 | ⚠️ 起源**高度争议**（8 万–1.7 万年前） | 狩猎效率 **+60%** |

**机制**：每个世代是一项**科技**。解锁后**永久提升全群体的狩猎效率** —— 无损耗、无个体追踪、无资源消耗。

**集体围猎**：猎人数达到阈值时触发**群体加成**（人越多，单位效率越高），对应 Schöningen 湖畔把马群逼向湖岸的实证。这是"文明尺度"对"个体狩猎"的替代。

### 5. 火 — 人口 — 食物 的咬合

```
        🔥 火（核心 · 环境因子）
        │ 熟食 → 食物加工效率 ↑
        │ 火源因子 → 人口增长率 r ↑
        │ 驱兽 → 损失 ↓
        ▼
   👥 人口（引擎 · 群体增长）
        │ 人口 = 人力上限
        │ 人口 = 经验来源
        ▼
   🍖 食物 / 🪨 工具（产出）
             食物 → 支撑人口上限与增长率
             工具世代 → 狩猎效率
```

**闭环**：火旺 → 人口增长率高 → 人力充沛 → 产出更多食物与经验 → 可建更多住所（提高 K）→ 人口继续增长
**反之**：火弱 → 增长率下降 → 人力不足 → 食物短缺 → 人口停滞甚至下降

### 6. 资源集

| 资源 | 图标 | 来源 | 用途 |
|---|---|---|---|
| **食物** | 🍖 | 采集者、猎人 | 支撑人口（上限 K 与增长率） |
| **木材** | 🪵 | 伐木者 | **维持火种**、建筑 |
| **石头** | 🪨 | 打石者 | 建筑、工具世代 |
| **经验** | 💡 | **人口自然产生** | 解锁本时代科技 |
| **人口** | 👥 | 逻辑斯蒂增长 | 人力上限 ＋ 经验来源 |

**两个特殊项**：

- **火种** —— 独立状态值（0–100），不计入资源列表，是本时代的**核心仪表盘**
- **经验** —— 本时代**没有"研究点"**（史实上还没有文字）。经验由**人口自然产生**，替代研究点

> **「经验」的意义**：人口越多 → 经验越快 → 科技解锁越快。
> **人口就是文明的进步速度。**

### 7. 岗位集

| 岗位 | 消耗 | 产出 |
|---|---|---|
| 🌾 **采集者** | 人力 | 食物（基础） |
| 🪓 **伐木者** | 人力 | 木材 |
| 🪨 **打石者** | 人力 | 石头 |
| 🦌 **猎人** | 人力 ＋ **工具世代 ≥1** | 食物（受工具世代倍率加成） |

**四个岗位，全部是群体分工**，没有个体追踪。

**核心取舍**：人力总量固定，伐木（维持火）与采集（吃饭）争夺同一份人力 —— **火灭则全盘皆输**。

### 8. 建筑集

| 建筑 | 效果 | 对应的限制 |
|---|---|---|
| 🏕️ **住所** | **人口上限 K +N** | 突破房屋限制 |
| 🔥 **火塘** | 火种衰减 −20%，上限 +20 | 强化火源 |
| ⚒️ **作坊** | 工具世代效果 +20% | 强化产出 |

**建筑只有三个方向**，分别对应人口、环境、产出 —— 简洁且与三大限制一一对应。

### 9. 科技树（本作的主角系统）

> **定位**：这是"点科技树"的游戏。**科技树是主菜**，资源/岗位/建筑都是**服务于解锁科技的机器**。

#### 9.1 科技树形态

每代是 **1 条主干 + 3 条分支 + 汇聚到门槛科技** 的结构：

```
                          ┌─────────────────┐
                          │  🌾 植物栽培     │ ← 门槛科技（→ E2）
                          └────────▲────────┘
                                   │
        ┌──────────────────────────┼──────────────────────────┐
        │                          │                          │
   【火之技艺】               【石器与工具】              【群体与定居】
        │                          │                          │
     火把                      弓箭                      烟熏储存
        │                          │                          │
   火种保存术                  投矛器                    集体围猎
        │                          │                          │
    热石煮食                  装柄技术                   赭石颜料
        │                          │                          │
    火塘营造                  燧石选材                   绳索编织
        │                          │                          │
    熟食烹饪                  削尖木矛                   群体协作
        │                          │                          │
     取火术                   石器打制                   住所营造
        │                          │                          │
        └──────────────────────────┼──────────────────────────┘
                                   │
                          ┌────────▼────────┐
                          │   🔥 掌握火      │ ← 核心科技（起点）
                          └─────────────────┘
```

**三条分支的定位**：

| 分支 | 主题 | 侧重 | 路线风格 |
|---|---|---|---|
| **火之技艺** | 火的应用 | 食物效率、火种强度 | 稳健 |
| **石器与工具** | 狩猎技术 | 猎人效率（省人力） | 效率 |
| **群体与定居** | 社会组织 | 人口上限、稳定性 | 规模 |

**三条分支最终汇聚到门槛科技** —— 玩家必须至少走通一条分支才能跃迁。

#### 9.3 科技内容配比（本作设计规范）

| 类型 | 本代占比 | 玩家感受 |
|---|---|---|
| **解锁型** | 40%（8/20） | "多出个新东西" |

| **数值型** | **20%（4/20）** | "数字大了" |
| **跃迁型** | 5%（1/20） | 推开新时代 |

> **规范**：数值型科技**不得超过 25%**。
> 玩家点科技时的期待是"开出新东西"，不是"数字又大了"。

#### 9.4 研究队列（挂机游戏的生命线）

> **挂机的本质是"你不在的时候也在进步"。没有队列，玩家必须守在电脑前——那就不是挂机游戏。**

| 功能 | 说明 | 可用时机 |
|---|---|---|
| **研究队列** | 预先排好 5 项研究，自动依次执行 | E1 起始即可用 |
| **离线研究** | 关闭浏览器后按队列继续推进 | E1 起始即可用（上限 8 小时） |
| **队列扩容** | 通过科技/建筑提升队列长度 | 各时代递增 |
| **自动选择** | AI 自动挑选下一项研究 | E7 计算机时代 |

**E1 队列规则**：

- 队列长度 **5**
- 排入队列的科技显示"预计完成时间"
- 离线时按 **50% 效率**推进（鼓励在线但有保底）
- 队列为空时弹出提示（避免玩家以为还在挂机）
- 可在队列中**拖动调整顺序**

#### 9.5 科技树是一棵"不断生长的树"

本作全流程是**一棵树在生长**，不是七张独立列表：

```
E7                                   新科技在顶端长出
E6                                 ／
E5                              ／
E4                           ／
E3                        ／
E2                     ／
E1  ●──────●──────●            ← 已点亮的旧科技成为"树干"
   掌握火   农业    文字
```

- 旧时代的科技进入新时代表现为**树的下部基础**（持续生效，但按时代系数降权）
- 玩家看到的是"**我的文明之树越长越大**"
- 这直接服务于"减弱而非废弃"原则 —— **树干不会消失，只是贡献变小**

> **[待实现]** 跨时代科技树的统一可视化，详见第 13 节 UI 要点。

### 10. 减弱后（E2 起）

- 定居后有了固定炉灶，**火种不再需要主动维护**（取消维持压力）

#### 11.3 人口（逻辑斯蒂增长）

**公式**：

```
人口增长速率 = r × P × (1 − P / K) × 食物因子

r = 基础增长率 × 火源因子      ← 环境（火）限制
K = 基础上限 + Σ住所容量        ← 房屋限制
P × (1 − P/K)                   ← 人口自身限制
```

| 项 | 值 |
|---|---|
| 基础增长率 | **0.02 / 秒** |
| K 基础上限 | 4 |
| 每座住所 | **K +4** |
| 食物消耗 | **0.2 / 秒 / 人** |
| **经验产出** | **0.12 / 秒 / 人** |

**增长率曲线示例**（K = 20，火种稳定）：

| 人口 P | 增长速率 | 阶段 |
|---|---|---|
| 2 | 0.036 /秒 | 起步慢（人口基数小） |
| 10 | 0.100 /秒 | **最快区间**（约 P ≈ K/2） |
| 18 | 0.036 /秒 | 接近上限，自然放缓 |
| 20 | 0 | 到达上限 |

> 逻辑斯蒂的 S 形曲线天然产生"**起步慢 → 中段快 → 接近上限放缓**"的节奏，不需要额外编造规则。

**火种熄灭时**：火源因子 = 0 → 增长停止；持续熄灭则人口以 0.5/秒 下降。

#### 11.4 岗位产出

> **E1 用线性产出，不用 sqrt 递减。**
> 理由：E1 规模极小（人口 2→25），每个人口增长都应手感明显；且此规模无爆炸风险。
> 递减收益建议从 **E3** 规模上千时再引入。

| 岗位 | 需求 | 产出/秒 |

| 🪓 伐木者 | 人力 | 0.4 木材 |
| 🪨 打石者 | 人力 | 0.3 石头 |
| 🦌 猎人 | 人力 ＋ 工具世代 ≥1 | 1.2 食物 × 工具世代倍率 |

#### 11.5 食物平衡验算

```
人口 20 人 → 消耗 4.0 食物/秒（0.2 / 秒 / 人）

方案 A：8 个采集者（0.5 × 8 = 4.0）    → 占用 8 人力
方案 B：4 个猎人（1.2 × 4 = 4.8）      → 占用 4 人力，余 0.8 食物/秒结余
```

**这就是 E1 的核心取舍**：猎人效率是采集者的 **2.4 倍**。

| 方案 | 人力占用 | 说明 |
|---|---|---|
| 纯采集 | 8 人 | 不需要科技，但吃掉 40% 人口 |
| 猎人 | 4 人 | **省下 4 个人力**，但要先投科技攀工具世代 |

**先攀科技（省人力）还是先堆人头（快见效）** —— 这是玩家在 E1 要反复权衡的问题。

> ⚠️ 校验记录：本节原按 `0.4/秒/人` 验算，与 11.3 节的 `0.2/秒/人` 不一致。
> 已统一为 **0.2/秒/人** —— 因为 E1 人口上限仅约 20–24，若按 0.4 则需 16 个采集者，只剩 4 人干别的，**取舍空间归零**。

| 项 | 经验 |
|---|---|

| 项 | 说明 |

### 12. 20 分钟节奏时间线

| 时段 | 玩家在做什么 | **科技解锁** | 人口 | 火种 |
|---|---|---|---|---|
| **0:00–2:00** | 采集食物攒经验 | 掌握火、石器打制 | 2 → 3 | 0 → 点燃 |
| **2:00–6:00** | 维持火种、建住所 | 住所营造、取火术、削尖木矛 | 3 → 7 | 稳定 |
| **6:00–11:00** | **路线选择关键期** | 三条分支各选 1–2 项 | 7 → 12 | 稳定 → 旺盛 |
| **11:00–16:00** | 深化所选分支 | 分支中段科技 3–4 项 | 12 → 18 | 旺盛 |
| **16:00–20:00** | 冲刺门槛科技 | 植物栽培 | 18 → 22 | 旺盛 |

**20 分钟解锁节奏**（共 20 项，平均 **1 分钟 1 项**）：

```
0min ●掌握火
2min ●石器打制
3min ●住所营造
4min ●取火术
5min ●削尖木矛 ────────┐
                        │ 路线选择点
7min ●（分支A/B/C 选一）─┘
...
17min ●植物栽培  ← 门槛
20min 跃迁
```

**体验曲线设计**：

- **前 2 分钟**：教学 —— 学会分配人力、点燃火，点出第一批科技
- **2–6 分钟**：**第一次危机** —— 火种衰减，必须派人伐木
- **6–11 分钟**：**第一次路线选择** —— 三条分支只能侧重走通一两条，玩家开始形成自己的文明风格
- **11–16 分钟**：**深化期** —— 沿选定路线推进，科技效果开始叠加显威
- **16–20 分钟**：**冲刺** —— 攒够经验点出「植物栽培」，明确目标

> **关键设计**：6–11 分钟是**路线分岔点**。玩家在这里做出的选择会决定他这一局走"食物稳健"、"狩猎效率"还是"人口规模"，且因为经验不够，**无法三条全走**。

## E2 · 定居时代（新石器 / 农业革命）

### 🌾 核心科技：农业

> 从"跟着食物走"到"让食物长在门口"。

| 维度 | 内容 |
|---|---|
| **发展方式** | **周期储备型**——夏秋生产、冬春消耗，为过冬做规划 |
| **核心矛盾** | 丰季人力该全投生产还是分去建设？冬季无法生产，全靠储备 |

**玩法围绕农业展开**：

- **季节循环**：春夏秋冬各 N 个游戏日，冬季产出大幅下降
- **粮仓**：存储上限决定你能撑过几个冬天
- **土地**：开垦更多田地需要人力与时间，但提升长期产能
- **作物选择**：不同作物产量/生长期/耐寒性不同（【待定】是否引入）
- **衍生科技**：灌溉、轮作、犁、育种、畜牧、陶器储存

**减弱后（E3 起）**：
- 农业仍是粮食来源，但**不再驱动增长**（增长引擎转移到文字与贸易）
- 保留"质"作用：提供粮食安全底线，不依赖外来供给

## E3 · 城邦时代（青铜时代）

### ✍️ 核心科技：文字

> 文字让知识可以累积——第一次，前人的发现能被后人接住。

| 维度 | 内容 |
|---|---|
| **发展方式** | **记录交换型**——知识可累积，物资可交换 |
| **核心矛盾** | 记录与计算需要人力（书吏），但这些人不直接产出物资 |

**玩法围绕文字展开**：

- **知识累积**：研究成果不再随时代丢失，可跨时代叠加
- **记录容量**：可"记住"的科技数量有上限，需扩建学宫
- **贸易路线**：与虚拟邻邦交换资源，价格浮动，需记录账目
- **契约**：与邻邦签订长期协议，违约有代价
- **衍生科技**：楔形文字、泥板、算筹、轮子、度量衡、货币雏形

**减弱后（E4 起）**：
- 文字成为**基础设施**，研究加成降权
- 保留"质"作用：作为后续所有科技的**前置钥匙**，且提供研究基础斜率

## E4 · 帝国时代（铁器 / 古典）

### ⚖️ 核心科技：法典

> 当疆域大到无法靠血缘维系，就需要成文的规则。

| 维度 | 内容 |
|---|---|
| **发展方式** | **规模治理型**——扩张带来收益，也带来成本 |
| **核心矛盾** | 版图越大产出越高，但维稳成本呈超线性上升 → **规模不经济** |

**玩法围绕法典展开**：

- **版图系统**：领土扩张提升产出，但每块新领土的维稳成本递增
- **政体**：君主 / 共和 / 神权，各自加成与代价不同（**政体系统在此首次登场**）
- **法典条款**：可立法调整各项参数（税率、兵役、贸易管制），有得有失
- **官僚**：官吏岗位消耗人力但降低维稳成本——**投入治理=换取规模**
- **衍生科技**：成文法、道路网、铸币、军团编制、驿站

**减弱后（E5 起）**：
- 法典成为**默认制度**，扩张收益递减、维稳成本固定化
- 保留"质"作用：无法律则扩张惩罚加剧

## E5 · 觉醒时代（中世纪 → 文艺复兴）

### 📖 核心科技：印刷术

> 知识第一次可以被廉价复制——复利开始了。

| 维度 | 内容 |
|---|---|
| **发展方式** | **知识复利型**——研究速度随已解锁科技数增长，滚雪球 |
| **核心矛盾** | 前期印刷投入巨大且不产出物资，回报要等很久 → **前期忍耐换后期爆发** |

**玩法围绕印刷术展开**：

- **复利机制**：`研究速度 = 基础 × (1 + 已解锁科技数 × 系数)`——科技越多，研究越快
- **印刷产能**：需要纸张（木材/破布）与印刷工，产能决定复利斜率
- **知识传播**：可将科技"输出"给邻邦换取资源（【待定】）
- **远航探索**：派船队发现新大陆，带回稀缺资源与随机事件
- **衍生科技**：活字印刷、造纸、指南针、火药、天文、解剖学

**减弱后（E6 起）**：
- 印刷成为**基础产业**，复利斜率降低但仍持续生效
- 保留"质"作用：提供知识的跨时代保留率

**【待定】**资源集 / 岗位集 / 建筑集 / 科技列表

## E6 · 机器时代（工业革命）

### ⚙️ 核心科技：蒸汽机

> 人类第一次不依赖肌肉与风水的力量。

| 维度 | 内容 |
|---|---|
| **发展方式** | **能量转换型**——煤 → 蒸汽 → 机械能 → 一切生产 |
| **核心矛盾** | 能量链条越长，损耗与瓶颈越多 → **优化能量转化效率** |

**玩法围绕蒸汽机展开**：

- **能量链**：煤 → 蒸汽 → 机械能 → 驱动工厂，每一环有效率损耗
- **电网**：电力成为二级资源，需平衡发电与耗电（发电不足则全厂降速）
- **工厂化**：生产从"岗位产出"转为"工厂产能"，规模效应显著
- **铁路**：连接产地与工厂，降低运输损耗
- **城市化**：人口向城市集中，产出提升但污染累积
- **衍生科技**：蒸汽机、铁路、炼钢、电力、化工、内燃机

**减弱后（E7 起）**：
- 电力取代蒸汽成为主能源，蒸汽设备效率降权但**仍在运转**
- 保留"质"作用：提供能源冗余备份（电网故障时仍可运转）

## E7 · 电子时代（信息时代）

### 💻 核心科技：计算机

> 当计算可以被外包给机器，人终于能从微观操作里抬头。

| 维度 | 内容 |
|---|---|
| **发展方式** | **信息自动化型**——用数据购买自动化，逐步交出微观操作 |
| **核心矛盾** | 自动化需要数据，数据需要算力，算力需要能源 → **三重依赖链** |

**玩法围绕计算机展开**：

- **数据资源**：由计算机中心产出，是自动化的唯一货币
- **自动化系统**：用数据购买 AI 助手，自动分配人力、自动排队建造、自动研究
- **算力**：计算机需持续耗电，算力上限决定可运行的自动化数量
- **核能**：高风险高回报的能源选项（可大幅缓解算力瓶颈）
- **航天准备**：发射场与轨道建造，为 E8 铺垫
- **衍生科技**：晶体管、互联网、核裂变、基因工程、航天器

**减弱后**：通往 E8 星海时代（另立文档）

旧核心进入"地基期"时，玩家应该**感受到交接**，而不是突然发现旧东西没用了。

|---|---|

| 界面降级 | 旧核心的界面从主面板移到"基础设施"折叠区 |
| 数值可见 | 悬停可看到"当前系数 ×0.6（来自 1 个时代前）" |

## 3.2 科技与时代跃迁的关系

沿用 `01-core-loop.md` 的**三条件**：

```
跃迁 = 核心科技研究完成 + 资源门槛达标 + 里程碑建筑建成
```

**新增确认**：跃迁的**门槛科技通常就是核心科技本身**（如 E1 的火 → 推开门的是农业）。

| 跃迁 | 核心科技（本代） | 门槛科技（推开下代） |
|---|---|---|
| E1 → E2 | 火 | 农业 |
| E2 → E3 | 农业 | 文字 |
| E3 → E4 | 文字 | 法典 |
| E4 → E5 | 法典 | 印刷术 |
| E5 → E6 | 印刷术 | 蒸汽机 |
| E6 → E7 | 蒸汽机 | 计算机 |
| E7 → E8 | 计算机 | 轨道建造 |

**视觉化理解**：

```
E1 火 ──▶ E2 农业 ──▶ E3 文字 ──▶ E4 法典
                                        │
                                        ▼
        E7 计算机 ◀── E6 蒸汽机 ◀── E5 印刷术
              │
              ▼
        E8 星海（另文档）

每代的核心科技，既是本代的引擎，也是推开下一扇门的钥匙。
```
