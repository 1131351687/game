# 第一部分 · 核心设计原则

## 1.1 一时代，一核心科技

**每个时代有且仅有一项核心科技。** 它是该时代一切发展的依托：

| 核心科技的作用 | 说明 |
|---|---|
| **定义发展方式** | 玩家在这个时代"优化什么"由它决定 |
| **统摄其他内容** | 该时代的岗位、建筑、次级科技都围绕它展开、为它服务 |
| **构成主要矛盾** | 该时代玩家要解决的核心问题由它产生 |
| **作为跃迁钥匙** | 通常与门槛科技同源或直接相关 |

**为什么这样设计**：放置游戏的通用问题——后期内容会退化成"同样的东西数字更大"。用"一时代一核心科技"强制每个时代换一套**优化对象**，玩家在 E1 琢磨"怎么维持火种"、在 E6 琢磨"怎么把煤变成电"，虽然底层框架相同，但**决策内容彻底不同**。

## 1.2 核心科技决定发展方式的差异

七个时代的发展方式递进关系：

| 时代 | 核心科技 | 发展方式 | 玩家优化什么 |
|---|---|---|---|
| E1 | **火** | 维持型 | 怎么让火不灭 |
| E2 | **农业** | 周期储备型 | 怎么攒够过冬的粮 |
| E3 | **文字** | 记录交换型 | 怎么让知识与物资流动起来 |
| E4 | **法典** | 规模治理型 | 怎么在扩张与维稳间平衡 |
| E5 | **印刷术** | 知识复利型 | 怎么让研究滚雪球 |
| E6 | **蒸汽机** | 能量转换型 | 怎么把煤转成生产力 |
| E7 | **计算机** | 信息自动化型 | 怎么把自己从微观操作中解放出来 |

**七个时代，七种完全不同的优化目标。** 这是本作区别于普通放置游戏的核心。

## 1.3 减弱机制：不废弃，只降权

> **设计约束（已定）**：进入新时代时，旧核心科技**不能被完全放弃，只能减弱**。

### 1.3.1 旧核心科技的三个阶段

| 阶段 | 时期 | 作用 |
|---|---|---|
| **主引擎期** | 所属时代 | 它是增长的主要来源，加成 ×1.0 |
| **地基期** | 后续时代 | **仍然生效并持续提供加成**，但效果随时代距离衰减 |
| **前置期** | 永远 | 作为后续科技的解锁前置，保持"必需"地位，不可跳过 |

### 1.3.2 衰减规则（【待定】具体数值）

```
时代距离 d = 当前时代序号 − 核心科技所属时代序号
加成系数 = max(下限, 衰减率 ^ d)
```

参考取值：

| 距离 d | 系数（衰减率 0.6） | 说明 |
|---|---|---|
| 0（当代） | ×1.00 | 主引擎 |
| 1 | ×0.60 | 刚换代，仍是重要助力 |
| 2 | ×0.36 | 转为基础支撑 |
| 3 | ×0.22 | 背景加成 |
| ≥4 | **×0.20** | **触底，永不归零** |

**下限 20% 是硬性保证**：即使打到 E7，E1 的火种仍在提供 20% 加成。这就是"不能完全放弃"的机制化表达。

### 1.3.3 关键：旧核心提供"质"的加成，不只是"量"

单纯数值衰减会让旧核心变成"聊胜于无的零头"，玩家情感上仍是放弃。因此旧核心科技还应提供**不可替代的功能性作用**：

| 旧核心 | 衰减后的"质"作用 |
|---|---|
| 火 | 提供人口舒适度底线（无火则人口增速受限） |
| 农业 | 提供粮食安全底线（不依赖外来供给） |
| 文字 | 提供研究的基础斜率（无文字则研究效率大减） |
| 法典 | 提供维稳成本的固定化（无法律则扩张惩罚加剧） |
| 印刷术 | 提供知识的跨时代保留率 |
| 蒸汽机 | 提供能源的冗余备份（电网故障时仍可运转） |

**设计意图**：即使加成降到 20%，玩家仍然"需要"它，而不是"懒得关掉"它。

## 1.4 科技树形态（【待定】）

在"核心科技"框架下，科技树自然形成**三层结构**：

```
         ┌──────────────────────────┐
         │   核心科技（每代一项）      │  ← 主干，必经
         └────────────┬─────────────┘
                      │
        ┌─────────────┼─────────────┐
        │             │             │
   ┌────▼───┐   ┌────▼───┐   ┌────▼───┐
   │ 支撑科技 │   │ 支撑科技 │   │ 支撑科技 │  ← 服务于核心，可多选
   └────────┘   └────────┘   └────────┘
        │             │             │
   ┌────▼───┐   ┌────▼───┐   ┌────▼───┐
   │ 效率科技 │   │ 效率科技 │   │ 效率科技 │  ← 数值加成，可选
   └────────┘   └────────┘   └────────┘
```

| 层级 | 数量 | 作用 | 是否必经 |
|---|---|---|---|
| 核心科技 | 每代 1 项 | 定义发展方式、开启新机制 | ✅ 必经 |
| 支撑科技 | 每代 3–5 项 | 围绕核心展开，解锁配套岗位/建筑 | 大部分必经 |
| 效率科技 | 每代 5–15 项 | 纯加成与优化 | ❌ 可选 |

**【待定】**：效率科技是否允许"互斥选择"（点了 A 就不能点 B）？

## E1 · 蒙昧时代（旧石器）

### 🔥 核心科技：火

> 掌握火，是人类第一次支配自然力。

| 维度 | 内容 |
|---|---|
| **发展方式** | **维持型**——你的首要任务不是"增长"，而是"别让火灭了" |
| **核心矛盾** | 火要木材、人口要人力、武器要石头 —— **三者争夺同一份人力** |

### 1. 火种系统（核心机制）

**火种值**：0–100 的动态数值，投入木材上升，随时间自然衰减。

| 火种阶段 | 区间 | 状态 |
|---|---|---|
| 熄灭 | 0 | 全部加成失效，人口开始下降 |
| 微弱 | 1–33 | 部分加成 |
| 稳定 | 34–66 | 完整基础加成 |
| 旺盛 | 67–100 | 触发额外效果（如夜间活动时间延长） |

**火提供三层作用**：

| 作用 | 效果 | 机制 |
|---|---|---|
| **熟食** | 食物能量转化率↑ | 影响食物产出的**有效值** |
| **取暖** | 婴儿死亡率↓ | 影响**人口增长速率**（见下） |
| **驱兽** | 损失事件↓ | 降低野兽袭击的损失 |

**衍生科技**：取火术、火塘、燧石、烤肉、火把、火硬化木矛

### 2. 人口系统（本时代第二条主线）

> **设计依据**：控火 → 食物被"体外预消化" → 能量盈余 + 食谱扩大 → **断奶提前 → 生育间隔缩短** → 人口跃升。
> （Wrangham「熟食假说」，⚠️ 学界非共识，此处作为设计灵感采纳其因果结构）

**关键设计**：火**不直接加人口**，而是通过缩短生育间隔来加速人口增长。

```
火稳定度 → 断奶周期 → 生育间隔 → 人口增速
```

| 参数 | 参考史实值 | 游戏中作用 |
|---|---|---|
| 游群规模 | 10–50 人（均值 25–30） | E1 人口基数与前期天花板 |
| 哺乳期 | 2–4 年 | 人口增长的天然节流阀 |
| 婴儿死亡率 | 20–40% | 受火/取暖影响的核心变量 |
| 成年后余寿 | 再活 40–50 年 | ⚠️ **不做"老龄死亡"机制** |

**人口的作用**：

- 人口 = **人力上限**，是全部岗位的燃料
- 人口规模决定**能支持多少专才**（书吏、工匠、萨满）

### 3. 人口阈值与"技术失传"（特色机制）

> **设计依据**：Henrich「塔斯马尼亚效应」——人口小且孤立 → 文化复杂度**丢失**，已掌握的技术退化。
> （⚠️ 该案例有反驳者，此处作为**机制灵感**而非史实依据）

```
人口 < 阈值  →  已解锁科技开始"失传"（退回未解锁）
人口 ≥ 阈值  →  科技正常累积，进入棘轮式增长
```

**设计意图**：放置游戏几乎不做"退化"，但它制造了**真实的压力**——你不能让人口掉下去，否则文明倒退。这比单纯的"人口越多越好"有张力得多。

**【待定】**失传是永久性的还是可恢复的？失传速度多快？

### 4. 承载力和选址

> **设计依据**：狩猎采集者人口密度 0.01–1 人/km²，但沿海/鲑鱼洄游/橡子富集区可达 1–10 人/km² —— **相差 100 倍**。

**机制**：开局选址决定**承载力上限**与**资源偏向**。

| 选址 | 承载力 | 特点 |
|---|---|---|
| 内陆草原 | 低 | 大型猎物多，适合狩猎路线 |
| 河谷 | 中 | 采集稳定，适合人口路线 |
| 沿海 | 高 | 承载力上限最高，但依赖水产 |

**这一设计同时是后续 P2「平行文明」起源系统的种子**（河谷/草原/海洋三种起源）。

### 5. 武器系统

**框架**：武器是**可累积 / 可损耗的资源**，而非一次性升级。

```
狩猎产出 = 猎人数 × f(武器数量)
```

玩家需持续投入人力与石头生产武器 → 形成长期的人力占用与取舍。

**武器演进（均据考古实证）**：

| 阶段 | 武器 | 年代锚点 | 游戏效果 |
|---|---|---|---|
| 1 | 削尖木矛 | Schöningen 矛（德国），约 **40 万年前**，重心靠前＝可投掷 | 解锁猎人岗位 |
| 2 | 装柄石矛 | 中晚旧石器普遍；燧石尖＋赭石树脂黏合剂（Le Moustier，6–3.5 万年前） | 狩猎效率显著↑ |
| 3 | 投矛器 atlatl | 可靠证据约 **2.1–1.7 万年前**（法国洞穴） | 投掷距离与穿透↑ |
| 4 | 弓箭 | ⚠️ 起源**高度争议**（8 万–1.7 万年前） | 远程狩猎，可攻击警觉猎物 |
| 旁支 | 石球 / 流星索 | ⚠️ 主要靠后世民族志推断 | 缠绊猎物，提高捕获率 |
| 旁支 | 火硬化木矛 | 用火衍生技术 | 提升木矛效果 |

**集体围猎（战术层）**：

- 实证：Schöningen 湖畔芦苇丛伏击、把马群逼向湖岸；La Cotte de St Brelade 堆积的猛犸与披毛犀骨
- 机制：猎人数达到阈值后触发**围猎加成**（人数越多，单位猎人效率越高）——与散户狩猎形成对比

### 6. 三者的咬合关系

```
              🔥 火（核心）
              │ 熟食 → 食物效率↑
              │ 取暖 → 婴儿死亡率↓ → 生育间隔↓
              │ 驱兽 → 损失↓
              ▼
        👥 人口（引擎）
              │ 人口 = 人力上限
              ▼
        🗡️ 武器（倍率）
                 狩猎效率↑ → 肉食↑ → 反哺人口
```

**形成闭环**：火旺 → 人口增 → 人力足 → 可造更多武器 → 狩猎多 → 人口再增。
**反之**：火弱 → 人口滞 → 人力缺 → 武器少 → 食物缺 → 更维持不住火。

### 7. 资源集

| 资源 | 图标 | 来源 | 用途 | 史实依据 |
|---|---|---|---|---|
| **食物** | 🍖 | 采集者、猎人 | 人口增长 | 采集＋大型猎物狩猎 |
| **木材** | 🪵 | 伐木者 | **维持火种**、制矛柄 | 木矛实证 |
| **石头** | 🪨 | 打石者 | 造石器、武器 | Oldowan 石器 |
| **兽皮** | 🦴 | 猎人（副产） | 衣物、棚屋 → 降低婴儿死亡率 | 刮削器＋骨针间接证据 |
| **武器** | 🗡️ | 制器者 | 狩猎效率（**有损耗**） | Schöningen 矛等 |
| **经验** | 💡 | **人口自然产生** | 解锁本时代科技 | 口头传承、无文字 |
| **人力** | 👥 | 人口 | 所有岗位的燃料 | 游群 10–50 人 |

**两个特殊项**：

- **火种** —— 独立状态值（0–100），不计入资源列表，是本时代的**核心仪表盘**
- **经验** —— **本时代没有"研究点"**（史实上还没有文字）。经验由**每个在世人口持续产生**，替代研究点

> **「经验」这个设计很关键**：人口越多 → 经验越快 → 科技解锁越快。
> 这直接呼应"人口阈值"机制——人口掉下去，不只是产出少，而是**文明停止进步甚至倒退**。

### 8. 岗位集

| 岗位 | 消耗 | 产出 | 说明 |
|---|---|---|---|
| 🌾 **采集者** | 人力 | 食物 | 最基础，无门槛 |
| 🪓 **伐木者** | 人力 | 木材 | 火种的燃料来源 |
| 🪨 **打石者** | 人力 | 石头 | 石器与武器的原料 |
| 🦌 **猎人** | 人力 × 武器 | 食物 ＋ 兽皮 | **需要武器**，产出受武器倍率影响 |
| 🔨 **制器者** | 人力 ＋ 石头 | 武器 | 武器的唯一来源 |

**关键取舍**：猎人需要武器才能高效工作，而制器者又占用人力——**造武器的人力从哪来**，是 E1 的核心运营决策。

### 11. 特色机制：考古争议（可选做）

研究给的灵感：旧石器史上有大量**学界争议条目**（用火年代、弓箭起源、Schöningen 测年）。

**设计用法**：把争议条目做成**分支科技或随机考古事件**——

- 同一条科技有两种解锁路径，玩家选择"相信哪种假说" → 得到不同加成
- 或触发"考古发现"事件：发现一处遗址，二选一解读，得到不同结果

**好处**：既增加重复游玩价值，又把真实考古学的"不确定性"变成玩法，很有辨识度。

### 12. 减弱后（E2 起）

- 定居后有了固定炉灶，**火种不再需要主动维护**（取消维持压力）
- 加成从 ×2.0 起按时代系数衰减
- 保留"质"作用：**提供人口舒适度底线**（无火则人口增速受限）

#### 13.1 起始状态

| 项 | 值 |
|---|---|
| 人口 | 2 |
| 食物 | 20 |
| 木材 | 10 |
| 石头 / 兽皮 / 武器 / 经验 | 0 |
| 火种 | **0（尚未掌握火）** |

#### 13.2 火种

| 项 | 值 |
|---|---|
| 上限 | 100 |
| 自然衰减 | **2.0 / 秒** |
| 投入 1 木材 | **+6 火种**（即维持需 ≈0.33 木材/秒） |

| 档位 | 区间 | 食物加成 | 婴儿死亡率 | 损失减免 |
|---|---|---|---|---|
| 熄灭 | 0 | — | 人口开始下降 | — |
| 微弱 | 1–33 | +10% | ×1.0 | 0% |
| 稳定 | 34–66 | +25% | ×0.7 | −20% |
| 旺盛 | 67–100 | +40% | ×0.5 | −40% |

#### 13.3 人口

| 项 | 值 |
|---|---|
| 基础上限 | 4（每座营地 +4） |
| 食物消耗 | **0.2 / 秒 / 人** |
| **经验产出** | **0.1 / 秒 / 人** |
| 生育条件 | 食物 > 人口 × 5 且 火种 > 0 |

**生育间隔** = `60 秒 × 火种系数 × 食物系数`

| 火种档位 | 系数 | 食物状况 | 系数 |
|---|---|---|---|
| 旺盛 | ×0.5 | 充裕（>人口×20） | ×0.8 |
| 稳定 | ×1.0 | 正常 | ×1.0 |
| 微弱 | ×2.0 | 紧张（<人口×8） | ×1.5 |
| 熄灭 | 停止增长 | — | — |

**熄灭惩罚**：火种归零时，每 30 秒 −1 人。

#### 13.4 岗位产出

> **E1 用线性产出，不用 sqrt 递减。**
> 理由：E1 规模极小（人口 2→27），每个人口增长都应手感明显；且此规模无爆炸风险。
> 递减收益建议从 **E3** 规模上千时再引入。

| 岗位 | 消耗 | 产出/秒 |
|---|---|---|
| 🌾 采集者 | 人力 | 0.5 食物 |
| 🪓 伐木者 | 人力 | 0.4 木材 |
| 🪨 打石者 | 人力 | 0.3 石头 |
| 🦌 猎人 | 人力 ＋ **武器** | 0.7 食物 ＋ 0.16 兽皮（需武器满配） |
| 🔨 制器者 | 人力 ＋ 0.2 石头 | 0.1 武器 |

#### 13.5 武器损耗（形成持续人力占用）

```
有效猎人数 = min(猎人数, 武器数)     ← 武器不足则猎人闲置
武器损耗   = 有效猎人数 × 0.02 / 秒   ← 50 秒磨损一把
```

**平衡验算**：20 个猎人 → 损耗 0.4 武器/秒 → 需 4 个制器者维持 → 4 个制器者又需 0.8 石头/秒 → 需约 3 个打石者。

**这就是 E1 的核心取舍**：每多养一个制器者，就少一个猎人。

### 14. 20 分钟节奏时间线

| 时段 | 玩家在做什么 | 人口 | 火种 |
|---|---|---|---|
| **0:00–2:00** | 采集食物攒资源；研究「掌握火」点燃第一堆火 | 2 → 4 | 0 → 点燃 |
| **2:00–6:00** | 建火塘；派伐木者维持火种；建第一座营地 | 4 → 9 | 稳定 |

- **前 2 分钟**：教学——学会分配人力、点燃火
- **2–6 分钟**：第一次危机——火种开始衰减，必须派人伐木

- **11–16 分钟**：进入正轨——三线稳定的运营期
- **16–20 分钟**：冲刺目标——明确知道要干什么

## E2 · 定居时代（新石器 / 农业革命）

### 🌾 核心科技：农业

> 从"跟着食物走"到"让食物长在门口"。

| 维度 | 内容 |
|---|---|
| **发展方式** | **周期储备型**——夏秋生产、冬春消耗，为过冬做规划 |
| **核心矛盾** | 丰季人力该全投生产还是分去建设？冬季无法生产，全靠储备 |

**玩法围绕农业展开**：

- **季节循环**：春夏秋冬各 N 个游戏日，冬季产出大幅下降
- **粮仓**：存储上限决定你能撑过几个冬天
- **土地**：开垦更多田地需要人力与时间，但提升长期产能
- **作物选择**：不同作物产量/生长期/耐寒性不同（【待定】是否引入）
- **衍生科技**：灌溉、轮作、犁、育种、畜牧、陶器储存

**减弱后（E3 起）**：
- 农业仍是粮食来源，但**不再驱动增长**（增长引擎转移到文字与贸易）
- 保留"质"作用：提供粮食安全底线，不依赖外来供给

## E3 · 城邦时代（青铜时代）

### ✍️ 核心科技：文字

> 文字让知识可以累积——第一次，前人的发现能被后人接住。

| 维度 | 内容 |
|---|---|
| **发展方式** | **记录交换型**——知识可累积，物资可交换 |
| **核心矛盾** | 记录与计算需要人力（书吏），但这些人不直接产出物资 |

**玩法围绕文字展开**：

- **知识累积**：研究成果不再随时代丢失，可跨时代叠加
- **记录容量**：可"记住"的科技数量有上限，需扩建学宫
- **贸易路线**：与虚拟邻邦交换资源，价格浮动，需记录账目
- **契约**：与邻邦签订长期协议，违约有代价
- **衍生科技**：楔形文字、泥板、算筹、轮子、度量衡、货币雏形

**减弱后（E4 起）**：
- 文字成为**基础设施**，研究加成降权
- 保留"质"作用：作为后续所有科技的**前置钥匙**，且提供研究基础斜率

## E4 · 帝国时代（铁器 / 古典）

### ⚖️ 核心科技：法典

> 当疆域大到无法靠血缘维系，就需要成文的规则。

| 维度 | 内容 |
|---|---|
| **发展方式** | **规模治理型**——扩张带来收益，也带来成本 |
| **核心矛盾** | 版图越大产出越高，但维稳成本呈超线性上升 → **规模不经济** |

**玩法围绕法典展开**：

- **版图系统**：领土扩张提升产出，但每块新领土的维稳成本递增
- **政体**：君主 / 共和 / 神权，各自加成与代价不同（**政体系统在此首次登场**）
- **法典条款**：可立法调整各项参数（税率、兵役、贸易管制），有得有失
- **官僚**：官吏岗位消耗人力但降低维稳成本——**投入治理=换取规模**
- **衍生科技**：成文法、道路网、铸币、军团编制、驿站

**减弱后（E5 起）**：
- 法典成为**默认制度**，扩张收益递减、维稳成本固定化
- 保留"质"作用：无法律则扩张惩罚加剧

## E5 · 觉醒时代（中世纪 → 文艺复兴）

### 📖 核心科技：印刷术

> 知识第一次可以被廉价复制——复利开始了。

| 维度 | 内容 |
|---|---|
| **发展方式** | **知识复利型**——研究速度随已解锁科技数增长，滚雪球 |
| **核心矛盾** | 前期印刷投入巨大且不产出物资，回报要等很久 → **前期忍耐换后期爆发** |

**玩法围绕印刷术展开**：

- **复利机制**：`研究速度 = 基础 × (1 + 已解锁科技数 × 系数)`——科技越多，研究越快
- **印刷产能**：需要纸张（木材/破布）与印刷工，产能决定复利斜率
- **知识传播**：可将科技"输出"给邻邦换取资源（【待定】）
- **远航探索**：派船队发现新大陆，带回稀缺资源与随机事件
- **衍生科技**：活字印刷、造纸、指南针、火药、天文、解剖学

**减弱后（E6 起）**：
- 印刷成为**基础产业**，复利斜率降低但仍持续生效
- 保留"质"作用：提供知识的跨时代保留率

**【待定】**资源集 / 岗位集 / 建筑集 / 科技列表

## E6 · 机器时代（工业革命）

### ⚙️ 核心科技：蒸汽机

> 人类第一次不依赖肌肉与风水的力量。

| 维度 | 内容 |
|---|---|
| **发展方式** | **能量转换型**——煤 → 蒸汽 → 机械能 → 一切生产 |
| **核心矛盾** | 能量链条越长，损耗与瓶颈越多 → **优化能量转化效率** |

**玩法围绕蒸汽机展开**：

- **能量链**：煤 → 蒸汽 → 机械能 → 驱动工厂，每一环有效率损耗
- **电网**：电力成为二级资源，需平衡发电与耗电（发电不足则全厂降速）
- **工厂化**：生产从"岗位产出"转为"工厂产能"，规模效应显著
- **铁路**：连接产地与工厂，降低运输损耗
- **城市化**：人口向城市集中，产出提升但污染累积
- **衍生科技**：蒸汽机、铁路、炼钢、电力、化工、内燃机

**减弱后（E7 起）**：
- 电力取代蒸汽成为主能源，蒸汽设备效率降权但**仍在运转**
- 保留"质"作用：提供能源冗余备份（电网故障时仍可运转）

## E7 · 电子时代（信息时代）

### 💻 核心科技：计算机

> 当计算可以被外包给机器，人终于能从微观操作里抬头。

| 维度 | 内容 |
|---|---|
| **发展方式** | **信息自动化型**——用数据购买自动化，逐步交出微观操作 |
| **核心矛盾** | 自动化需要数据，数据需要算力，算力需要能源 → **三重依赖链** |

**玩法围绕计算机展开**：

- **数据资源**：由计算机中心产出，是自动化的唯一货币
- **自动化系统**：用数据购买 AI 助手，自动分配人力、自动排队建造、自动研究
- **算力**：计算机需持续耗电，算力上限决定可运行的自动化数量
- **核能**：高风险高回报的能源选项（可大幅缓解算力瓶颈）
- **航天准备**：发射场与轨道建造，为 E8 铺垫
- **衍生科技**：晶体管、互联网、核裂变、基因工程、航天器

**减弱后**：通往 E8 星海时代（另立文档）
