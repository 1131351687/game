# 核心循环与阶段骨架

> 本文档定义游戏主干：玩家在做什么、文明如何推进、长线结构如何支撑长线游玩。
> 主题：**现实文明史**（石器 → 太空）｜节奏：**长线挂机**（各时代实际时长由机制与配平自然涌现，不做人工规划）

---

## 1. 一句话定位

**你从一簇篝火旁的采集者起步，亲手把人类文明从蒙昧推向星海。**

不是"升级数值"，而是"重走文明史"——每个时代引入一套**全新的动词**（采集 → 种植 → 冶炼 → 治理 → 研究 → 工业化 → 计算 → 殖民），让玩家在每一次跃迁中真正换一种玩法。

## 2. 玩家幻想（Player Fantasy）

| 阶段感受 | 玩家心理 |
|---|---|
| 起步 | "我在荒野里活下来了" |
| 定居 | "我让族人不再挨饿" |
| 城邦 | "我建起了第一座城" |
| 帝国 | "我的法典统治了百万臣民" |
| 觉醒 | "知识正在改变世界" |
| 机器 | "我的工厂日夜轰鸣" |
| 电子 | "我让整个星球互联" |
| 星海 | "人类不再只属于一颗行星" |

**核心张力**：每一次"跃迁"都意味着**放弃现有积累、换一套新玩法**——玩家永远在"稳住现在"和"赌一个未来"之间权衡。

---

## 3. 核心循环（四层嵌套）

### 3.1 微观循环 —— 秒级（决策：人往哪放）

```
观察资源缺口 → 调整人力分配 → 资源产出变化 → 出现新缺口
```

- **周期**：1–10 秒
- **玩家动词**：分配、调配（把人力从 A 岗位挪到 B 岗位）
- **决策内容**：食物快断了还是该冲研究了？
- **反馈**：资源数字实时跳动

### 3.2 中观循环（决策：先发展什么）

```
攒够资源 → 建造/研究 → 解锁新岗位或建筑 → 产能上升 → 下一个目标
```

- **玩家动词**：建造、研究、解锁
- **决策内容**：仓库还是研究所？扩产还是升科技？
- **反馈**：新内容出现、队列推进、消息提示

### 3.3 宏观循环（决策：何时跃迁）

```
达成时代条件 → 触发时代跃迁 → 旧内容降权、新动词登场 → 在新框架下重建
```

- **玩家动词**：跃迁（主动决策，不可逆）
- **决策内容**：现在跃迁（收益立刻生效但失去旧体系优势），还是再攒一层？
- **反馈**：整个界面换代、新资源与新面板解锁

### 3.4 元循环（决策：怎么重来）

```
文明重启 → 获得遗产点 → 永久加成 → 以更快速度重走 → 尝试不同路线
```

- **玩家动词**：重启、选择起源
- **决策内容**：这轮走"农业立国"还是"商贸立国"？
- **反馈**：全局倍率提升、新起源解锁

### 3.5 四层关系

```
        ┌─────────────────────────────────────┐
        │  元循环（重启）                        │
        │  ┌───────────────────────────────┐  │
        │  │  宏观（时代跃迁）                  │  │
        │  │  ┌─────────────────────────┐  │  │
        │  │  │  中观（建造研究）          │  │  │
        │  │  │  ┌───────────────────┐  │  │  │
        │  │  │  │ 微观（分配，秒级）  │  │  │  │
        │  │  │  └───────────────────┘  │  │  │
        │  │  └─────────────────────────┘  │  │
        │  └───────────────────────────────┘  │
        └─────────────────────────────────────┘
```

**设计铁律**：四层必须**同时活跃**。玩家挂机 8 小时回来，应该发现"微观层早已满负荷运转（说明自动化到位）、中观层卡在几个待决策项（说明有事可做）、宏观层就差临门一脚"——而不是"什么都没发生"或"全乱了"。

## 4. 阶段骨架总览

八个时代，对应真实历史分期：

| # | 时代 | 史实锚点 | 新动词 |
|---|---|---|---|
| E1 | **蒙昧** | 旧石器：用火、打制石器 | 采集·生火 |
| E2 | **定居** | 农业革命：种植、驯养、陶器 | 种植·驯养 |
| E3 | **城邦** | 青铜时代：金属、文字、轮子 | 冶炼·书写 |
| E4 | **帝国** | 铁器与古典：道路、法典、货币 | 治理·扩张 |
| E5 | **觉醒** | 文艺复兴：印刷、火药、远航 | 研究·探索 |
| E6 | **机器** | 工业革命：蒸汽、铁路、电力 | 工业化 |
| E7 | **电子** | 信息时代：计算机、核能、航天 | 计算·联网 |
| E8 | **星海** | 太空时代：轨道站、火星、星际 | 殖民·改造 |

> **不设时长目标**：每个时代要玩多久，由数值曲线与机制节奏自然决定——时间不是目标，节奏体感才是。

## 5. 逐时代详设

### E1 · 蒙昧时代（旧石器）

> **史实锚点**：距今约 300 万–1 万年。用火、打制石器、采集狩猎、语言协作。

| 项 | 内容 |
|---|---|
| **玩家动词** | 采集、分配人手、维持火种 |
| **资源** | 食物、木材、石头、人力 |
| **岗位** | 采集者、伐木者、打石者 |
| **建筑** | 营地、篝火、石器作坊 |
| **新机制** | **火种**：需要持续投入木材维持，熄灭则全产出下降（第一个"必须照看"的机制） |
| **跃迁门槛** | 研究「植物栽培」+ 积累 5,000 食物 |

**设计意图**：教会玩家"分配人手"这个核心动词。「火种」提供第一个需要照看的动态压力，让玩家理解挂机之外要回来看看。

---

### E2 · 定居时代（新石器 / 农业革命）

> **史实锚点**：约 1 万年前。农业、畜牧、陶器、纺织、定居村落。

| 项 | 内容 |
|---|---|
| **玩家动词** | 种植、驯养、建造 |
| **新增资源** | 粮食（可储存，区别于易腐的食物）、黏土、牲畜 |
| **新增岗位** | 农夫、牧人、陶工、织工 |
| **新增建筑** | 村落、粮仓、畜栏、陶窑 |
| **新机制** | **季节循环**：春夏秋冬影响农业产出，冬季必须靠粮仓存货过冬 |
| **跃迁门槛** | 研究「冶金术」+ 建造「矿场」 |

**设计意图**：引入"储备"概念——粮仓让玩家第一次需要为未来做规划。季节循环把"挂机"变成"有节奏的挂机"。

---

### E3 · 城邦时代（青铜时代）

> **史实锚点**：约 3000 BCE。青铜冶炼、文字、轮子、城邦、长途贸易、成文法典。

| 项 | 内容 |
|---|---|
| **玩家动词** | 冶炼、书写、贸易 |
| **新增资源** | 铜、锡、青铜、知识 |
| **新增岗位** | 矿工、工匠、书吏、商人 |
| **新增建筑** | 城墙、神庙、集市、学宫 |
| **新机制** | **贸易路线**：与虚拟邻邦交换资源，价格浮动；**文字**：解锁科技树永久记录 |
| **跃迁门槛** | 研究「铁器冶炼」+ 建成 3 座城邦 |

**设计意图**：贸易引入"外部世界"概念，玩家不再闭门造车。知识作为抽象资源，为后面的科技大爆发铺路。

---

### E4 · 帝国时代（铁器 / 古典）

> **史实锚点**：约 800 BCE–500 CE。铁器普及、道路网、军团、货币、哲学与法学。

| 项 | 内容 |
|---|---|
| **玩家动词** | 治理、扩张 |
| **新增资源** | 铁、货币、影响力 |
| **新增岗位** | 铁匠、士兵、官吏、哲人 |
| **新增建筑** | 大道、法典碑、军团营、铸币厂 |
| **新机制** | **政体系统**（首次登场）：君主 / 共和 / 神权，各自加成与代价不同；**版图**：领土越大产出越高但维稳成本上升 |
| **跃迁门槛** | 研究「活字印刷」前置「学术传承」 |

**设计意图**：政体是第一个"路线选择"，让不同玩家的文明开始分化。版图扩张引入"规模不经济"，防止无脑扩张。

---

### E5 · 觉醒时代（中世纪 → 文艺复兴）

> **史实锚点**：约 500–1600。大学、印刷术、指南针、火药、大航海。

| 项 | 内容 |
|---|---|
| **玩家动词** | 研究、探索 |
| **新增资源** | 纸张、火药、海图、殖民地物资 |
| **新增岗位** | 学者、水手、印刷工、制图师 |
| **新增建筑** | 大学、印刷所、船坞、天文台 |
| **新机制** | **科技树大爆发**：本时代解锁的科技数量是前三代总和；**远航探索**：派出船队发现新大陆，带回稀缺资源与事件 |
| **跃迁门槛** | 研究「蒸汽动力」+ 完成 3 次远航 |

**设计意图**：从"攒资源"转向"攒知识"。玩家开始感受到"知识复利"——早期研究投入在此刻集中回报。

---

### E6 · 机器时代（工业革命）

> **史实锚点**：1760–1900。蒸汽机、铁路、工厂制、电力、资本主义。

| 项 | 内容 |
|---|---|
| **玩家动词** | 工业化 |
| **新增资源** | 煤、蒸汽、钢、电力、资本 |
| **新增岗位** | 产业工人、工程师、技师、金融家 |
| **新增建筑** | 工厂、铁路、发电厂、交易所 |
| **新机制** | **电网**：电力成为二级资源，需平衡发电与耗电；**城市化**：人口向城市集中，带来产出提升与污染压力 |
| **跃迁门槛** | 研究「内燃机」+ 电力产能达标 |

**设计意图**：电网引入"资源转换链"——不再是从岗位直接产出，而是"煤 → 电 → 生产"。这是放置游戏深度的重要来源。

---

### E7 · 电子时代（信息时代）

> **史实锚点**：1900–2000。计算机、互联网、核能、航天、基因工程。

| 项 | 内容 |
|---|---|
| **玩家动词** | 计算、联网、发射 |
| **新增资源** | 石油、芯片、数据、铀 |
| **新增岗位** | 程序员、研究员、航天员、医生 |
| **新增建筑** | 计算机中心、互联网骨干、核电站、发射场 |
| **新机制** | **自动化**：可用"数据"购买自动分配人力的 AI 助手（放置游戏的关键体验升级）；**核能**：高风险高回报的能源选项 |
| **跃迁门槛** | 研究「轨道建造」+ 建成发射场 |

**设计意图**：自动化让玩家从"微观层解放"，符合放置游戏的成长曲线——玩家的注意力应该逐层上移。

---

### E8 · 星海时代（太空）

> **史实锚点**：未来。轨道站、月球基地、火星殖民、星际航行。

| 项 | 内容 |
|---|---|
| **玩家动词** | 殖民、改造（terraforming） |
| **新增资源** | 氦-3、稀土、合金、反物质 |
| **新增岗位** | 轨道工人、行星工程师、星际船员 |
| **新增建筑** | 轨道站、月球基地、火星穹顶、星际船坞 |
| **新机制** | **多星球并行经营**：每颗星球有独立资源与特性，需分配注意力；**行星改造**：长期工程，改变星球环境以提升产能 |
| **跃迁门槛** | 通关条件：完成「星际播种」 |

**设计意图**：多星球把"分配人力"的微观决策放大到"分配资源到哪个星球"，是核心动词的最终形态。

## 6. 时代跃迁机制

### 6.1 跃迁的三个条件（全部满足才能跃迁）

```
1. 关键科技      —— 该时代的"门槛科技"必须研究完成
2. 资源积累      —— 达到该时代的资源门槛
3. 里程碑建筑    —— 建成至少一个标志性建筑
```

### 6.2 跃迁是主动决策，不是自动的

**这是核心设计**：玩家可以选择"现在跃迁"或"再攒一层"。

| 选择 | 收益 | 代价 |
|---|---|---|
| 立即跃迁 | 新动词、新资源、更高产出上限 | 旧体系优势削弱，重建成本 |
| 延迟跃迁 | 旧时代资源继续累积，可换更多遗产点 | 时间成本，产能增长遇到天花板 |

### 6.3 跃迁后旧内容怎么处理

**不做"作废"，做"降权"**：

- 旧时代的岗位/建筑**保留**，作为新体系的基础供应
- 但它们的**产出占比逐步降低**（新体系效率更高）
- 玩家不需要推倒重来，只需把注意力转移到新层

这避免了"跃迁 = 惩罚"的负面体验。

## 7. 长线结构（重置层级）

三层重置，逐层解锁：

### P1 · 文明重启（首次跃迁到 E4 后解锁）

```
触发：主动选择重启
保留：遗产点（Legacy）、成就、已解锁科技图纸
失去：所有资源、建筑、岗位
收益：遗产点，每点 +3% 全局产出（后续递减）
```

**设计意图**：让"重走"比第一次快得多，这是放置游戏长线留存的核心。

### P2 · 平行文明（通关一次后解锁）

```
触发：重启时选择"起源"
选项：
  · 河谷文明 —— 农业 +25%，但矿产 -15%
  · 草原文明 —— 畜牧 +30%，但研究 -10%
  · 海洋文明 —— 贸易 +35%，但扩张成本 +20%
收益：不同起源走不同路线，解锁起源专属科技
```

**设计意图**：用"不同起点"制造重复游玩价值，而不是单纯数值翻倍。

### P3 · 星际播种（通关星海时代后解锁）

```
触发：在多个星球同时重启文明
收益：星球间资源互补、专属终局科技、真结局
```

## 8. 设计原则与约束

### 8.1 必须遵守

1. **每个时代必须引入新动词**，不能只是数值放大
2. **跃迁必须是玩家主动决策**，不能自动触发
3. **旧内容降权而非作废**，避免跃迁变成惩罚
4. **四层循环同时活跃**，挂机回来必须有事可做
5. **离线收益有上限**（建议 8 小时），防止放置游戏失控
6. **所有数字必须可解释**：悬停能看到"为什么是这个数"

### 8.2 明确不做

- ❌ 不做强制剧情与对话（玩家自己书写文明史）
- ❌ 不做 PVP / 排行榜（纯单机体验）
- ❌ 不做随机毁灭式事件（避免挫败感，事件应可预期可应对）
- ❌ 不做"必须每天上线"的日常任务（放置游戏应尊重玩家时间）

## 9. 与现有 demo 的关系

当前 demo 实现了 E1–E2 的雏形：

| demo 已有 | 对应 |
|---|---|
| 5 资源（食物/木材/石头/人力/研究） | E1–E2 资源集 ✓ |
| 4 岗位（农夫/伐木工/矿工/科学家） | E1–E2 岗位集 ✓ |
| 科技系统 | E1 雏形 ✓ |
| 政体系统（3 种） | 提前实现了 E4 的机制 ⚠️ |
| 重置系统 | P1 雏形 ✓ |

**结论**：demo 的主干是对的，但政体系统出现得太早（应在 E4）。后续开发应先把 E1→E2→E3 的**时代跃迁**做出来，让"文明推进"这条主干先跑通。
