# E5 · 觉醒时代（中世纪盛期 → 文艺复兴，约 1000–1550）

> 知识第一次可以被廉价复制 —— 从这一刻起，研究不再是一项一项地"攒"，而是开始**滚雪球**。

---

## 📖 核心科技：印刷术

| 维度 | 内容 |
|---|---|
| **发展方式** | **知识复利型** —— 研究速度随已解锁科技数增长：科技越多 → 研究越快 → 科技更多 |
| **核心矛盾** | 印刷链**前期投入巨大、且不产出任何物资**，回报要等很久 → **前期忍耐换后期爆发** |

### 为什么是"复利"而不是"更快"

E1–E4 的增长都是**线性累加**：多一个采集者多一份食物，多一项科技多一个加成。
E5 是**全游戏第一次出现正反馈循环**：投入 → 斜率 → 更快投入。

这带来两个必须解决的设计问题，本章第 1 节专门处理：

1. **正反馈天生会失控** —— 必须给出上界或递减，否则后期数值爆炸
2. **忍耐期必须可感知** —— 玩家在"看不到回报"的阶段里会以为自己玩错了

### 继承自 E4 的起点条件

| 项 | E5 起始状态 | 说明 |
|---|---|---|
| **法典** | **降级为"默认制度"** | 维稳成本不再随扩张超线性上升（**固定化**），玩家不再需要主动立法 |
| **扩张收益** | **转为递减** | 第 m 块领土的产出加成 = 基础 × `0.90^(m−1)`，累积下限 40% |
| **官僚** | 保留，人力需求降为 E4 的 **60%** | 治理从"要解决的问题"变成"已解决的地基" |
| **政体** | 保留，但切换代价极高 | 本时代的优化目标不是治理，是知识 |
| **火（E1）** | 地基期，d=4 → 系数 ×0.20 | 提供"人口舒适度底线"的质作用 |
| **文字（E3）** | 地基期，d=2 → 系数 ×0.36 | 提供研究的基础斜率 |
| **农业（E2）** | 地基期，d=3 → 系数 ×0.22 | 提供粮食安全底线 |

> **设计意图**：E4 的"规模治理型"矛盾（越大越难管）在 E5 被**制度消化**掉了。
> 玩家不再纠结扩张，因为本时代要纠结的是**要不要把三分之一的人力丢进一个短期内什么都不产出的东西里**。

## 1. 知识复利（核心机制）

### 1.1 公式

```
研究速度 = 印刷产能 × 复利倍率 × 识字率因子

复利倍率 R(N) = 1 + k × N_eff
```

| 项 | 含义 | 来源 |
|---|---|---|
| **印刷产能** | 典籍/秒，研究速度的"底数" | 造纸坊 → 印书坊 → 造纸工 / 印刷工 |
| **复利倍率 R** | 研究的"乘数"，随科技数上升 | 本机制 |
| **N_eff** | 有效科技数（对已解锁科技数做**分段递减映射**） | 见 1.3 爆炸控制 |
| **k** | 复利系数，0.05 → 0.10，由科技推进 | 见 11.2 |
| **识字率因子** | `0.70 + 0.60 × 识字率` | 见第 4 节 |

**基础形态就是 brief 里那条公式**：`研究速度 = 基础 × (1 + 已解锁科技数 × 系数)`。
在 N ≤ 20 的区间内，`N_eff = N`，**逐字成立** —— 玩家每解锁一项科技，面板上就实实在在 +k。
超过 20 项后才进入递减段（见 1.3）。

### 1.2 雪球到底滚在哪里：底数 × 乘数

这里有一个必须讲清楚的设计判断。

如果只有复利倍率 R 在涨，而科技成本按指数增长，那么**解锁速率反而会下降**：

| N | N_eff | R (k=0.07) | 下一项成本(相对) | 解锁速率 ∝ R/成本 |
|---|---|---|---|---|
| 5 | 5 | 1.35 | 1.00 | 1.35 |
| 10 | 10 | 1.70 | 1.76 | 0.97 |
| 15 | 15 | 2.05 | 3.11 | 0.66 |
| 20 | 20 | 2.40 | 5.47 | 0.44 |
| 30 | 25 | 2.75 | 17.0 | 0.16 |

单看 R，**没有拐点，只有减速**。所以"滚雪球"绝不能只靠 R。

**真正的雪球是乘积**：

```
研究速度 = 印刷产能 B(t)  ×  复利倍率 R(N)
              ↑ 指数增长          ↑ 有界、饱和
```

- **B(t) 是底数，它自己就是一个正反馈**：典籍↑ → 解锁"水轮捣浆 / 双人压印机 / 印坊分工" → 典籍↑↑。
  这是指数增长，且**不受任何人为上限约束** —— 它只受木材、人力、建筑成本这些**物理资源**约束。
- **R(N) 是乘数，它是有界的**：因为 N_eff 有硬上限，R 永远 ≤ ×4.20（见 1.3）。

**为什么这样分工**：
- 把指数增长交给 B —— 玩家能理解"我多盖一座印书坊，产出就多一截"，且它天然被资源卡住，不会失控
- 把有界乘数交给 R —— 它提供"知识积累有回报"的**叙事与手感**，但正因为有界，**不构成爆炸风险**

**两个乘积才是"爆发"**：前期 B≈0，R≈1，所以慢得让人怀疑人生；后期 B 涨了 50 倍、R 涨到 ×3.5，乘积涨了 175 倍 —— 这就是"忍耐换爆发"的数学形态。

### 1.3 ⚠️ 爆炸风险控制（三道闸门）

正反馈机制必须有闸门。这里给三道，**互相独立，任何一道单独失效都不会崩**。

#### 闸门一：纪元内计数（结构性闸门）

```
N = 本时代已解锁科技数（从 0 起算）
```

**复利不跨时代叠加。** 跃迁到 E6 时 N 归零，复利重新从 ×1.00 起步。

| 为什么 | 说明 |
|---|---|
| 数学上 | 若 N 累计 E1–E7（约 200 项），R 会变成 ×15 以上，E7 的数值框架直接崩掉 |
| 叙事上 | 每一代的"觉醒"都要重新发生一次；E6 的引擎是能量，不是知识 |
| 手感上 | 开局 ×1.00 是"忍耐期"得以成立的前提 —— 见 1.4 |

> 印刷术在 E6/E7 不是消失了，而是**降级为地基期**：`k` 按 0.6^d 衰减（E6 ×0.6，E7 ×0.36），下限保底 20%，同时保留"知识跨时代保留率"的质作用（见第 10 节）。

#### 闸门二：分段递减映射（数值闸门）

```
N_eff = 
  N                          ,  N ≤ 20
  20 + (N − 20) × 0.5        ,  21 ≤ N ≤ 35
  27.5 + (N − 35) × 0.25     ,  N > 35
硬上限：N_eff ≤ 32
```

| N | N_eff | 该段每项增量 | k=0.05 | k=0.07 | k=0.10 |
|---|---|---|---|---|---|
| 0 | 0 | — | ×1.00 | ×1.00 | ×1.00 |
| 5 | 5 | **+1.00** | ×1.25 | ×1.35 | ×1.50 |
| 10 | 10 | **+1.00** | ×1.50 | ×1.70 | ×2.00 |
| 15 | 15 | **+1.00** | ×1.75 | ×2.05 | ×2.50 |
| 20 | 20 | **+1.00** | ×2.00 | ×2.40 | **×3.00** |
| 25 | 22.5 | +0.50 | ×2.13 | ×2.58 | ×3.25 |
| 30 | 25.0 | +0.50 | ×2.25 | ×2.75 | ×3.50 |
| 35 | 27.5 | +0.50 / +0.25 | ×2.38 | ×2.93 | ×3.75 |
| ∞（饱和） | **32** | +0.25 → +0 | **×2.60** | **×3.24** | **×4.20** |

**关键性质**：
- N ≤ 20 段**严格线性**，与 brief 的公式完全一致，玩家在最重要的"建立复利感"阶段能算出精确收益
- 三段递减**全部可解释**，悬停即可看到"第 21–35 项每项仅 +4%"
- **R 的绝对上界是 ×4.20**，与 N 无关 —— 爆炸风险在数学上被消除

#### 闸门三：科技成本指数增长（经济闸门）

第 n 项科技的有效成本按 **≈1.12^n** 增长（见 11.7 完整成本表）。

成本增速（1.12^n）长期高于复利增速（线性饱和），因此**解锁速率最终必然回落**，
R 只负责把中段的坡度抬起来 —— **它买的是时间，不是无限**。

#### 三道闸门的联合效果

| 失效场景 | 哪道闸门接住 |
|---|---|
| 玩家在 E5 内狂点效率科技 | 闸门二（N_eff 递减）+ 闸门三（成本指数） |
| 玩家跨时代想保留复利 | 闸门一（N 纪元内归零） |
| 印刷产能 B 无限膨胀 | **物理资源约束**（木材/人力/建筑成本），B 无法脱离资源独立增长 |
| 数值因 bug 叠加 | 闸门二硬上限 N_eff ≤ 32，R 永远 ≤ ×4.20 |

### 1.4 忍耐期：核心矛盾的机制化

核心矛盾不能只写在文档里，必须**被玩家看见**。

| 阶段 | 玩家体验 |
|---|---|
| **投资期** | 印刷链吃掉 30–40% 人力与资源，**物资净增长 ≈ 0，研究速度只涨了 2 倍** |
| **低谷** | 复利倍率过 ×1.9，但成本也过 1.12^14，**解锁速度看起来毫无变化** |
| **拐点** | B（印刷产能）的指数曲线终于压过成本指数，**解锁速度肉眼可见地加快** |
| **爆发** | B×R 同时高速上升，远航白银回流，**剩余科技被快速扫空** |

**UI 必须明确告诉玩家他正在忍耐**（见第 13 节）：

> 🔴 **知识投资期**：印刷链占用 37% 人力，物资净增长 −2.1%/分。
> 当前复利倍率 **×2.12**。预计再过 **3 项科技**产出转正。

没有这条提示，"忍耐"就会退化成"玩家以为自己在犯错然后弃游"。

**史实锚点（极强的支撑）**：
- 1450 与 1452 年，Johann Fust 两次借贷给 Gutenberg，共 **1,600 古尔登**；
  1455 年诉讼（Helmasperger Instrument，1455-11-06）后，Gutenberg **失去印刷坊与全部印版**。
- 1472 年，罗马最早的印刷商 Sweynheim 与 Pannartz 向教皇 Sixtus IV 请愿，
  自述**因印了太多书卖不掉而陷入贫困**，并列出印量明细（合计 **12,475 册**）。
- **历史上第一批印刷商，真的破产了。** ⚠️ 这不是游戏编的惩罚，是史实。

## 2. 印刷产能链：纸张 → 典籍 → 研究（核心机制）

复利倍率 R 决定"乘数有多少"，而**印刷产能决定"这个乘数乘在多大的底数上"**。
brief 要求"印刷产能决定复利斜率" —— 本作把它做成**一明一暗两条线**：

| 线路 | 机制 | 玩家感知 |
|---|---|---|
| **暗线（主）** | 印刷产能 → 典籍 → 研究 → N↑ → R↑ | "书印得多，研究就快" |
| **明线（辅）** | 累计典籍产量达到里程碑 → 解锁"复利斜率 +"科技 | 面板直接写"复利系数 0.05 → 0.06" |

### 2.1 链条

```
🪵 木材（伐木工，E1 遗产）
        │
        ▼
   📜 纸张 ──────────► 存储上限受「图书馆」约束
        │  （造纸工消耗 0.5 木材/秒 → 1.2 纸张/秒）
        ▼
   📚 典籍 ──────────► 存储上限受「图书馆」约束
        │  （印刷工消耗 0.8 纸张/秒 → 0.6 典籍/秒）
        ▼
   🎓 学者（消耗 0.5 典籍/秒 → 2.0 研究/秒）
        │
        ▼
   研究速度 = 学者产出 × R(N) × 识字率因子
```

**这条链有三个独立瓶颈，玩家必须逐个打通**：

| 瓶颈 | 卡在哪 | 打通方式 |
|---|---|---|
| **原料** | 木材不够 → 纸张不足 | 伐木工（E1 遗产岗位，**旧内容在此重新变得关键**） |
| **产能** | 造纸坊/印书坊工位不够 | 加盖建筑（成本含木材+铁+白银） |
| **转化** | 学者不够 → 典籍堆积无人读 | 大学（解锁学者）+ 人口 |
| **存储** | 典籍溢出被浪费 | 图书馆 |

> **设计意图**：E1 的伐木工在 E5 依然是链条的第一环 —— 这是"旧内容降权而非作废"的最佳体现。
> 玩家会惊讶地发现：**五个时代之后，他还在为木材发愁，只是发愁的原因换了一个。**

### 2.2 典籍是消耗品，不是积分

**典籍会被学者"读掉"**（0.5 典籍/秒/学者）。

| 这个设计解决什么 | 说明 |
|---|---|
| 印刷链不会被淘汰 | 若典籍是永久积分，读完后印刷工就可以下岗。现在**印刷必须持续运转** |
| 复利不能脱离投入 | 研究速度再高，也要有典籍喂 —— **乘数再大也乘不了 0** |
| 创造真实的取舍 | 典籍库存 = 储蓄；学者数 = 提现速度。玩家要在"存书"和"读书"之间选 |

### 2.3 印刷的里程碑（明线）

| 累计典籍产量 | 解锁 | 效果 |
|---|---|---|
| 5,000 | 铅锡锑合金 | 印刷速度 +20%，活字寿命↑ |
| 20,000 | 印坊分工 | 印书坊工位 +4 |
| 60,000 | **复利系数 +0.01** | k: 0.05 → 0.06 |
| 200,000 | 双人压印机 | 印刷产能 +50% |
| 600,000 | **复利系数 +0.01** | k: 0.07 → 0.08 |

> ⚠️ 里程碑门槛是**累计产量**，不是当前库存 —— 被读掉的典籍同样计入。否则"读书"会变成反优化。

## 3. 远航探索（新系统 · 新动词「探索」）

知识复利提供了**确定性**的指数曲线，但如果全程只有一个确定性引擎，整个时代会过于平稳。
**远航探索提供随机性与第二资源线**，并给玩家一个"离开书桌"的理由。

### 3.1 三环海图

| 环 | 名称 | 史实锚点 | 单次耗时 | 船队成本 |
|---|---|---|---|---|
| **第 1 环** | 近海航行 | 葡萄牙沿西非海岸推进，1434 年绕过博哈多尔角 | 60 s | 40 木材 + 20 铁 + 5 水手 |
| **第 2 环** | 远洋航线 | 哥伦布 1492-10-12 登陆巴哈马；达伽马 1498-05-20 抵达科泽科德 | 180 s | 120 木材 + 60 铁 + 50 白银 + 12 水手 |
| **第 3 环** | 环球航行 | 麦哲伦船队 1519–1522，Elcano 完成首次环球 | 480 s | 300 木材 + 150 铁 + 200 白银 + 25 水手 |

**航海进度** = 水手数 × 1.0/秒，累积到该环目标值即返航。

> **史实依据**：达伽马的往返航程是当时**已知最长的远洋航行**；麦哲伦出发 5 船、返航 1 船（Victoria），
> 265 人出发、18 人返回 —— **环球航行在数值上就应该贵得离谱**。

### 3.2 新大陆：一次性里程碑

首次完成第 2 环远航时，必定触发**「发现新大陆」**（不是随机事件，是保底里程碑 —— 保证每个玩家都能拿到第二资源线）：

| 奖励 | 数值 | 史实锚点 |
|---|---|---|
| 🌽 **异域物产** | +80 | 哥伦布大交换：玉米、马铃薯、番茄、烟草、木薯、辣椒 |
| 🪙 **白银** | +300 | 1545 年 Potosí（Cerro Rico）银矿发现，成为西班牙帝国主要银源 |
| 📚 **研究点** | +5,000 | 新世界的天文/地理观测数据回流 |
| **永久加成** | 食物 +15%、K 上限 +10% | 玉米与马铃薯在旧世界的推广 |

> ⚠️ **不做的部分**：不模拟殖民暴行、不模拟原住民人口崩溃。
> 规格书 2.3 禁止"强制剧情"，且把 80–95% 的原住民人口损失做成游戏奖励是**不可接受的**。
> 本作只保留"物种与资源交换"这一层，**以中性事件文本呈现，不给正反馈**。

### 3.3 事件表（第 2 环示例）

| 权重 | 事件 | 结果 |
|---|---|---|
| 18% | **发现新大陆** | 首次触发里程碑；此后改为「新的海岸线」+40 异域物产 |
| 15% | 抵达香料海岸 | 白银 +150，异域物产 +5（胡椒、肉桂） |
| 14% | 顺风 | 本次航海进度 +25% |
| 12% | 风暴 | 损失 30% 货舱，提前返航 |
| 10% | 原住民接触 | 异域物产 +8；小概率触发外交事件（换得研究点） |
| 8% | 船员病疫 | 水手群体损失 50%，提前返航 |
| 8% | 沉船 | 船队损失，返还 50% 白银 |
| 6% | 古代典籍 | 研究点 +500（阿拉伯/拜占庭典籍回流） |
| 5% | 海图残页 | 永久 +2% 远航成功率 |
| 3% | 黄金国传说 | ⚠️ **纯传说事件**（史实上不存在），仅给异域物产 +15 |
| 1% | 环球航线达成 | 永久 +5% 研究速度 |
| **100%** | | |

**期望值验算（第 2 环，单次）**：

```
成本 ≈ 120 木材 + 60 铁 + 50 白银 + 180 水手秒
期望白银收益 = 0.15×150 + 0.08×(−25) + 0.18×0 ≈ 22.5 − 2.0 = 20.5
期望异域物产 = 0.18×40 + 0.15×5 + 0.10×8 + 0.03×15 = 7.2 + 0.75 + 0.8 + 0.45 ≈ 9.2
```

→ **单次远航是净亏损的**（白银期望 +20.5 < 成本 50）。

**这是刻意的**：远航的回报在**里程碑与新作物**，不在单次跑船。
玩家如果为了白银去刷第 2 环，会稳定亏本 —— **逼他去推第 3 环，或者回去印书**。
随机性负责"要不要试一次"，经济学负责"试完就回去干活"。

### 3.4 异域物产：第二资源线的出口

🌽 异域物产不能在市场上直接卖钱，只能投入**「物种交换」**面板换取永久加成：

| 兑换项 | 消耗 | 效果 |
|---|---|---|
| 玉米栽培 | 60 | 食物 +30% |
| 马铃薯栽培 | 100 | K 基础上限 +150 |
| 番茄与辣椒 | 80 | 人口 r +8% |
| 烟草贸易 | 120 | 白银 +500（唯一可换钱的项） |
| 金鸡纳树皮 | 200 | 人口 r +12%（医学） |

> **设计意图**：异域物产是**永久加成货币**，与白银（可消耗资源）严格分开。
> 这防止玩家把远航变成"白银矿场"，从而保留"探索"作为**动词**而非"生产"作为动词。

## 4. 识字率与知识扩散（新系统）

印刷术的真正历史后果不是"书变多了"，而是**"会读书的人变多了"**。

> **史实依据**：印刷普及后，书籍价格**下降约五分之四**（Hallam 引 Chevillier）；
> 15 世纪末欧洲已有 **282 座城市**拥有印刷所，覆盖约 20 个现代国家、**18 种语言**。
> 方言印刷（vernacular）取代拉丁文，直接推动了成人识字率上升 ——
> 这是印刷术与识字率之间最硬的因果链。

### 4.1 识字率是独立状态值（本时代的核心仪表盘）

**识字率 0–100%**，是文明级统计量（**不追踪任何个体的读写能力**）。

```
识字率增长率 = 基础增长 × 印刷产能因子 × (1 − 识字率 / 识字率上限)

识字率上限 = 0.15 + 0.15 × 大学数（硬上限 0.95）
印刷产能因子 = 0.5 + 0.5 × min(1, 典籍产能 / 2.0)
```

逻辑斯蒂形式 —— 与人口模型同构，**保证本作全时代只有一种增长范式**。

| 项 | 值 |
|---|---|
| 基础增长 | 0.0008 / 秒（典籍产能充足时） |
| 起点 | 12% |
| 无大学时的上限 | 15%（**印刷不足以让全社会识字，必须有学校**） |
| 每座大学 | 上限 +15% |
| 教师岗位 | 额外 ×1.3 增长 |

**为什么识字率上限必须由大学决定**：如果印刷产能单独就能把识字率推到 100%，大学就成了纯粹的数值建筑。让**产能决定速度、大学决定上限**，两条线都有意义。

### 4.2 识字率的三处作用

| 作用 | 公式 | 效果区间 |
|---|---|---|
| **研究速度** | 识字率因子 = `0.70 + 0.60 × 识字率` | ×0.77（12%）→ ×1.27（95%） |
| **人口增长率 r** | 识字率因子 = `0.70 + 0.60 × 识字率` | 同上 |
| **远航成功率** | `+0.10 × 识字率` | +1.2% → +9.5% |

> **人口模型的接入方式（规格书 2.2 要求）**：
> 本时代不新增 r 的乘法因子之外的东西，只是把**识字率**加进 E5 的环境因子构成：
>
> ```
> r = 基础增长率 × 舒适度因子 × 识字率因子
> 舒适度因子   = 0.8 + 0.2 × 火源因子(E1 地基, 系数 ×0.20)   ← 火的"质"作用：无火则舒适度底线缺失
> 识字率因子   = 0.70 + 0.60 × 识字率                        ← E5 新增
> K = 基础上限 + Σ住所容量 + 新作物加成(P2/P3 永久项)
> ```
>
> **"识字率影响人口增长"不是牵强附会**：识字意味着能读懂农书、医书、卫生常识与契约，
> 在群体尺度上表现为更高的生存与组织效率。

## 5. 印刷术 — 人口 — 产出 的咬合

```
        📖 印刷术（核心 · 知识复利）
        │ 复利倍率 R(N) = 1 + k × N_eff     ← 有界乘数，上限 ×4.20
        │ 依赖：📚 典籍 供给（印刷产能 B）    ← 无界底数，受物理资源约束
        ▼
   🎓 研究速度 = B × R(N) × 识字率因子
        │ 解锁科技 → N↑ → R↑ ；解锁印刷科技 → B↑
        │ 解锁「世俗学校 / 大学自治」→ 识字率上限↑
        ▼
   👥 人口（引擎 · 逻辑斯蒂增长）
        │ 识字率因子 → 人口增长率 r ↑
        │ 人口 = 人力上限（造纸工 / 印刷工 / 学者 / 教师 / 水手）
        ▼
   📜 纸张 → 📚 典籍 → 🎓 研究          （印刷链）
   ⛵ 远航 → 🪙 白银 + 🌽 异域物产       （第二资源线）
             白银 → 建筑 / 加速
             异域物产 → 永久加成（食物 / K / r）
```

### 闭环描述

**主环（复利）**：
```
印刷产能 B ↑ → 典籍 ↑ → 研究速度 ↑ → N ↑ → 复利倍率 R ↑ → 研究速度 ↑↑
                     ↑                                              │
                     └──── 印刷科技解锁（水轮捣浆/压印机/分工）◄──────┘
```
→ 这是一个**双正反馈**：B 自己滚（产能滚产能），R 自己滚（知识滚知识），且两者相乘。

**副环（人口与识字）**：
```
识字率 ↑ → 研究速度 ↑ 且 人口 r ↑ → 人口 ↑ → 人力 ↑ → 造纸/印刷/学者 ↑ → 典籍 ↑ → ...
```

**探索环（资源与随机）**：
```
白银/异域物产 → 新作物 → K ↑ 与 食物 ↑ → 人口 ↑ → 人力 ↑
              → 白银 → 大学/印书坊 → 识字率上限 ↑ 与 B ↑
```
→ 探索环**没有正反馈**（远航单次净亏），只提供**一次性跃升与随机扰动**。

### 反向：卡住会卡在哪

| 症状 | 真实原因 | 玩家该怎么想 |
|---|---|---|
| 研究龟速 | B 太低（典籍产能不足） | "去盖印书坊 / 派木材工" |
| 典籍堆积，研究不涨 | 学者不够 / 大学不够 | "我印的书没人读" |
| 复利倍率涨得很慢 | N_eff 已进入递减段（>20 项） | "该转向纵深了，不是继续铺科技" |
| 人口不涨 | 识字率上限卡在 15%（没建大学） | "只印书是没用的" |
| 物资全线告负 | 正是"忍耐期" | 看红字提示，撑住 |

### 10.2 保留的"质"作用：知识的跨时代保留率

**这不是数值加成，是功能性的**：

```
若无印刷术（E5 核心）：
  新时代全部科技成本 ×1.25   ← 知识传不下来，每一代都要重新发现
  且复利倍率 R 直接失效（R(N) ≡ 1）

> **设计意图（规格书 1.3.3 要求）**：即使 k 衰减到 20%，玩家仍然**需要**印刷术 ——
> 因为砍掉它会让**所有**科技成本上涨 25%，并且**整个复利机制停机**。
> 玩家不会"懒得关掉"它，玩家**不敢关**。

### 11.3 人口（逻辑斯蒂增长，沿用 E1 模型）

```
人口增长速率 = r × P × (1 − P / K) × 食物因子

r = 基础增长率 × 舒适度因子 × 识字率因子
舒适度因子 = 0.8 + 0.2 × 火源因子(E1 地基，系数 ×0.20)
识字率因子 = 0.70 + 0.60 × 识字率
K = 基础上限 + Σ住所容量 + 新作物加成
```

| 项 | 值 |
|---|---|
| 基础增长率 r_base | **0.0012 / 秒** |
| 舒适度因子 | 0.80（火灭）→ 1.05（火旺） |
| 识字率因子 | 0.77（12%）→ 1.27（95%） |
| 起始 r | 0.0012 × 1.00 × 0.772 = **0.000926 / 秒** |
| 终局 r | 0.0012 × 1.05 × 1.24 = **0.001562 / 秒** |
| K 基础上限 | 300 |
| 每座住所 | K +60 |
| 新作物（马铃薯） | K +150 |
| 食物消耗 | 0.2 / 秒 / 人 |
| 研究基础产出 | 由学者决定（见 11.4） |

**增长率曲线示例**（E5 开局，K = 300）：

| 人口 P | 增长速率 | 阶段 |
|---|---|---|
| 120 | 0.062 /秒 | 起步 |
| 150 | 0.069 /秒 | **最快区间**（P ≈ K/2） |
| 240 | 0.045 /秒 | 接近上限，放缓 |
| 300 | 0 | 到达当前 K |

> 与 E1 完全同一个公式，**只是 r 的环境因子换成了"舒适度 + 识字率"**。
> E1 玩家学到的直觉（人口会自己加速、快到上限时自然刹车）在 E5 依然成立。

### 11.5 平衡验算（研究点收入 vs 科技成本）

**研究点收入预算**（按**验算基准周期** 16,200 秒分段核算，检验复利曲线形状；**实际时代时长不设目标**，配平迭代时以"比例与曲线形状"为准重新核算）：

|---|---|---|---|

| 210–270 min | 3,600 s | 1,050 | 3,780,000 |
| **合计** | **16,200 s** | | **≈ 6,537,600** |

**科技成本预算**（详见 11.7）：

| 层 | 数量 | 小计 |
|---|---|---|

**配平结论**：

```
总收入              ≈ 6,537,600
必点（核心+支撑+门槛） =    33,700 + 600 + 3,000,000 = 3,034,300
剩余可支配           = 6,537,600 − 3,034,300 = 3,503,300

→ 玩家可点完：核心 + 全部支撑 + 门槛 + 效率前段(12) + 效率中段(10) + 后段约 2/6
→ 无法点完全部效率科技，取舍成立 ✅
```

**取舍压力点**：后段 6 项（高价效率科技）是真正的选择题 —— 点「日心说」还是点「殖民据点」？
因为**远航线**和**科学线**在后期争夺同一笔预算，而两条线提供的"质"完全不同。

## 12. 节奏曲线（不设时长目标）

> **设计原则**：本代要玩多久由跃迁条件与复利曲线的拐点自然决定，**不做人工时长规划**。下表按**体验阶段**给出节奏参考。

| 阶段 | 玩家在做什么 | 人口 | 已解锁 N / 复利倍率 |
|---|---|---|---|
| **教学期** | 靠 E4 遗产积累木材与铁；研究「造纸术」；第一次看到复利面板写着 ×1.00 | 120 → 165 | 0 → 1 / ×1.05 |
| **第一次投入** | 建造纸坊与印书坊；派第一批造纸工与印刷工；**物资净增长开始转负** | 165 → 215 | 1 → 6 / ×1.25 → ×1.36 |
| **忍耐期** | 印刷链吃掉 37% 人力；红字提示"知识投资期"；靠「银行与信贷」贷款续命 | 215 → 285 | 6 → 13 / ×1.36 → ×1.62 |
| **拐点 + 首次远航** | 白银凑够 → 出海 → 发现新大陆 → 异域物产 → K 与食物跃升；研究速度明显加快 | 285 → 420 | 13 → 21 / ×1.62 → ×2.05 |
| **爆发期** | B 与 R 同时高增；解锁速度肉眼可见地加快；识字率破 60%；第 3 环环球航行 | 420 → 640 | 21 → 30 / ×2.05 → ×3.00 |
| **收束** | 冲刺「蒸汽机」（3,000,000 研究点）；补足跃迁条件 | 640 → 780 | 30 → 35 / ×3.00 → ×3.50 |

**体验曲线设计**：

- **教学**：学会"木材 → 纸张 → 典籍"的链条，看到复利面板但感受不到它
- **第一次投入**：印刷链启动，物资开始负增长，玩家开始怀疑
- **核心矛盾的高潮（忍耐期）**：红字提示是唯一的心理支持。这一段**必须让人不舒服**
- **第一次反转**：远航带回白银与新大陆，同时复利倍率过 ×2.0，玩家**第一次感到"雪球在滚"**
- **爆发**：科技被快速扫空，识字率飙升，人口和产出一起起飞
- **收束**：冲刺门槛科技，为 E6 的能量时代铺垫

> **关键节奏判断**：忍耐期**必须占约 1/3 的时代周期**（按比例，不设绝对时长）。
> 如果忍耐期太短，"前期忍耐换后期爆发"就变成了一句空话；
> 如果太长，玩家在见到回报之前就流失了。比例是这两者之间的平衡点（待实测验证）。

## 14. 与 E6 的衔接

跃迁到 E6 机器时代时：

| 变化 | 说明 |
|---|---|
| **复利机制停机** | N 归零，复利倍率重置为 ×1.00。印刷术转为地基期，k × 0.6 |
| **核心科技换成蒸汽机** | 优化目标从"怎么让研究滚雪球"变成"怎么把煤转成生产力" |
| **新动词更换** | 「研究」保留但降权；「探索」转为「运输/铁路铺设」的雏形 |
| **典籍转为投入品** | 从"研究的燃料"变为"工业技术文献"，继续被消耗 |
| **识字率转被动** | 不再需要主动管理，成为人口 r 的背景因子 |
| **异域物产面板折叠** | 已兑换的永久加成沉入「文明遗产」列表 |
| **印刷面板降级** | 从主面板移到"基础设施"折叠区（规格书 3.1 方案：**界面降级**） |

**交接提示（弹窗文案）**：

> 印刷术不再推动研究了 —— 从今往后，推动文明的是**能量**。
> 但印刷术仍在运转：它保证知识的跨时代保留率（没有它，所有新科技成本 +25%）。
> **你不会关掉它，你只是不再盯着它。**

> **设计意图**：让玩家理解"旧核心没被废弃，只是降级"。
> 与 E1 → E2 时"火种不再需要维护，但仍是人口的基础"完全同构 ——
> **每次跃迁都用同一句话安慰玩家，让他逐渐学会：在这个游戏里，没有东西会真的消失。**
