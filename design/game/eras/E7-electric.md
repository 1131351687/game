# E7 · 电气时代（第二次工业革命 / 约 1870–1945）

> 人类第一次让"能量"脱离了具体的煤堆、水轮与蒸汽机——它变成一种**在铜线里流动、不能囤积、必须实时相等**的东西。当电成为文明的血液，玩家面对的不再是"怎么多产"，而是"怎么让供与求永远贴在一起呼吸"。

## ⚡ 核心科技：电力网

| 维度 | 内容 |
|---|---|
| **发展方式** | **系统调度型** —— 把分散的产能点、消费者与运输线拧成一张实时呼应的网；玩家不再"生产"，而是"**调度**"——让供给始终贴着负荷走 |
| **核心矛盾** | **规模化的三道天花板**：① 电不能囤，发电必须实时等于用电；② 人口上限从土地解放，却带来污染代价；③ 产出爆发式增长，撞上需求侧瓶颈 |
| **新动词** | **调度**（实时平衡电网）· **量产**（标准化复制）· **机动**（内燃机调动人货） |
| **门槛科技（→ E8 计算机）** | **计算机** —— 当电网、化工厂、流水线一齐运转而人管不过来时，把"调度"外包给机器 |

> **为什么核心科技是"电力网"而不是"电"**：电本身在 E6 已经出现（发电厂、发电机）。E7 真正新增的，是**把电组织成一张网**——中央电站统一发电、输电网统一配送、消费者随时"接负荷"。这一"网"的形态，才是第二次工业革命区别于 E6 单机能量转换的本质。所以 E7 的核心动词是**调度**，不是 E6 的**转换**。

> **继承自 E6（电网从原型升级为主干）**
> E6 §3 已经有一个朴素的 ρ 判定（发电 vs 工厂）。E7 把它**升级为全文明主干系统**：消费者从"工厂"扩展为化工厂、装配线、炼油厂、住宅、百货公司——每一座新建筑都是一道新负荷，玩家每接一个就得重新平衡一次。这是"跃迁只新增不重置"铁律的体现：E6 建好的电网**原样带过河**，只是角色从"配角"变成"主引擎"。

### 「刻度」行（每代文档头部固定）

```
材料：合金钢 / 合成材料　　能源：电（二次能源）　　信息：电话 · 广播 · 时刻表式调度
```

> **刻度含义（为什么是这三项）**：E7 的"材料"从 E6 的熟铁/钢跃升到**合金钢与合成材料**（贝塞麦钢之上再进化，化工给出塑料）；"能源"第一次出现**二次能源**——电不是一次能源，它必须由煤/水/油转换而来，这决定了"电不能囤"的物理本质；"信息"从 E6 的印刷复利，变为**实时调度信息**（电话指挥、广播宣发、铁路时刻表式排程），为 E8 的"计算·联网"埋下种子。

## 1. 电网实时平衡（核心机制 · 本代最值钱的部分）

**这是 E7 相对 E6 最根本的新约束**：电是**流量**而非**存量**——它**不能囤积**（区别于 E6 的煤可以堆在矿场）。发电与用电必须在**每一瞬间**相等，否则要么不够用、要么白浪费。

```
供给 G = Σ(发电厂 × 单机产能) × η_输电
负荷 D = Σ(各耗电建筑 × 额定功率) + Σ(住宅 × 生活用电) + 人口 × 生活用电

实时平衡率 ρ = G / D
```

#### 1.1 ρ 判定表（核心规则）

| 实时平衡率 ρ | 状态 | 后果 | UI 表现 |
|---|---|---|---|
| **ρ ≥ 1.1** | **宽裕** | 正常运转，可继续接新负荷 | 绿色，有冗余余量 |
| **1.0 ≤ ρ < 1.1** | **刚好** | 正常，但无冗余；再接负荷即跌破 | 黄色，提示"余量不足" |
| **ρ < 1.0** | **限电降速** | 所有耗电单元产出 × ρ（全城连锁降速） | 橙色，全网条闪烁 |
| **ρ < 0.6** | **区域限电** | 追加：城市不满 +1 级，人口增长率 r ×0.85 | 橙红，屏幕边缘暗角 |
| **ρ < 0.3** | **电网崩溃** | 产出 ×0.3；蒸汽冗余（E6 遗产）接管基础运转 | 红色，全屏告警 |

> **为什么用"全城降速"而不是"选择性断电"**：真实电网无法精细到"只给某台机器断电"。降速是一个**连续、平滑、可感知**的惩罚——玩家会看到产出数字缓慢下滑，从而立刻去查电网面板，而不是突然暴死。这与 E6 §3.1 的处理一脉相承，但 E7 把它推到了文明级规模。

#### 1.2 电"不能囤"是本代的新动词土壤

| 对比 | E6 煤 | E7 电 |
|---|---|---|
| 形态 | 存量（可堆在矿场，上限 20,000） | **流量（不可囤，瞬时平衡）** |
| 玩家策略 | 旺季多挖、淡季囤着缓冲 | **必须持续预测负荷、即时调度** |
| 新动词 | 能量转换 | **调度（让供贴着求走）** |

> **设计意图**：E6 玩家靠"囤积"平滑了波动；E7 抽掉了这个缓冲垫。抽掉之后，玩家被迫养成"**每接一个新负荷，先算一遍 ρ**"的习惯——这就是"调度"这个动词被刻进肌肉记忆的方式。它不是数值放大，而是**操作模式的改变**（铁律①）。

#### 1.3 输电技术链（继承并扩展 E6 的电流之战）

| 科技 | 年代锚点 | η_输电 | 覆盖范围 | 史实依据 |
|---|---|---|---|---|
| **交流输电** | **1886**，Westinghouse 引入变压器交流系统 | **88%** | 跨区（≤5 km） | 交流"used transformers to step down from a high voltage" |
| **高压交流输电** | 1890s，"电流之战"之后 | **94%** | 无距离限制，全域 | "high voltage allowed an AC system to transmit power over longer distances" |
| **电网调度自动化** | 20 世纪初（负荷预测雏形） | 输电损耗 **−10%** | 全域 + 余量缓冲 | 中央调度所（load dispatch center）出现 |

#### 1.4 输电网 / 变电站（新建筑角色）

E7 把"输电"从科技效果**物化为建筑**：每座**变电站**把发电厂的电"落地"到一片区域；区域间若未联通，则**各自独立算 ρ**——玩家可能一边限电、一边邻区浪费。这制造了"先建电站还是先联网"的取舍。

```
ρ_区域 = G_区域 / D_区域
未联网区域：各自为政，可能一区宽裕、一区崩溃
联网后：全域统一 ρ，但输电损耗随距离上升
```

> **为什么物化变电站**：E6 的输电只是效率系数，玩家感受不到"网"。E7 用"区域独立 ρ"把"网"变成可见、可规划的实体，让"调度"从抽象数字变成空间决策。

## 2. 化学合成（哈伯-博世 1913 · 化肥 → 人口爆炸）

**第二个核心矛盾**：化肥把"人口上限"从**土地**约束里解放出来 → **人口爆炸**（1900 年约 16 亿 → 2000 年约 60 亿，约 3.75 倍）。但它同时带来**污染**代价。

#### 2.1 机制链：化肥 → 粮食上限 → K

```
合成氨产量 N_fert = Σ(化工厂 × 催化等级系数)
粮食上限加成 F_cap = 基础上限 × (1 + 0.4 × ln(1 + N_fert / 10))      ← 边际递减（地力有限）
K = K_基础(继承 E6) + Σ住宅容量 + F_cap对人口承载的贡献
```

| 化工厂数 | N_fert（催化 I） | 粮食上限加成 | K 较 E6 末态（4,000） | 对标史实 |
|---|---|---|---|---|
| 0 | 0 | ×1.00 | 4,000 | 前工业化后期 |
| 3 | 6 | ×1.22 | 4,880 | ~1900 年（16 亿） |
| 6 | 12 | ×1.39 | 5,560 | ~1920s |
| 12 | 24 | ×1.60 | 6,400 | ~1950 年（25 亿） |
| 24 | 48 | ×1.83 | 7,320 | ~1960s |

> **为什么用 ln 而非线性**：化肥的收益遵循**边际递减**——第一吨肥救活瘦地，第一百吨肥只能榨出一点。ln 让"建到 24 座厂"的 K 约是"建到 6 座"的 1.3 倍而非 4 倍，逼迫玩家在"继续堆化工厂"和"用别的手段（住宅、卫生）抬 K"之间权衡。史实上 20 世纪人口从 16 亿涨到 60 亿是**数十年累积**，ln 的缓坡正对应这种"持续但放缓"的曲线；游戏内 K 从 4,000 抬到约 7,300+（再加住宅可破万），**约 3 倍跃升**，与史实 3.75 倍同量级——这是"人口上限从土地解放"在玩法里的直接翻译。

#### 2.2 污染的代价（机制化）

化工厂、炼油厂在产出的同时**持续累积污染**：

```
污染累积速率 = Σ(化工厂 × 0.010/秒) + Σ(炼油厂 × 0.015/秒) − 治理速率
治理速率 = 卫生设施等级 × 3 + 绿化
卫生因子 = 1 − 污染 / 250        ← 直接压低人口增长率 r（沿用 E6 §4.3）
```

| 污染值 Pol | 卫生因子 | 对 r 的影响 |
|---|---|---|
| 0 | 1.00 | 无 |
| 40 | 0.84 | r ×0.84 |
| 70 | 0.72 | r ×0.72 |
| 100 | 0.60 | r ×0.60 |

> **设计意图**：化肥解放了 K，却用卫生因子反噬 r。于是"人口爆炸"不是纯爽点——玩家必须在**多建化工厂抬 K** 与 **控污染保 r** 之间走钢丝。这与 E6"城市化双刃"同构，但代价来源从"拥挤"变成了"化工污染"，是新矛盾而不是换皮。

## 3. 流水线量产（1913 福特 · 标准化与需求侧瓶颈）

**第三个核心矛盾**：标准化使**单件成本随产量下降**，但产出爆发后撞上**需求侧瓶颈**（需要消费社会）。

#### 3.1 量产机制

```
单线产能 = 4 工业品/秒 × 规模系数
规模系数 = 1 + 0.15 × ln(1 + 总装配线数)        ← 标准化带来的规模经济
单件有效成本 = 基础成本 / (1 + 0.20 × ln(1 + 累计产量))   ← 学习曲线，越产越便宜
```

| 装配线数 | 规模系数 | 单线产出（工业品/秒） |
|---|---|---|
| 1 | ×1.00 | 4.0 |
| 5 | ×1.24 | 4.96 |
| 10 | ×1.40 | 5.60 |
| 20 | ×1.60 | 6.40 |

#### 3.2 需求侧瓶颈（新动词"创造需求"）

产出若超过需求，则**滞销**——工业品堆在仓库却变不成推进文明的资源：

```
有效产出 = 装配线总产出 × min(1, 需求 / 产出)
需求 = 基础需求 + Σ(百货公司 × 等级) + 广告所效果 + 消费信贷加成
```

| 需求侧建设 | 对需求的作用 |
|---|---|
| **百货公司** | 需求 +300/座（集中消费场景） |
| **广告所** | 全域需求 ×(1 + 0.10 × 等级)（创造欲望） |
| **消费信贷** | 需求上限 +25%（预支未来消费） |
| **公路与汽车** | 让商品抵达消费者（否则需求"够但送不到"） |

> **为什么必须有"需求侧"**：史实上福特 T 型车降价到工人买得起，才引爆大众消费——**没有消费社会，流水线只是把仓库填满**。玩家会卡在"产出爆了但停滞"的诡异状态，然后发现答案不是"再建一条线"，而是"建百货公司、打广告"。这是 E7 独有的**反向瓶颈**：供给自己成了问题，需要去拉动需求。

#### 3.3 机动化（内燃机 → 公路与汽车）

内燃机把"能量"装进可移动载体，第一次让**人和货脱离铁轨自由移动**：

```
公路覆盖率 = f(公路与汽车建筑数)
机动效率 = 1 + 0.10 × 公路覆盖率      ← 影响工业品→建造的送达速度、需求的触达
```

> **机动化的"质"作用**：它为 E8 的"管不过来的规模"做铺垫——当文明铺到公路能到的每个角落，单靠人力分配岗位已不可能，自动化（E8）成为必然。

## 4. 电力网 — 人口 — 产出 的咬合

```
        ⚡ 电力网（核心 · 实时调度引擎）
        │ 供必须等于求（ρ 判定）
        │ 电不能囤 → 玩家持续"调度"
        ▼
   🏭 化工厂 / 装配线 / 炼油厂（负荷，也是产出）
        │ 化肥 → 粮食上限 → K（人口爆炸）
        │ 装配线 → 工业品（规模经济）
        │ 化工/炼油 → 污染（反噬 r）
        ▼
   👥 人口（引擎 · 逻辑斯蒂增长）
        │ 人口 = 人力上限 = 研究速率基数
        │ 人口 = 用电负荷（生活用电随人口涨 → 推高 D → 压低 ρ）
        ▼
   回到 ⚡：更多人口 → 更多工人进厂 → 更多负荷 → 必须更多发电
```

**正向闭环**：电网稳定（ρ≥1.1）→ 化工厂/装配线满速 → 化肥抬 K + 工业品暴涨 → 人口爆炸 → 人力充沛 → 更多发电与建造 → 电网扩容。

**负向螺旋（本代死亡方式）**：忽视平衡 → 接负荷过猛 → ρ<1 → 全城降速 → 化工厂产出 ×ρ → 化肥不足 → K 被粮食上限卡住 → 人口停滞 → 工人短缺 → 发电岗缺人 → 发电更少 → ρ 更低。

> **与前代的区别**：E6 的螺旋入口是"煤荒/环境"，E7 的入口是"**你自己贪心接了太多负荷**"。失败叙事从"自然报复"变成了"**规模失控**"——这正是第二次工业革命的主题：文明第一次大到能**自己绊倒自己**。

### 11.3 平衡验算

**验算 A：第一次限电危机（接新负荷后 ρ 跌破 1）**

设定：承接 E6 的 16 座发电厂（高压交流 η94%）+ 既有 15 工厂（150 kW 沿用 E6 口径）已达标；现玩家新建 4 座化工厂 + 2 座装配线。

```
① 发电 G = 16 × 250 × 0.94 = 3,760 kW
② 既有负荷 = 15×150 + 3,600×0.012 = 2,250 + 43 = 2,293 kW
③ 新接负荷 = 4×220(化工厂) + 2×180(装配线) = 880 + 360 = 1,240 kW
④ 总负荷 D = 2,293 + 1,240 = 3,533 kW
⑤ ρ = 3,760 / 3,533 = 1.064  → 宽裕边缘
⑥ 再建 2 座化工厂 → D +440 = 3,973 > G → ρ = 0.947 < 1.0 → 限电降速！
```

→ **玩家接第 5–6 座化工厂时 ρ 跌破 1.0，全城降速**——这正是"第一次限电危机"的机制触发点。解法：再建 2 座发电厂（+470 kW×0.94≈+442）→ G=4,644，ρ 回到 1.17 ✅

**验算 B：化肥 → K 人口爆炸**

设定：化工厂 12 座，催化 I（2/秒），N_fert=24

```
粮食上限加成 = 1 + 0.4 × ln(1 + 24/10) = 1 + 0.4 × ln(3.4) = 1 + 0.4 × 1.224 = 1.490
K（仅化肥贡献增量）≈ 基础上限 × 0.49 ≈ +1,960
加 16 座住宅(×200=3,200) → K ≈ 4,000 + 1,960 + 3,200 ≈ 9,160
```

→ K 从 4,000 抬到约 9,160（**约 2.3 倍**），配合住宅可破万，人口爆炸在玩法内成立 ✅

**验算 C：流水线产出 vs 需求（滞销瓶颈）**

设定：装配线 10 座，规模系数 1.40 → 总产出 = 10×4×1.40 = 56 工业品/秒

```
无需求侧建设：需求 = 基础 20 → 有效产出 = 56 × min(1, 20/56) = 20（仅 36% 生效）
建 3 座百货公司：需求 = 20 + 3×300 = 920 → 远超产出，有效产出 = 56（满效）
```

→ **不建消费社会时 64% 产出被浪费**；建 3 座百货公司即可释放全部产能。需求侧是新瓶颈 ✅

| 阶段 | 玩家在做什么 | 人口 | 电网状态（ρ） |
|---|---|---|---|
| **教学** | 研究「中央电站」「电力网」；把 E6 遗留电网升级为全文明主干；第一次看到 ρ 仪表盘与"电不能囤" | 3,600 → 4,500 | ρ ≈ 0.95 刚好（无冗余） |
| **第一次限电危机** | 接上新负荷（化工厂/装配线）后 ρ 跌破 1.0，全城降速；狂建发电厂、升高压交流输电 | 4,500 → 6,000 | ρ < 1.0 限电降速 → 回升至 1.1 |
| **化工与人口爆炸** | 哈伯-博世法 → 化肥 → 粮食上限↑ → K 跳升；人口暴涨；污染读数同步攀升 | 6,000 → 10,000 | ρ 回升至 1.1 宽裕 |
| **需求侧瓶颈** | 装配线产出爆发却滞销；建百货公司/广告所/消费信贷，创造消费社会 | 10,000 → 12,000 | ρ ≥ 1.05 稳定 |
| **收束** | 冲刺「计算机」；内燃机+流水线+电网三者汇流，为 E8 信息时代埋线 | 12,000 → 12,500 | ρ ≥ 1.05 稳定 |

**体验曲线设计**：

- **教学**：学会"调度"这一套全新语言（供必须等于求，电不能囤）
- **第一次危机（限电）**：ρ 像 E1 的火种一样跳动，但这次是"规模失控"而非"自然报复"
- **人口爆炸**：化肥抬 K，数字第一次跳变——本代最爽的时刻，但污染同步抬头
- **需求侧瓶颈**：产出爆了却停滞的诡异状态，逼玩家去"创造需求"而非"再建产线"
- **收束**：门槛科技可见，三分支汇流，时代交棒的叙事高潮

## 13. UI 要点

| 元素 | 设计 |
|---|---|
| **电网仪表盘（标志性 UI）** | 屏幕中央一条**发电/用电双曲线**：上方 G 曲线、下方 D 曲线，两线重合时ρ=1；D 越过 G 的瞬间整屏泛橙。**ρ 数字实时跳动**（缺电时跳变而非平滑） |
| **实时平衡率 ρ 大表** | 顶部大号显示 `ρ 1.07 / 宽裕`，配色（绿/黄/橙/红）；ρ<1 时全屏边缘暗角 |
| **区域 ρ 小图** | 地图按变电站划分区域，每区独立显示 ρ；未联网区一绿一红对比，刺激玩家去联网 |
| **人口爆炸曲线** | 右侧纵轴人口、横轴（阶段/时间），化肥上线后曲线陡升；叠加 K 上限虚线，显示"离天花板还有多远" |
| **污染读数** | 底部常驻污染条 0–100，化工厂/炼油厂图标旁冒"污染粒子"；超标时变红并提示"卫生因子 −X%" |
| **需求 vs 产出对照** | 装配线面板显示 `产出 56 / 需求 20 ⚠ 滞销 64%`，明确告诉玩家"不是产得少，是卖不掉" |
| **瓶颈指示器** | 顶部一行：`⚠️ 当前瓶颈：电网 ρ<1（限电降速）` 或 `需求不足（滞销）`，并给可点击建议 |
| **化肥 → K 链路悬浮** | 悬停 K 数字：`K 9,160 = 基础4,000 + 化肥+1,960 + 住宅+3,200`——落实"数字可解释"铁律 |
| **三分支进度环** | 底部常驻"迈向信息时代"进度：显示计算机的前置三分支达标度 |

> **与前代 UI 的区别**：E6 的视觉中心是"能量链流水图"（煤→蒸汽→机械能）；E7 的视觉中心变成"**两条曲线是否重合**"——从"看转化效率"转为"看实时平衡"。这是动词从"转换"变为"调度"的 UI 映射。

## 14. 与 E8 的衔接

跃迁到 E8 信息时代时：

| 交棒内容 | 在 E8 中的作用 |
|---|---|
| **实时供电基线** | E8 的算力中心必须挂在稳定电网上；E7 练出的"调度"手感直接用于管理 E8 的电力-算力链（E8 三重依赖链第一道闸门） |
| **电网系统保留并扩展** | 变电站、发电厂原样带过河，扩展为算力供电基础；ρ 规则永久保留 |
| **化肥/人口模型** | 逻辑斯蒂增长 + 粮食上限机制完整继承；E8 在更大规模上再次改写 K 与 r |
| **石油 / 内燃机** | 降权为机动化基线（×0.60），但仍是物流与移动的前提 |
| **流水线 / 标准化** | 这是**自动化的雏形**——E8 把"标准化复制"升级为"把微观操作外包给机器"；E7 的量产经验是 E8 自动化的前夜 |
| **污染机制转化** | E7 的"污染 → 卫生因子"转为 E8 的"环境压力/碳排放"，仍是 r 的负项 |
| **计算机 → 算力** | 门槛科技直接成为 E8 核心科技 |

**交接提示文案**：

> *"你终于让供与求永远贴在一起呼吸。但当电网、化工厂、流水线一齐轰鸣，你会发现——**人已经管不过来了**。*\
> *下一台机器不再烧煤，它烧的是'算力'；它要的不再是你的手，而是你的决策。*\
> *电力网不会消失，它退到地下，继续为一切供电。而你，终于可以抬头看向信息本身。"*

**一条明确留给 E8 的钩子**：E7 的「计算机」研究完成后，描述文字只有一行：
*"它能算，但还不知道算什么。等文明大到人管不过来，它才有用。"*
—— 这正是"门槛科技 = 下一代核心科技"原则的**情感版**：玩家带着"为什么现在就要计算机"的疑问离开电气时代，进入 E8 才恍然——**那是为'管不过来的规模'准备的答案**。
