# E3 · 城邦时代（青铜时代）

> 文字让知识可以累积 —— 第一次，前人的发现能被后人接住；而青铜需要铜和锡，它们往往不长在同一块土地上。

## ✍️ 核心科技：书写

> **2026-09-12 修订**：本代核心科技由「文字」表述为「**书写**」，并明确本代有**三个并列支点**——
> 书写（信息轴）、青铜（材料轴）、轮子（交通轴）。三者同属通用目的技术，
> 共同把人类从"村落自给"推向"城市与交换"（依据：通用技术史 GPT 清单）。

| 维度 | 内容 |
|---|---|
| **本代三大支点** | ✍️ **书写**（信息）· 🔨 **青铜**（材料）· 🛞 **轮子**（交通） |
| **刻度** | 材料：青铜 ｜ 能源：人力 · 畜力 ｜ 信息：泥板书写 · 账簿 |
| **发展方式** | **记录交换型** —— 知识可累积（泥板），物资可交换（商路） |
| **核心矛盾** | 记录与计算需要人力（书吏），但这些人**不直接产出物资** —— 每多一个书吏，就少一个农夫、矿工或冶炼工 |
| **门槛科技** | 🔨 **钢铁**（推开 E4） |

**史实锚点**：楔形文字是已知最早的书写系统，最初用于书写苏美尔语；书写最早出现于**乌鲁克（Uruk）**，时在**公元前 4 千纪末**（约 3200 BCE，学界常引"晚乌鲁克期 Uruk IV–III，c. 3500–3000 BCE"）。[来源](https://en.wikipedia.org/wiki/Cuneiform)

**三个支点之间的关系**：三者不是并列的三个系统，而是**一条因果链**——
> 铜与锡**产地分离** → 必须长途贸易 → 必须记账与契约 → 必须**书写**；
> 而贸易要靠**轮子**把货物运出去，靠**青铜**把工具与武器升级。

所以玩法上：**书写**是引擎（它决定了记录容量这个硬上限），**青铜**是产出（贵且需要进口锡），
**轮子**是通道（决定运力与运输半径）。三者缺一，城市就退化成村庄。

### 1. 泥板与书吏（记录容量 —— 核心矛盾的机制化）

> **史实依据**：楔形文字并非凭空诞生，它脱胎于新石器时代的**黏土筹码（clay tokens）** —— 人们用筹码记录牲畜与货物的数量，先压印在黏土球（bulla）上，后来演变为刻写的泥板。[来源](https://en.wikipedia.org/wiki/Cuneiform)

#### 1.1 记录容量（独立仪表盘，0–N）

**记录容量不是资源，是一个槽位上限** —— 与 E1 的"火种仪表盘"地位对等。

| 项 | 值 |
|---|---|
| 基础容量 | **3**（E2 遗留的记账泥板） |
| 每座 🏛️ **学宫**（é.dub.ba，"泥板屋"） | **+5** |
| 每项科技占用 | **1 槽** |

#### 1.2 刻录状态：一项科技有两种生命

| 状态 | 本代效果 | 跨时代 |
|---|---|---|
| **口头**（刚解锁，未刻录） | **×50%** | ❌ **不进入档案库，E4 起失效** |
| **已刻录**（泥板已刻，槽位已占） | **×100%** | ✅ 进入**档案库** |

**刻录条件**：① 有 1 个空闲槽位；② 支付该科技知识成本的 **10%** 作为誊录开销；③ 城邦内至少有 1 名书吏。

**刻录不可撤销，槽位永久占用。**

> **为什么这样设计**：这是本时代最核心的决策。泥板槽位有限，你研究出的科技远多于能刻下的。**"哪些知识值得传给下一代"** 变成玩家的真实选择 —— 不刻录的科技在 E4 会彻底消失。并且刻录成本与科技大小挂钩，**大科技挤占小科技的位置**，取舍有牙齿。

#### 1.3 书吏（核心矛盾的人格化）

书吏是本代核心岗位，它做**三件事**，全部消耗同一批人：

| 职能 | 说明 |
|---|---|
| **编录** | 产出「知识」（研究货币） |
| **记账** | 维持贸易路线（每条活跃路线需 **40 名书吏**） |
| **誊刻** | 刻录取前置条件（1 名即可，不消耗额外人力） |

**书吏不产食物、不产铜锡、不产青铜、不产木材。** 这就是核心矛盾的全部。

> **史实依据**：Early Dynastic 苏美尔（c. 2900–2300 BCE）时期，"计量与数学尚不可分，同属一门书吏技艺"；乌鲁克 IV–III 期的原始楔形文字中并存 **12 套计数系统**，用于分别计量奴隶、牲畜、谷物、田地、啤酒等。[来源](https://en.wikipedia.org/wiki/Ancient_Mesopotamian_units_of_measurement)
>
> 这说明**书吏是一个庞大的、专业化的、脱离直接生产的社会阶层** —— 本作的岗位设计直接对应这一史实。

### 2. 贸易路线（资源产地分离 → 必须贸易）

> **这是本代的第一条新线，也是"青铜"两个字的史实驱动力。**

#### 2.1 史实驱动力：锡比铜稀有约 35 倍

| 金属 | 地壳丰度 | 说明 |
|---|---|---|
| 铁 | 50,000 ppm | |
| **铜** | **70 ppm** | 相对常见 |
| **锡** | **2 ppm** | **约为铜的 1/35** |
| 银 | 0.1 ppm | |
| 金 | 0.005 ppm | |

> 原文："Tin is a relatively rare element in the Earth's crust, with about two parts per million (ppm), compared to iron with 50,000 ppm, copper with 70 ppm... **Ancient sources of tin were therefore rare, and the metal usually had to be traded over very long distances to meet demand in areas that lacked tin deposits.**"
> [来源](https://en.wikipedia.org/wiki/Tin_sources_and_trade_during_antiquity)

古代已知锡源极为集中：**阿富汗、英国康沃尔与德文、法国布列塔尼、德国–捷克边境（厄尔士山脉）、伊比利亚、意大利、中国云南至马来半岛的东南锡矿带** —— 彼此相隔数千公里。

> 青铜时代百科原文："In many areas bronze continued to be rare and expensive, **mainly because of difficulties in obtaining enough tin**, which occurs in relatively few places, unlike the very common copper."
> [来源](https://en.wikipedia.org/wiki/Bronze_Age)

#### 2.2 机制：本地矿藏决定你的文明形态

开局（或由 E2 的选址继承）玩家获得一种**本地矿藏**：

| 本地矿藏 | 铜自给 | 锡自给 | 玩法基调 |
|---|---|---|---|
| **铜矿带**（如山麓、阿曼方向） | ✅ 富余，可出口 | ❌ 零 | 卖铜买锡，早期有钱 |
| **锡矿带**（罕见，如阿富汗方向） | ❌ 零 | ✅ 少量 | 卖锡买铜，货真价实的稀有 |
| **冲积平原**（**苏美尔核心区**） | ❌ 零 | ❌ 零 | **两样全靠进口**，最难的起点 |

> ⚠️ **史实说明**：美索不达米亚南部冲积平原**本身几乎没有任何金属矿藏**，铜、锡、石头、木材全部依赖进口 —— 这正是"贸易文明"在苏美尔诞生的物质原因。
> ⚠️ **争议**：青铜时代近东的锡究竟来自何处（阿富汗、伊朗东部、中亚、还是康沃尔）学界仍有争论，本作采用"多源、远距离"的模糊设定以规避争议。

**设计意图**：因为铜与锡**极少同地共生**，玩家在自己领土内**永远无法闭环**。这不是难度调节，是史实强制的设计约束。

#### 2.3 贸易路线（虚拟邻邦）

地图上有 **4–6 个虚拟邻邦城邦**，每个拥有：

| 属性 | 说明 |
|---|---|
| **产出** | 铜 / 锡 / 食物 / 木材 / **青金石** |
| **需求** | 它要什么（这决定你拿什么去换） |
| **距离** | 1（近）/ 2（中）/ 3（远）—— 距离决定运费与断线风险 |
| **基准价与波动率** | 见 2.4 |

**建立路线**：消耗商人运力 + **40 名书吏** + 1 个商栈槽位。

**结算**：每 **30 秒**一个"商队周期"，以物易物：

```
获得量 B = 支付量 A × (A 的当期单价 / B 的当期单价) × 路线效率 × 周期波动
路线效率 = 0.3（断账）或 1.0（记账正常），书吏不足时线性下滑
```

#### 2.4 价格浮动（本代的价格模型）

```
某货物当期单价 = 基准价 × 距离系数 × 需求冲击 × 随机波动

距离系数 = 1 + 0.15 × 距离          ← 远距离运费（史实：锡必须长途运输）
需求冲击 = 1 + 0.15 × (近 5 周期累计买入 / 该邦基准供应量)   ← 你买得越猛，越贵
随机波动 = 0.8 – 1.2，每 30 秒刷新
```

**基准价表**：

| 货物 | 基准价 | 说明 |
|---|---|---|
| 食物 | 1 | 通货基准 |
| 木材 | 2 | |
| 石头 | 3 | 苏美尔缺石，**进口品** |
| 铜 | 12 | 相对充裕 |
| **锡** | **150** | **全表最贵的常规货物** —— 稀有性直接体现为价格 |
| 青铜 | 30 | 冶炼加价（原料 16.8 → 成品 30） |
| 青金石 | 200 | 极高价值 / 极低体积，单位运力利润最高 |

> **史实依据（青金石）**：青金石早在公元前 7 千纪即开采于**阿富汗巴达赫尚省 Sar-i Sang 矿**，经约 **1,500 英里**（约 2,400 km）运抵美索不达米亚，约 **c. 4900–4000 BCE（晚乌拜德期）** 已见于 Tepe Gawra；乌尔王陵（Royal Cemetery of Ur）大量出土青金石镶嵌物，图坦卡蒙黄金面具亦用之。[来源](https://en.wikipedia.org/wiki/Lapis_lazuli)
>
> 这是**史实上最早、最长距离的奢侈品贸易链之一** —— 本作把它做成"高价值低体积"的贸易品类，用来惩罚"只会用粮食换锡"的单一路线策略。

#### 2.5 度量衡与换算损耗（贸易的前置）

**未研究「度量衡」时**：每条路线有 **15% 换算损耗** —— 因为"每个城邦、每个贸易行会都有自己的标准"。

> **史实依据**：美索不达米亚计量标准起源于**早期王朝时期松散的城邦**，"Each city, kingdom and trade guild had its own standards **until the formation of the Akkadian Empire when Sargon of Akkad issued a common standard**." 直到萨尔贡（Sargon of Akkad，约 2334–2279 BCE）才颁布统一标准。[来源](https://en.wikipedia.org/wiki/Ancient_Mesopotamian_units_of_measurement)

研究「度量衡」后：换算损耗归零，并解锁**契约**。

#### 2.6 契约与声望

| 行为 | 效果 |
|---|---|
| **签订长期契约** | 锁定该路线价格 ±10% 达 **5 分钟**，运力 +20%，声望 **+2** |
| **单方毁约** | 声望 **−15**，该邦下次报价 **+25%** 持续 3 分钟 |
| 声望 ≥ 70 | 全部路线价格 **−10%** |
| 声望 ≤ 20 | 全部路线价格 **+25%**，且 **20% 概率被拒绝交易** |

### 3. 知识累积（研究成果跨时代叠加）

> **这是本代的第二条新线，也是与 E1/E2 的正式交接。**

#### 3.1 交接：E1/E2 的「经验」在本代被「文字」取代

| 维度 | E1 / E2（口头传承） | **E3（文字）** |
|---|---|---|
| 货币名称 | 经验 💡 | **知识 📜** |
| 产出方式 | **人口自然产生**（0.1/秒/人） | **书吏产出**（需泥板容量 + 书吏岗位） |
| 与人口的关系 | **正比** —— 人多就学得快 | **不再正比** —— 要学得快就得养更多不产物资的人 |
| 累积性 | ❌ **学到哪算哪**，换代后归零 | ✅ **刻录进档案库，跨时代永久保留** |
| 升级关系 | —— | **升级，非替代**：经验系统被"文字"接管并加压 |

> **为什么必须交接，而不是叠加**：如果 E3 同时保留"经验 = 人口 ×0.1"和"知识 = 书吏产出"，玩家会两边都要，人口再度变成唯一解，核心矛盾就被稀释了。**本代明确：E1/E2 的经验产出通道关闭，只有书吏能产出研究货币。**

**交接演出**：跃迁进 E3 时弹窗 —— "你们的神话与歌谣记住了很多，但每一个冬天都会忘掉一些。现在，把话刻在泥上。"

#### 3.2 档案库（跨时代叠加的实现）

每条**已刻录**的科技进入本城邦的**档案库**，永久提供研究加成：

```
研究速度倍率 = 1 + 0.03 × 档案库内已刻录科技数 × 时序系数

E3（当代）  时序系数 = 1.00          → 20 项刻录 = ×1.60
E4（d=1）   时序系数 = 0.60          → ×1.36
E5（d=2）   时序系数 = 0.36          → ×1.22
E6（d=3）   时序系数 = 0.22          → ×1.13
E7 及以后   时序系数 = 0.20（下限）  → ×1.12，永不归零
```

> **与全局 1.3.2 衰减规则一致**：衰减率 0.6，下限 0.20。**文字作为 E3 的核心，在 E7 仍提供 ×1.12 的研究斜率** —— 这就是"不能完全放弃，只能减弱"的机制化表达。

**关键差异（对比 E5 印刷术）**：E3 的档案库是**存量加成**（固定 +0.03/项），E5 的印刷术是**流量复利**（研究越快→科技越多→研究更快）。E3 是"把知识留住"，E5 才是"让知识滚起来"。

#### 3.3 记录容量与知识累积的张力

```
知识越多 → 能研究的科技越多 → 但槽位只有那么多 → 必须取舍刻录哪些
                              ↓
                    未刻录的科技 E4 起彻底消失
```

**玩家在 E3 末的终极决策**：用有限的 20–23 个泥板槽，留下哪 20 项知识给下一个时代？

### 4. 工具世代与青铜装备（E1 系统的延续）

**沿用 E1 的"文明级工具世代"，不做个体装备追踪。**

| 世代 | 工具 | 史实锚点 | 群体效果 |
|---|---|---|---|
| 5 | 红铜工具 | 铜石并用期（Chalcolithic），早于青铜 | 采集/采石效率 +25% |
| 6 | **砷青铜工具** | 中东砷铜共生矿自然合金，毒性很快被察觉 | 效率 +30%，但**书吏/工匠舒适度 −1** |
| 7 | **锡青铜工具** | 锡青铜需"分别开采锡石、单独冶炼、再加入热铜" | 效率 +60%（**需稳定锡供给**） |
| 8 | 青铜兵器（文明级） | 青铜多用于兵器或精英艺术 | 损失事件 −40%，防御 |

> **史实依据**：最早的青铜器物含锡或砷 **< 2%**，被认为源自铜矿（如含砷的黝铜矿 tennantite）的**无意合金**；砷青铜先出现于中东，但"健康风险很快被认识到，于是青铜时代早期就开始了寻找危险性低得多的锡矿的历程"。[来源](https://en.wikipedia.org/wiki/Tin_sources_and_trade_during_antiquity)
>
> **机制意义**：世代 7（锡青铜）**性能最好但依赖进口锡**，世代 6（砷青铜）**本地可得但代价是舒适度**。这是一个史实驱动的真实取舍。

**轮子**（效率科技）：公元前 4500–3300 年出现陶轮与最早实心木轮（带轴孔的木盘）；公元前 2200–1550 年出现辐条轮与战车。[来源](https://en.wikipedia.org/wiki/Wheel)
→ 游戏中「轮子」提升**陆路运力 40%**，是贸易线的关键乘数。

### 5. 文字 — 人口 — 产出 的咬合

```
        ✍️ 文字（核心 · 记录交换型）
        │
        ├── 书吏 ──▶ 知识 ──▶ 科技解锁
        │        └─▶ 记账 ──▶ 维持贸易路线
        │        └─▶ 誊刻 ──▶ 档案库（跨时代加成）
        │
        ├── 泥板 + 度量衡 ──▶ 契约 / 压低价格波动
        │
        ▼
   🗺️ 贸易路线（第二条线）
        │  铜产地 ≠ 锡产地 → 必须交换
        │  进口锡 ──▶ 冶炼 ──▶ 青铜
        ▼
   🥉 青铜 ──▶ 工具世代 7/8 ──▶ 采集·采石·防御效率
        │
        ▼
   👥 人口（引擎 · 逻辑斯蒂增长）
        │  r 含「贸易繁荣因子」与「农业底线因子」
        ▼
   🍖 食物 / 🪵 木材 / 🪨 石头（产出）
```

**闭环**：
书吏多 → 知识快 + 路线稳 → 科技快 + 锡进得来 → 青铜多 → 工具世代高 → 物资产出高 → 民居/学宫建得起 → K 与记录容量上升 → 人口更多、能养更多书吏

**反之（本代特有失速）**：
书吏不足 → 路线断账（效率 30%）→ 锡断供 → 冶炼停工 → 青铜为 0 → 工具世代卡死 → 物资产出停滞 → 无力扩学宫 → 槽位不足 → 大量科技停在"口头"×50% 且**下一代丢失**

**核心取舍（一句话）**：**人口总量固定，书吏与生产者争抢同一份人力 —— 而书吏效率越高，你越缺人挖矿。**

**③ 锡 — 本代的真正瓶颈**

```

→ 平均 2,000 / 5,400 = 0.37 锡/秒

而城邦本地锡产出 = 0（史实约束，永不开放）
→ 必须全部由贸易进口
```

**进口成本**：

```
0.37 锡/秒 × 150 基准价 = 55.5 价值/秒
若以食物支付（食物价格 = 1）：需出口 55.5 食物/秒
占食物总产出的 55.5 / 400 = 13.9%
```

→ **玩家必须把约 14% 的粮食经济转化为锡。** 这个比例刻意设计在"肉疼但可行"区间：低于 10% 无感，高于 25% 会逼玩家放弃农业底线因子（触发人口失速）。

**④ 铜平衡**

```
本地铜矿（400 人）：13.1 铜/秒
冶炼消耗：3.7 × 0.9 = 3.33 铜/秒
→ 盈余 9.8 铜/秒，正是你用来换锡的筹码 ✅
```

→ **有铜矿的城邦 = 富余铜换锡；无铜矿的城邦（苏美尔式冲积平原）= 铜锡双缺，只能用粮食和青金石换。** 两条产地的玩法完全不同。

**⑤ 运力平衡**

```
锡路线（距离 3）：需运输 55.5 价值/秒
商人每有效人：1.2 / (1 + 0.15×3) = 1.2 / 1.45 = 0.83 价值/秒
→ 需 67 等效商人 → N^0.9 = 67 → N ≈ 108 人（占人口 5.4%）✅
```

**⑥ 书吏与核心矛盾（本代最关键的一笔账）**

| 用途 | 占用 |
|---|---|
| 维持 3 条路线（锡 ×1 + 铜/粮 ×2） | 3 × 40 = **120 人** |
| 知识产出 | 425 − 120 = **305 人** 有效 |
| 刻录 | 1 人（象征性） |

```
305 人书吏 → 305^0.9 = 172 等效 → 0.15 × 172 = 25.8 知识/秒
全代可获知识（含成长期折算） ≈ 100,000
```

→ **书吏占人口约 20%（425 / 2,160），其中 28% 的书吏被贸易吃掉。** 如果你的书吏不足，玩家要在"路线断账（效率 30%）"和"研究停滞"之间二选一 —— **这就是核心矛盾的可玩形态。**

**⑦ 知识收支验算**

| 项 | 知识 |
|---|---|
| 必点（核心 800 + 支撑 15,600 + 门槛 30,000） | **46,400** |
| 必点 + 刻录费（×1.1） | **51,040** |
| 全部 20 项科技 | 142,900 |
| 全部 + 刻录费 | **157,190** |
| 典型节奏下累计可获（验算基准，非时长承诺） | **≈ 100,000** |

→ 玩家能点完**必点科技 + 约 6–7 项效率科技（共 13 项）**，但**无法全点**。取舍成立 ✅

**⑧ 记录容量验算**

| 项 | 值 |
|---|---|
| 全代可研究科技数 | 最多 20 项（含必须刻录的法典） |
| 起始槽位 | 3 |
| 需要学宫 | (20 − 3) / 5 = 3.4 → **4 座** |
| 跃迁最低要求 | 18 槽 = 3 座学宫 |

→ **玩家必然面临"槽位不够刻满全部科技"**，必须放弃一些效率科技不刻录（它们本代只有 ×50%，且 E4 消失）。✅

#### 11.6 建筑

| 建筑 | 成本 | 效果 |
|---|---|---|
| 🏠 民居 | 220 木材 + 120 石头 | K **+130** |
| 🔥 熔炉 | 180 石头 + 40 铜 | 冶炼工效率 +25%；解锁冶炼工 |
| 🏛️ 学宫 | 260 木材 + 200 石头 | **记录容量 +5** |
| ⚖️ 商栈 | 150 木材 + 60 青铜 | 贸易路线槽位 **+2** |
| 📏 标准器 | 100 青铜 | 换算损耗 −5% |

**成本递增**：同类建筑第 n 座成本 × `1.15^(n−1)`（16 座民居 → 最后一座成本已达首座的 9.4 倍，形成真实的建造节奏压力）。

#### 11.7 科技经验（知识）成本 + 配平验算

| 层级 | 项数 | 合计 |
|---|---|---|
| 核心（楔形文字） | 1 | 800 |
| 支撑 | 5 | 15,600 |
| 效率 | 13 | 96,500 |
| 门槛（钢铁） | 1 | 30,000 |
| **合计** | **20** | **142,900** |

| 验算项 | 知识 | 结论 |
|---|---|---|
| 必点（含刻录费） | 51,040 | ✅ 轻松达成 |
| 典型节奏下累计可获 | ≈ 100,000 | ✅ |
| 必点剩余可用于效率科技 | ≈ 49,000 | → 约 **6–7 / 13 项** |
| 全部（含刻录费） | 157,190 | ❌ **不可能点完** |

#### 11.8 跃迁条件（E3 → E4）

```
✓ 科技：研究「钢铁」（门槛科技）并**完成刻录**（占 1 槽位）
✓ 人口：≥ 1,800
✓ 青铜：库存 ≥ 2,000
✓ 建筑：学宫 ≥ 3 座（记录容量 ≥ 18）
✓ 建筑：商栈 ≥ 2 座
✓ 档案库：已刻录科技 ≥ 12 项
```

**六项全部满足**后，出现"走向帝国"按钮。

> **为什么"已刻录 ≥ 12 项"是跃迁条件**：法典时代的前提是**有一套能被继承和引用的成文规则库**。一个没留下记录的城邦，没有资格进入帝国 —— 这正是"文字是核心科技"的最终确认，也让玩家在时代后期必须回头补学宫与刻录。

### 12. 节奏曲线（不设时长目标）

> **设计原则**：本代要玩多久由跃迁条件与配平自然决定，**不做人工时长规划**。下表按**体验阶段**给出节奏参考。

| 阶段 | 玩家在做什么 | 人口 | 记录容量 / 已刻录 |
|---|---|---|---|
| **教学期** | 派农夫保粮、开本地铜矿；研究「泥板制作」「书吏训练」；**开出第一条贸易路线** | 260 → 380 | 3 / 1 |
| **第一次危机：锡荒** | 发现本地无锡，冶炼彻底卡死。被迫开第二、三条路线，第一次体验价格浮动与"用什么去换" | 380 → 700 | 3 / 3 |
| **冶炼上线** | 研究「铜锡冶炼」「度量衡」；冶炼工上线；熔炉 + 第一座学宫；开始管理"书吏 vs 商人 vs 矿工"的人力三角 | 700 → 1,200 | 8 / 6 |
| **核心取舍期** | 书吏需求暴涨（记账 120 人 + 知识产出），必须在"路线断账"与"研究停滞"间选择；开青金石商路；签契约锁价 | 1,200 → 1,700 | 13 / 12 |
| **记录取舍期** | 冲刺「法典」；扩建学宫；**槽位压力爆发** —— 必须在有限泥板上决定"哪些知识值得传下去" | 1,700 → 2,000 | 18 / 16 |
| **收束** | 补齐跃迁六条件；刻录法典；跃迁 | 2,000 → 2,160 | ≥18 / ≥20 |

**体验曲线**：

- **学习"记录"** —— 理解书吏不产物资的代价
- **第一次危机 = 锡荒** —— 这是本代最有力的一击。玩家会亲眼看到"铜堆成山，但没有锡，一克青铜也炼不出来"，从而真正理解"为什么青铜时代一定要有贸易"
- **扩张期** —— 三条线（文字/贸易/生产）同时运转，人力开始吃紧
- **核心矛盾的正面冲突** —— 书吏不够用了
- **记录容量的取舍** —— 从"怎么变强"转向"留下什么"
- **收束** —— 建立可传承的知识库，推开帝国之门

### 13. UI 要点

| 元素 | 设计 |
|---|---|
| **记录容量仪表盘** | 顶部**大号**泥板槽位格 `▣▣▣▢▢▢▢▢`，每格 = 1 项科技。**地位等同 E1 的火种仪表盘** —— 它是本代的视觉主角 |
| **科技图标双状态** | 已刻录 = 实心 + 泥板边框；**未刻录 = 褪色 50% 透明度 + 虚线边框**，悬停提示"未刻录：效果减半，进入下一时代将失传" |
| **贸易地图** | 4–6 个邻邦节点，连线显示：距离、运力占用、书吏占用、当期价格、波动箭头。断账路线显示为**红色虚线** |
| **价格走势小图** | 每条路线附 5 周期迷你折线，让"买得越多越贵"**看得见** |
| **核心矛盾提示** | 当书吏占人口 > 25% 时，顶部弹出提示："**书吏不产出任何物资** —— 当前 26% 的人口在记账与誊刻" |
| **数字可解释** | 任一价格悬停展开：`基准价 150 × 距离系数 1.45 × 需求冲击 1.22 × 波动 0.94 = 现值 249.5` |
| **人力分配一览** | 农夫 / 矿工 / 冶炼工 / 商人 / **书吏** 五项占比，书吏以不同色系标出，强化"它不产物资"的视觉暗示 |
| **遗产预警** | 时代跃迁前弹窗列出**所有未刻录科技**，标注"这些知识将随这一代人老去"，并给一次机会补刻录 |

### 14. 与 E4 的衔接

| 变化 | 说明 |
|---|---|
| **文字加成衰减** | 从 ×1.60 降至 ×1.36（`0.6^1`），**不是归零** |
| **书吏降级** | 从核心岗位变为普通岗位，职能移交给 E4 的**官僚** |
| **泥板/学宫降级** | 从顶部大号仪表盘移到"基础设施"折叠区 |
| **未刻录科技消失** | E4 起，所有"口头"状态的科技**永久失效**（这是本代最沉的代价） |
| **贸易路线保留** | 降为物资来源之一；E4 有**铸币**，价格波动与换算损耗大幅收窄 |
| **人口模型保留** | 逻辑斯蒂增长是通用机制，E4 改的是 **K 的来源 = 版图** |
| **解锁法典系统** | E4 核心机制登场：版图、政体、法典条款、官僚 |

**交接提示**：跃迁时弹窗 ——

> "泥板很重，但比记忆轻。
> 你刻下的 20 项知识留下来了；没有刻下的，随着最后一位记得它的书吏一起走了。
> 现在，疆域大到血缘维系不住，你需要的不再是记录，而是**规则**。"

**这完成了核心科技的链式推进**：`文字（把知识写下来）→ 法典（把规则写下来）`。
