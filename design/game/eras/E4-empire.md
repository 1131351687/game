# E4 · 帝国时代（铁器 / 古典时代）

> 当疆域大到无法靠血缘与熟人维系，就必须把规则写成文——**法典是人类第一项"让大规模协作成为可能"的技术**。

| 维度 | 内容 |
|---|---|
| **核心科技** | ⚖️ **法典** |
| **发展方式** | **规模治理型**——扩张带来收益，也带来成本 |
| **核心矛盾** | 版图越大产出越高，但维稳成本呈**超线性**上升 → **规模不经济** |
| **新动词** | **治理**、**扩张** |
| **时长目标** | **3 小时**（10,800 秒） |
| **门槛科技** | 📖 **印刷术**（推开 E5） |

## 🌟 核心科技：法典

> 文字让知识可以记录，法典让**规则可以脱离人而存在**。前者是记忆的外包，后者是**权威的外包**。

| 维度 | 内容 |
|---|---|
| **发展方式** | **规模治理型** —— 你的产出随版图上升，但维稳开支的**增速快于**产出的增速；最优规模是有限的 |
| **核心矛盾** | 每多占一格领土，**边际承载力递减、边际维稳成本递增**——越过某一点后，扩张是净亏的 |

**为什么法典是"规模治理型"的钥匙**：

在 E3 城邦时代，规则靠**人**承载（长老、祭司、贵族口头解释法律）。这种治理的**有效半径极小**——因为每个新并入的族群都需要重新谈判一遍。法典把规则**固化为文本**：

| 无文字/无法典 | 有法典 |
|---|---|
| 每块新领土都要重新解释一遍习惯法 | 文本一次颁布，处处适用 |
| 判决依赖个人权威，权威死了规则就变 | 规则独立于个人存续 |
| 行政半径 ≈ 熟人网络半径 | 行政半径 ≈ **文本 + 驿道**的半径 |

**史实锚点**：
- **《十二铜表法》**（Lex Duodecim Tabularum），**公元前 449 年**正式颁布于罗马广场。此前法律不成文、且由贵族祭司（pontifices）垄断解释；公布于青铜板后，"罗马法的基础延续了一千年"（西塞罗称其"胜过所有哲学家的图书馆"）。[Wikipedia: Twelve Tables](https://en.wikipedia.org/wiki/Twelve_Tables)
- **秦统一后的标准化**：公元前 221 年秦并六国，随即统一货币、度量衡与文字，并"分天下作三十六郡"（《汉书·地理志》）。[Wikipedia: Qin dynasty](https://en.wikipedia.org/wiki/Qin_dynasty) · [ctext.org 汉书地理志](https://ctext.org/han-shu/di-li-zhi-xia)
- **秦汉三级行政**：汉帝国（不含封国）按 州 → 郡 → 县 三级划分。**公元 2 年**中国史上第一次全国性普查登记人口 **57,671,400 人 / 12,366,470 户**。[Wikipedia: Han dynasty](https://en.wikipedia.org/wiki/Han_dynasty)
- **⚠️ 争议**：中文史学界常把"成文法"追溯到子产铸刑书（前 536 年）与李悝《法经》。本作取"**成文法在古典时代成为治理大规模政体的通用技术**"这一层，不主张单一源头。

## 1. 版图与维稳（核心机制一）：规模不经济

### 1.1 领土 = 收益 + 负债

每一格领土同时带来两件事：

| 带来的 | 机制 |
|---|---|
| **收益** | ① 提高人口承载力 K（见第 5 节）② 提供"领土物产加成"（耕地、矿脉、商路） |
| **负债** | **行政负荷 A(n)** ——必须有人去管它，且管的地方越远越贵 |

### 1.2 维稳成本的超线性函数

```
行政负荷        A(n)  = 1.5 × n^1.5                       ← 超线性核心
行政半径惩罚     R(n)  = 1 + (0.030 − 0.006·D) × (n − 1)    ← D = 驰道等级 0–4
武力压制         Λ(L)  = 1 − 0.02·L   （下限 0.70，L = 军团数）
有效行政负荷     A_eff = A(n) × R(n) × Λ(L)

维稳开支率       ρ(n)  = 0.80 × A_eff / (A_eff + 240) × (1 + 0.6·δ)
                         其中 δ = max(0, 1 − κ)，κ = 治理覆盖率（见第 2 节）
```

**ρ 的物理含义**：**维稳吃掉全国总产出的百分比。**

**三处设计意图**：

| 项 | 为什么这样设计 |
|---|---|
| `n^1.5` | 超线性。史实上，帝国扩张的边际治理成本上升不是线性的：罗马从共和国到戴克里先时期，行省被**不断拆分**，总督（praesides）管辖**更小的区域与更少的人口**——即**单位面积的行政成本上升**；戴克里先由此建立了"帝国史上最庞大、最官僚化的政府"，并被迫进行全面税制改革。 |
| `R(n)` 行政半径惩罚 | **纯线性**叠加，让有效指数从 1.5 抬到约 **1.67**。史实依据：在没有快速通信的时代，政令传递时间随距离线性增长（波斯御道 Susa→Sardis 全长 **2,699 km**，驿使 9 天、步行 90 天，见 §1.4）。 |
| `Λ(L)` 军团压制 | 军队是**第二种治理手段**：昂贵但即时。史实依据：罗马军团既是扩张工具也是行省镇压力量；波斯 satrap 叛乱频发（公元前 5 世纪中期起），中央须以武力弹压。 |

**⚠️ 为什么是 0.80 和 240**：这两个常数决定"维稳开支率的上限与饱和点"。取 0.80 表示**再有秩序的国家也把八成产出视为维稳天花板**（史实参考：罗马帝国军费占财政的 50–60%，戴克里先把成年男性服役比例从约 **1/25 提高到 1/15**，被当时评论者认为过度）；取 240 使饱和发生在 n≈20 附近，正好落在本时代的扩张走廊上。

### 1.3 边际成本 vs 边际收益（**这是本章的核心验算**）

以"治理配置基准"验算：官署 Lv3（治理效率 ×1.75）、**共和制**（σ=1.15）、法典条款「成文法」+10% 与「编户齐民」+5%，则

```
治理效率 E = 1.75 × 1.15 × 1.15 = 2.314
κ ≥ 0.8 为稳定线   →   所需官吏  B(n) = ⌈0.8 × A_eff(n) / E⌉
```

| 领土 n | 行政负荷 A_eff（D=0, L 取需求值） | 所需官吏 B | 维稳开支率 ρ | 净产出指数* | 单格边际 |
|---|---|---|---|---|---|
| 1 | 1.50 | 1 | **0.5%** | 348 | — |
| 3 | 8.26 | 3 | 2.7% | 402 | **+6.5%** |
| 5 | 18.8 | 7 | 5.8% | 441 | +4.9% |
| 10 | 60.2 | 21 | 16.1% | 502 | +1.8% |
| 13 | 95.6 | 34 | 22.8% | 519 | +0.9% |
| 15 | 113.9 | 40 | 25.7% | 527 | +0.6% |
| 18 | 173.0 | 61 | 33.5% | 531 | +0.2% |
| **20** | **210.6** | **73** | **37.4%** | **532** | **+0.06%** ← **最优规模 n\*** |
| 22 | 252.3 | 88 | 41.0% | 531 | −0.05% |
| 24 | 298.1 | 91 | 44.3% | 529 | **−0.26%** |

\* 净产出指数 = `(K_base + 60·n^0.85) × 0.30 × (1 + 0.10·n^0.6) × (1 − ρ)`，仅为量纲一致的比较指标，非绝对产出。K_base 取 1,000。

**读表结论（"规模不经济"的量化表达）**：

1. **边际收益递减**：第 3 格带来 **+6.5%**，第 15 格只剩 **+0.6%**，第 20 格 **+0.06%** —— 衰减约 **99%**。
2. **存在明确的最优规模 n\* ≈ 20**，越过之后**每多一格领土，全国净产出反而下降**（第 24 格 −0.26%）。
3. **成本增速约为规模增速的 2 倍以上**：从 n=15 到 n=24，领土只增 **60%**，而官吏编制从 **40 增至 91（+128%）**，维稳开支率从 **25.7% 升至 44.3%（+72%）**。
4. **官吏编制的绝对数很小是史实正确的**：Bagnall 依埃及数据估计，罗马官僚约为 **每 5,000–10,000 人 1 名官员**（400–800 名官员管理 400 万居民）。**帝国的真实成本不是人头，而是财政份额 ρ。** 本作因此把惩罚放在 ρ 上，而非放在人口占用上。

### 1.4 道路网：用基础设施"购买规模"

**驰道（D=0 → 4）把行政半径惩罚压到近零**：

| 驰道等级 D | R(24) | A_eff(24) | ρ(24) | 净产出指数(24) | 相对 n\*(D=0)=532 |
|---|---|---|---|---|---|
| 0 | 1.69 | 298.1 | 44.3% | 529 | −0.5% |
| 2 | 1.414 | 249.4 | 40.6% | 565 | +6.2% |
| **4** | **1.138** | **200.7** | **36.4%** | **604** | **+13.5%** |

**驰道 Lv4 把 n=24 从"净亏"变成"比旧最优点高 13.5%"** —— 即**道路网把最优规模从 n≈20 推到 n>24**。

**史实锚点**：罗马道路从约公元前 300 年起随共和国与帝国的扩张修建。鼎盛时期，**113 个行省**由 **372 条大道**连接，自罗马辐射出 **29 条军事干道**，路网总长 **超过 400,000 km**，其中**石板铺装超过 80,500 km**（高卢 21,000 km、不列颠 4,000 km）。[Wikipedia: Roman roads](https://en.wikipedia.org/wiki/Roman_roads)

**波斯御道（Royal Road）**：大流士一世整顿，Susa → Sardis 全长 **1,677 英里（2,699 km）**，由 **Angarium** 驿使接力 **9 天**送达；徒步需 **90 天**。[Wikipedia: Royal Road](https://en.wikipedia.org/wiki/Royal_Road)

**罗马国家驿运（cursus publicus）** 由**奥古斯都创设**，用于在行省与意大利之间传递文书、官员与税款；后期维护成本转嫁为沿途居民的地方义务。[Wikipedia: Cursus publicus](https://en.wikipedia.org/wiki/Cursus_publicus)

> **设计意图**：让"扩张"与"基建"形成**一对一的攻防**——想变大，就先修路。这正是罗马与波斯真实做过的事。

## 2. 法典条款与官吏（核心机制二）：投入治理 = 换取规模

**这是本时代的新动词「治理」的全部内容。**

### 2.1 治理覆盖率 κ

```
治理供给   G = B × E          B = 官吏数   E = 治理效率
治理需求   A_eff              见 §1.2
覆盖率     κ = G / A_eff
```

| κ 区间 | 状态 | 秩序 O 变化 |
|---|---|---|
| ≥ 1.0 | 从容 | `dO/dt = +3.0/s`，且每超出 0.1 额外 ρ −1.5%（上限 −15%） |
| 0.8 – 1.0 | **稳定线内** | `dO/dt ∈ [0, +3.0]` |
| 0.5 – 0.8 | 吃力 | `dO/dt < 0`，秩序开始下滑 |
| < 0.5 | 失控 | `dO/dt ≤ −4.5/s`，ρ 额外 ×(1+0.6δ) 恶化 |

**统一公式**：

```
秩序 O（0–100）：dO/dt = clamp( 15 × (κ − 0.8), −8.0, +3.0 )
```

> **为什么阈值是 0.8 而不是 1.0**：治理永远不可能完美覆盖。留 20% 的"灰色地带"给地方豪强、宗族、神庙等自发秩序——史实上罗马与秦汉都依赖地方自治体代理基层治理。这也让玩家不必把官吏堆到数学上的满配。

### 2.2 治理效率 E 的三个来源

```
E = (1 + 0.25 × 官署等级) × σ_政体 × (1 + Σ法典条款治理加成)
```

- **官署（建筑）**：最直接的杠杆。Lv0 → ×1.00，Lv4 → ×2.00
- **政体（系统）**：君主 1.00 / 共和 1.15 / 神权 0.90 —— 见第 3 节
- **法典条款**：可立法的制度调整 —— 见 §2.4

**核心取舍**：把这三者堆满，可以把所需官吏数压到 **1/3**。但官署要木材与铁，政体有各自的代价，条款有得有失。**没有任何一项是免费的。**

### 2.3 官吏岗位的成本结构

> **设计意图**：让"治理"这个动作有**真实的人力代价**，而不是一个免费滑块。

| 项 | 值 | 说明 |
|---|---|---|
| 每 1 个官吏岗位占用人口 | **9 人** | 1 名官员 + 8 名吏员/书吏/差役。史实依据：罗马总督赴任携带 `cohors amicorum`（随员团）、书吏与侍从；汉代官有"吏"的庞大僚属层 |
| 官吏岗位上限 | 每座**官署 +12 岗** | 治理是需要"办公场所"的，不能凭空雇人 |
| 粮食消耗 | 1.20 / 秒 / 岗 | 平民的 **6 倍**（平民 0.20） |
| 铸币俸禄 | 0.15 / 秒 / 岗 | **官俸必须以铸币支付**（见第 4 节） |
| 裁撤惩罚 | 裁撤 1 岗 → **秩序 −10** | 官位编制一旦设立，撤销本身就是动乱源。史实：裁撤冗官在罗马与汉代均引发剧烈政争 |

**为什么用「9 人」而不是「1 人」**：真实帝国的"官"极稀少（Bagnall：1/5,000–1/10,000），但每个官背后是成倍的吏员与差役。把成本打包进"每岗 9 人"，既保留史实量级，又让**人力占用可感**。

### 2.4 法典条款（立法调整）

**法典碑**每座提供 **1 个条款槽位**（初始 2 槽，上限 8 槽）。每条条款**有得有失、不可全取**。

| 条款 | 收益 | 代价 | 史实锚点 |
|---|---|---|---|
| **成文法** | 治理效率 **+10%** | 铸币 −10% | 十二铜表法，前 449 年 |
| **编户齐民** | 治理效率 +5%；每格领土 K **+4** | 官吏俸禄 +15% | 汉 2 年普查 57,671,400 人 / 12,366,470 户 |
| **军功爵 / 普遍兵役** | 兵员配额 **+30%** | 粮食 −10% | 秦二十等爵；戴克里先征兵比例 1/25 → 1/15 |
| **度量衡统一** | 铸币产出 **+20%** | 一次性成本：铁 20,000 | 秦 221 BCE 统一度量衡与货币 |
| **铸币权收归中央** | 铸币 +15%；秩序恢复 +20% | 需 **君主制**（其他政体须额外研究「万民法」） | 亚历山大里亚在戴克里先治下因叛乱被剥夺独立铸币权 |
| **信仰宽容 / 国教** | κ 稳定线由 0.80 **降至 0.65**（祭司体系代行基层治理） | 研究 −10%；兵员 −10% | 米兰敕令 313 CE 给基督教合法地位；380 CE 国教化 |
| **佃农绑定 / 限田** | 粮食 **+15%** | 人口增长率 r **−10%** | 罗马 coloni 与汉"限民名田" |
| **盐铁专营** | 铸币 **+15%** | 秩序 −1.0/秒 压力（永久） | 汉武盐铁官营 |
| **商路特许** | 铸币 **+25%** | 秩序恢复 ×0.85（豪商坐大） | 罗马 `publicani` 包税商 |

**条款可随时改**（冷却 3 分钟），但**改动本身触发秩序 −5**——立法不是免费的。

## 3. 政体系统（新系统 · **本时代首次登场**）

> ⚠️ **归属声明（必须修正现有 demo）**：政体系统**属于 E4，不属于 E1**。
> 现有 demo 让玩家在 E1 就能切换三种政体，这是**机制与史实双重错位**：
> - **史实上**：君主 / 共和 / 神权是**大规模政体**的组织形态，其意义在于"如何在庞大疆域上分配权威"。狩猎采集群体（E1，人口 2–25）不存在需要政体去调节的规模问题。
> - **机制上**：政体系统的代价（兵员配额、治理效率、研究速度）全部作用于**扩张与维稳**这两个 E4 才存在的动词。在 E1 它无事可做，只是一组**无成本的数值加成**。
>
> **修正方案**：政体系统解锁于 E4 支撑科技「**郡县制**」；E1–E3 不出现政体 UI。E1–E3 若需要"社会形态"的表达，应改用**起源（河谷/草原/海洋）**，那是 E1 已有的系统。

### 3.1 三种政体

| 政体 | 治理效率 σ | 兵员配额 | 铸币 | 研究 | 秩序恢复 | 秩序上限 | 独特规则 |
|---|---|---|---|---|---|---|---|
| 👑 **君主制** | ×1.00 | **+40%** | +10% | −10% | ×1.0 | **90** | **继承危机**：每 25 分钟触发一次，秩序 −15 |
| 🏛️ **共和制** | **×1.15** | −20% | −5% | **+15%** | ×1.0 | 100 | **审议成本**：每次扩张前需满足 官署数 ≥ ⌈n/3⌉ |
| ⚖️ **神权制** | ×0.90 | −35% | −15% | −20% | **×1.6** | 100 | **κ 稳定线 0.80 → 0.65**；太平档产出加成 +15% → **+22%** |

### 3.2 三者的设计意图

| 政体 | 玩家用它优化什么 | 代价住在哪 | 史实锚点 |
|---|---|---|---|
| **君主制** | **扩张速度** | 永久无法进入太平档 + 周期性继承危机 → **快而不稳** | 罗马从元首制到多米那特制；秦 14 年而亡，为中国史上最短的主要王朝 |
| **共和制** | **治理效率 + 研究** | 兵员少、且扩张受"官署门槛"掣肘 → **稳而慢** | 罗马共和国元老院；十二铜表法正是**平民阶层施压**的产物 |
| **神权制** | **维稳**（把 κ 稳定线从 0.8 降到 0.65，等于凭空多出 19% 治理余量） | 兵员与研究双低 → **能守住，但走不远** | 米兰敕令 313 CE、国教化 380 CE；汉武独尊儒术（前 141–87 BCE 在位） |

**三者互不支配**：君主适合"我还想再吃两格"，共和适合"我要把 ρ 压到 30% 以下"，神权适合"我的秩序一直在崩"。

### 3.3 切换政体

```
✓ 一次性成本：铸币 200,000
✓ 立即代价：秩序 −25
✓ 冷却：切换后 15 分钟内不可再切
```

**为什么切换这么贵**：政体变更在史实上是**政变级别的动荡**，不是菜单选项。15 分钟冷却对应 3 小时局长的 **1/12**，意味着**玩家整局最多认真切 2–3 次**——每一次都必须是真正的战略转向。这符合铁律 4「跃迁是玩家主动决策」。

## 4. 铸币与军团（新系统二）：扩张的执行手段

### 4.1 铸币：让"大规模支付"成为可能

**为什么铸币是本时代的必需品**：法典解决了"规则如何扩张"，铸币解决了"**支付如何扩张**"。
- 官吏俸禄与军团军饷**必须以铸币支付**（粮食无法跨国、跨年地标准化支付）
- **没有铸币，就没有常备军和常任官僚**——只有临时征召与分封，那就退回了 E3

**史实锚点**：
- **吕底亚的琥珀金（electrum）狮币**是现存最古老的硬币之一，**约公元前 7 世纪**（学界常引"约 600 BCE"，即以 Alyattes 在位期为准），首都 Sardis。[Wikipedia: Lydia](https://en.wikipedia.org/wiki/Lydia) · [Wikipedia: History of coins](https://en.wikipedia.org/wiki/History_of_coins)
- 早期铸币的目的相当朴素：**简化并规范化"称量贵金属"这件事**。它随后成为波斯 daric / siglos、希腊与罗马货币体系的源头。[Wikipedia: Coin](https://en.wikipedia.org/wiki/Coin)
- 秦统一后**统一货币、度量衡与文字**。[Wikipedia: Qin dynasty](https://en.wikipedia.org/wiki/Qin_dynasty)

**⚠️ 关于年代**：任务书给出"约 600 BCE"，学界常引区间为**公元前 7 世纪**。本作采用"**约公元前 600 年**"作为叙事锚点，并在百科词条层标注区间。

### 4.2 军团：扩张的工具与维稳的保险

**单位 = 军团（legion）**

| 项 | 值 |
|---|---|
| 编制 | **480 兵员** |
| UI 表现 | 显示"第 N 军团 · 10 大队"（保留罗马内部结构做视觉表现） |
| 军饷 | **0.8 铸币/秒 + 2.0 粮食/秒** |
| 武力压制 | 每军团让 A_eff **×0.98**（即 −2%），上限 −30% |
| 容量 | 初始 2；每座**军团营垒 +2** |

**⚠️ 编制抽象声明**：史实罗马军团编制为**共和国期 4,200 步兵 + 300 骑兵**；**晚期共和国约 5,200 人**（10 大队，首大队双倍兵力）；**帝国期 5,280 人 + 120 辅助兵**（首大队约 800 人）。[Wikipedia: Roman legion](https://en.wikipedia.org/wiki/Roman_legion)

本作按约 **1:10 抽象**为 480 兵员。**理由**：若采用史实编制，则维持 6 个军团需 30,000 兵员；按戴克里先时期约 2% 的兵员配额，需要 **150 万人口**——这会让 E3（城邦，人口约 1,000）到 E4 出现 1,500 倍断层，破坏时代连续性。抽象后保留"10 大队"作为 UI 结构，**头部数字（编制人数）仍是设定的一部分，只是不与史实严格对齐**。

### 4.3 兵员配额

```
兵员配额 = 人口 × 2.0% × 政体系数 × (1 + 条款加成)
```

- 基准 2.0%：史实上，戴克里先把成年男性服役比例从约 1/25 提到 1/15（约合全人口 2%），被当时评论者视为**过度扩张**。罗马奥古斯都时期的 28 个军团约占 5,500 万人口的 **0.27%**。
- 因此本作取**上界 2%**，并让君主制（+40%）与「军功爵」条款（+30%）可以把配额推到 **3.6%** —— 这正是玩家为了扩张必须付出的政治代价。

### 4.4 扩张动作

```
扩张第 n → n+1 格的完整代价：

✓ 前置：秩序 O ≥ 50（安定档以上）；军团数 L ≥ ⌈0.15 × n^1.15⌉
✓ 一次性铸币：800 × n^1.3
✓ 一次性铁：200 × n^1.1
✓ 平定期：(15 + 2n) 秒，期间 A_eff × 1.5（新附之地尚未归心）
✓ 共和制额外前置：官署数 ≥ ⌈n / 3⌉
```

**驻军需求 L_req(n) = ⌈0.15 × n^1.15⌉**：

| n | 3 | 6 | 10 | 15 | 20 | 24 |
|---|---|---|---|---|---|---|
| L_req | 2 | 2 | 3 | 4 | 5 | **6** |

**扩张是一次**主动的、有成本的、可撤销（放弃领土）**的决策**——完全符合铁律 4。

### 4.5 秩序（核心仪表盘）

| 档位 | 区间 | 产出 | 研究 | 可否扩张 | 额外后果 |
|---|---|---|---|---|---|
| **太平** | 80–100 | **×1.15** | ×1.00 | ✅ | ρ −5% |
| **安定** | 50–79 | ×1.00 | ×0.90 | ✅ | — |
| **骚动** | 20–49 | ×0.80 | ×0.70 | ❌ | 每 60 秒随机 1 格产出归零 |
| **叛乱** | 1–19 | ×0.50 | ×0.50 | ❌ | **每 30 秒丢失 1 格领土** |
| **崩解** | 0 | ×0.30 | ×0.30 | ❌ | **每 10 秒丢失 1 格领土；人口 −0.5%/秒** |

> **秩序是 E4 的"火种"**：它占据了 E1 火种仪表盘的位置，但机制完全相反——火种是**你必须主动维持**的外部条件，秩序是**你的治理决策实时产生的结果**。前者是环境压力，后者是**决策的镜子**。

## 5. 法典 — 人口 — 产出 的咬合

```
                    ⚖️ 法 典（核心 · 制度技术）

            ▼                                          │

            │
     ┌──────┴───────┐
     ▼              ▼
  ⚖️ 秩序 O      ρ 维稳开支率
  (dO/dt =         = 0.80·A_eff/(A_eff+240)

     ├──► 产出乘子（太平 ×1.15 … 崩解 ×0.30）
     ├──► 研究乘子（安定 ×0.90 … 崩解 ×0.30）
     ├──► **r 的安定因子 = 0.50 + 0.50κ**  ← 维稳/腐败影响人口增长
     └──► 扩张许可（< 50 禁止扩张）
                    │

                    │
            ┌───────┴────────┐
            ▼                ▼

            │                │
            ▼                ▼
   🧑🌾农庄 / ⛏️铁矿 /    科技解锁
   🪙铸币 / 📜官吏 / ⚔️军团      │

            └───────┬────────┘
                    ▼
              💰 产出 → 供养更多人口 → 更多人力 → 更多领土与治理
```

**闭环（正向）**：
治理充足（κ↑）→ 秩序升 → 产出与研究升 → 有铸币雇更多官吏、有铁建官署 → 治理更强 → **可以安全地再扩张一格**
**闭环（负向）**：
盲目扩张 → A(n) 超线性上涨 → κ 跌破 0.8 → 秩序下滑 → 产出与研究降 → 铸币不足、官吏雇不起 → κ 继续跌 → **骚动（禁扩张）→ 叛乱（丢领土）→ 崩解**

**这个负向闭环就是"规模不经济"的运行时表达。** 玩家不会因为一个数学公式而停止扩张，他们会因为**秩序条开始变红**而停止。

### 人口模型（沿用逻辑斯蒂，K 与 r 的来源按 E4 更新）

```
人口增长速率 = r × P × (1 − P / K) × 食物因子

r = r_base × 政体系数 × **安定因子** × 粮食因子
    其中 安定因子 = 0.50 + 0.50κ      ← E4 新增：维稳/腐败影响 r
    r_base = 0.004 /秒

K = K_base + Σ住所容量 + **60 × n^0.85**   ← E4 新增：版图提供承载力
    K_base = 200
    住所四级容量：100 / 400 / 1,600 / 6,400（分别由 4 项科技解锁）
```

**两处刻意设计**：

| 项 | 为什么 |
|---|---|
| **K 加入 `60 · n^0.85`** | 领土提供承载力，但**指数 0.85 < 1** ——后占领的土地更贫瘠、更远、更难开发。史实对照：罗马帝国与汉帝国的核心区人口密度远高于边疆；汉 2 年普查 5,767 万人集中于郡县核心区。这让"版图提供 K"**存在但递减**，与维稳成本的 `n^1.5` 形成剪刀差。 |
| **r 加入 `0.50 + 0.50κ`** | 任务要求的"r 受维稳成本/腐败影响"。κ=1 → 因子 1.0；κ=0.8（稳定线）→ 0.90；κ=0.5 → 0.75；κ=0 → **0.50**（增长腰斩但不归零）。**失序不会灭绝人口，只会让人口引擎熄火**——符合铁律 5「不归零」的精神。 |

| **扩张收益递减** | 领土物产加成 **×0.60**（E5 的扩张回报进一步下降） |
| **维稳成本固定化** | **ρ 的下限锁定为 15%，不再随 n 上升**——即"有法律则扩张惩罚固定" |
| **秩序仪表盘** | 从顶部大号降级为"治理"折叠区的小条；秩序仍影响产出，但不再决定能否扩张 |

**保留的"质"作用（不可替代）**：

> **提供维稳成本的固定化。—— 无法律则扩张惩罚加剧。**
> E5 中若某种原因导致法典失效（如"未颁布法典"的起源变体），ρ 将恢复按 n 增长——**惩罚立刻变成超线性的**。这让法典在 E5–E7 始终"被需要"，而不是"懒得关掉"。

**加成衰减**：从 ×2.0 起，按全局衰减规则 `max(0.20, 0.6^d)` 衰减。E5 时 ×0.60，E6 ×0.36，E7 ×0.22，E8 起触底 ×0.20。

### 11.2 核心机制数值

```
行政负荷        A(n)   = 1.5 × n^1.5
行政半径惩罚     R(n)   = 1 + (0.030 − 0.006·D) × (n − 1)          D ∈ [0, 4]（御道网后 5）
武力压制         Λ(L)   = max(0.70, 1 − 0.02·L)
有效行政负荷     A_eff  = A(n) × R(n) × Λ(L)
治理效率         E      = (1 + 0.25k) × σ_政体 × (1 + Σ条款)         k ∈ [0, 4]
治理供给         G      = B × E
覆盖率           κ      = G / A_eff
缺口             δ      = max(0, 1 − κ)
维稳开支率       ρ      = 0.80 × A_eff/(A_eff + 240) × (1 + 0.6δ)
秩序             dO/dt  = clamp(15 × (κ − 0.8), −8.0, +3.0)         可额外 ×政体秩序恢复系数
领土承载力       K_terr = 60 × n^0.85
领土物产加成     Y_terr = 0.10 × n^0.6
```

### 11.4 岗位产出

> **E4 引入递减收益**：E1 因规模极小（人口 2–25）使用线性产出；E4 规模达十万级，故采用 `sqrt` 型递减——**同类岗位越多，单位效率越低**（拥挤、协调成本、边际土地质量下降）。
> 公式：`实际产出 = 岗位数 × 基础产出 / (1 + 岗位数 / 岗位饱和常数)`

| 岗位 | 需求 | 基础产出/秒 | 岗位饱和常数 |
|---|---|---|---|
| 🧑🌾 农庄佃农 | 人力 | 0.50 粮食 | 60,000 |
| ⛏️ 铁矿工 | 人力 + 铁器世代 ≥1 | 0.40 铁 | 12,000 |
| 🪙 铸币工 | 人力 + 铸币厂 | 0.50 铸币 | 500 |
| 📜 官吏 | 人力 ×9 + 官署岗位 | 治理力 1.0 × E | 120（超编则治理效率递减） |
| ⚔️ 军团兵 | 480 人力 + 营垒容量 | 1 军团建制 | 无（受配额硬约束） |

**官吏饱和常数 120 的含义**：超过 120 名官吏后，**每多一名官吏带来的治理力增量递减**——史实上这就是官僚膨胀的低效（Diocletian 大幅扩充官僚，Lactantius 讥其使"城市被官员淹没"；Bagnall 的数据显示官僚在人口中占比极低，说明**问题从来不是人少，而是层级繁复**）。

| **0:00–0:40** | **"变大真爽"** —— 扩张立刻有回报，法典像一剂万能药 |
| **0:40–1:20** | **"等等，好像变贵了"** —— 第一次读到 ρ，第一次被迫在"多一格"和"多一个官署"之间选 |
| **1:20–1:45** | **"我懂了，治理就是买规模"** —— 政体 + 官署 + 条款的组合拳让 ρ 回落，扩张重新变便宜 |
| **1:45–2:35** | **"20 格是极限"** —— 数学家式的顿悟：边际收益趋零。驰道是唯一出路 |
| **2:35–3:00** | **"我要停下帝国，去搞印刷"** —— 从空间扩张转向知识复利，为 E5 铺轨 |

**与 E1 的节奏对照**：E1 的危机是**外部的、周期性的**（火要灭了）；E4 的危机是**内部的、累积的**（我自己造的官僚机器开始拖垮我）。这是"文明复杂度上升"的机制化表达。

## 13. UI 要点

| 元素 | 设计 |
|---|---|
| **秩序仪表盘** | 顶部**大号**（占据 E1 火种的位置），五档配色（崩解暗红 / 叛乱红 / 骚动黄 / 安定蓝 / 太平金）。**κ < 0.8 时数字开始跳动并闪红** → 制造与 E1 火种同级的视觉压力 |
| **版图地图** | 中央区域。已整合的格子按「物产类型」着色（耕地绿 / 矿脉灰 / 商路金）；**当前平定期格子闪烁**。悬停任一未占领格显示：`边际维稳成本 ΔB、边际承载力 ΔK、净收益 −0.26%` |
| **规模不经济曲线图** ⭐ | **本章最重要的 UI**。实时绘制 `净产出 vs n` 曲线，标出 **当前 n** 与 **n\***（最优规模）。当 n > n\* 时曲线右侧变红，并给出提示："**继续扩张将使全国净产出下降。修建驰道可提高 n\***"。这让铁律 7「所有数字可解释」在一张图上完成 |
| **治理覆盖率 κ 条** | 显示 `G / A_eff`，并用 0.8 处画一条**稳定线**。κ < 0.8 时条体变红，旁边提示"再雇 N 名官吏可回到稳定线"——**把抽象的覆盖率变成一个可操作的数字** |
| **维稳开支率 ρ** | 与 κ 条并列，显示"维稳吃掉全国产出的 44.3%"。附悬停明细：`行政负荷 298.1 × 半径 1.69 × 压制 0.88` |
| **政体面板** | 三张卡片并列，各自的代价用**红字**标注（君主："秩序上限 90 · 每 25 分钟继承危机"）。切换按钮显式展示 `铸币 −200,000 / 秩序 −25 / 冷却 15 分钟` |
| **法典条款面板** | 槽位式（🗿 法典碑提供槽位）。每条条款**同时显示收益与代价**，未填满的槽显示为空的青铜板 |
| **扩张按钮** | 显式列出五项代价（秩序前置、军团需求、铸币、铁、平定期时长）。不满足条件时**高亮具体是哪一项**，而非单纯置灰 |
| **旧核心降级区** | 「基础设施」折叠区放置：火种（E1）、粮仓季节（E2）、文字与贸易路线（E3）。每组显示当前跨时代系数 `×0.60（来自 1 个时代前）` —— 落实铁律 5 的界面表达 |

## 14. 与 E5 的衔接

跃迁到 E5 觉醒时代（印刷术）时：

| 变化 | 说明 |
|---|---|
| **政体系统保留** | 政体从"扩张速度的杠杆"转为"研究复利的载体"（共和制 ×1.15 研究直接叠乘 E5 的复利斜率） |
| **版图系统降级** | 领土物产加成 ×0.60；**维稳开支率 ρ 的下限锁定 15%**，不再随 n 上升 |
| **秩序仪表盘降级** | 从顶部大号移到"治理"折叠区；秩序仍影响产出，但**不再决定能否扩张** |
| **法典面板折叠** | 条款全部预设为已颁布，进入"基础设施"区 |
| **官吏岗位保留** | 转为"研究人力"的一种：官吏提供的治理力在 E5 转为**知识保留率**的加成 |
| **铸币保留为核心资源** | E5 的印刷需要纸张（木材/破布）与**资本**，铸币继续作为资本 |
| **人口模型保留** | 逻辑斯蒂增长是通用机制；E5 改变的是 **K 的来源**（城市化）与 **r 的环境因子**（知识传播） |

**交接提示（跃迁弹窗）**：

> **"法典已成为你文明的默认制度。**
> 扩张不再带来惩罚的加剧——但你也不再需要它了。
> **印刷术会把'规则'升级为'知识'：法典让规则可以被复制，印刷术让知识可以被复制。**"

**这段文案的设计意图**：让玩家理解**旧核心没被废弃，只是降级**（铁律 5）——法典的"质"作用（维稳成本固定化）会一直生效到最后，但它的主引擎地位正式交给印刷术。
