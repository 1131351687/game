# E4 · 帝国时代（战国至秦统一）

> E4 的主题是**军事扩张带动生产**：以钢铁、军制和铸币支撑连续征伐，用新占版图扩大人口与物产，最终以统一天下结束本时代。

> **权威声明**：本文件是 E4 当前设计与实现口径。旧稿中的秩序、政体三选、官吏编制、法典条款、行政覆盖率、规模不经济和印刷术门槛均已废弃。后续 AI 不得据此恢复这些系统。

## 核心口径

| 维度 | 内容 |
|---|---|
| 核心科技 | 钢铁 |
| 军事支柱 | 常备军、铁兵器、军功爵、骑兵、器械、军需转输 |
| 经济支柱 | 铸币厂、铸币工、铁矿工、军屯、驰道 |
| 发展方式 | 征伐扩张型：战争是主引擎，生产是军需与后勤 |
| 新动词 | 征伐 / 扩张版图 |
| 时代结束 | 统一天下：统一科技 + 版图 ≥ 20 + 铸币 ≥ 150,000 + 军团营垒 ≥ 4 |

## 核心闭环

```text
铁矿工 -> 铁 -> 铸币厂 + 铸币工 -> 铸币 -> 军团军饷
   |                 |                         |
   |                 +-------- 征伐成本 -------+
   +---- 营垒/武库/驰道/兵器成本 --------------+
                                               v
                                       军团 + 铁 + 铸币
                                               |
                                               v
                                          发动征伐
                                               |
                                      平定期结束，版图 +1
                                               |
                    人口承载、物产、知识产出提高，征伐需求也提高
                                               |
                                               v
                                        军工扩建与统一科技
                                               |
                                               v
                                          统一天下
```

## 已删除的旧系统

- 秩序 0-100 仪表盘。
- 君主 / 共和 / 神权政体三选。
- 官吏岗位与官署。
- 法典碑、条款槽和立法冷却。
- 行政覆盖率、维稳开支率、叛乱与崩解状态机。

## 资源与产出

| 资源 | 来源 | 用途 |
|---|---|---|
| 铁 | 铁矿工，基础 0.40/秒/人 | 铸币、军营、武库、驰道、征伐 |
| 铸币 | 铸币厂 + 铸币工，基础 0.40/秒/人，产 1 铸币耗 0.20 铁 | 军饷、征伐、后续时代资本 |
| 知识 | 人口 × 0.02 × 版图物产倍率 × 遗产倍率，沿用 `experience` 字段 | 研究 E4 科技 |

铁库存：`1000 + (territory - 1) × 350 + 仓库/武库扩容`。铸币库存上限 1,000,000。

## 岗位与建筑

| 类型 | 名称 | 作用 |
|---|---|---|
| 岗位 | 铁矿工 | 产铁；需铁制农具 |
| 岗位 | 铸币工 | 产铸币并耗铁；每座铸币厂 20 岗 |
| 岗位 | 军团兵 | 提供征伐兵力与战力；营垒 + 武库提供工位 |
| 建筑 | 铸币厂 | 木 1,200 + 铁 600，×1.18；提供铸币工位 |
| 建筑 | 军团营垒 | 木 1,000 + 铁 800，×1.18；提供军团工位 |
| 建筑 | 驰道 | 木 1,500 + 铁 1,200，×1.20；降低平定期 |
| 建筑 | 武库 | 木 800 + 铁 1,800，×1.18；铁储量 +1,200，军团战力 +5%/座（上限 +20%），军饷最多 -15% |

首座铸币厂和军团营垒必须在 `territory = 1` 的初始铁上限内可支付，防止 E4 启动死锁。

## 版图与征伐

```text
版图物产倍率 = (1 + 0.08 × (territory - 1)) × 科技 territoryOutputMul
版图承载力   = 60 × territory^0.85 × 科技 territoryCapacityMul

铸币成本 = ceil(600 × territory^1.25 × expansionCostMul)
铁成本   = ceil(160 × territory^1.08 × expansionCostMul)
所需军团 = ceil((2 + 0.75 × (territory - 1)) / 军团战力)
平定期   = (15 + 2 × territory) × expansionFlatMul
```

军团战力 = 科技 `legionPowerMul` × 武库战力加成。发动征伐必须同时满足军团、铸币、铁、无待完成平定期、版图未达 24。平定期结束 `territory = min(24, targetN)`。

## 科技树

三条路线汇聚到 `unification`：

- 钢铁与铸币：钢铁冶炼、铁制农具、牛耕与重犁、河渠水利、军屯制、铸币制度、钱粮调拨。
- 后勤与编户：编户齐民、驰道、郡县征兵、军需簿册、统一度量衡。
- 军略与统一：常备军、军功爵、铁兵器、骑兵建制、攻城器械、军需转输、军制统一、统帅部、统一天下。

当前成本、效果与依赖关系以 `demo/src/data/e4-techs-*.ts` 与 `demo/src/data/techs.ts` 为准；数值调整必须同时通过链式回归和 `diag-e4-fast.ts`。

## 启动与完成

E3 → E4 继承人口、资源、建筑、岗位、知识、记录、贸易路线与声望，进入 E4 时初始化 `territory = 1`、`legions = 0`、`expansionPending = null`、`p1Unlocked = true`。

E4 完成条件：

- 研究「统一天下」。
- 版图 ≥ 20。
- 铸币 ≥ 150,000。
- 军团营垒 ≥ 4。

## UI 与验收

UI 只回答“下一场统一战争还缺什么”：顶部显示版图、军团、下一战需求、平定期、军饷和遗产倍率；文明面板显示统一战争、军团军需、军营/武库和统一检查。

验收必须同时满足：

1. `npm run build` 通过。
2. `npm run regression` 通过。
3. `npx --yes tsx src/dev/diag-e4-fast.ts` 通过。
4. 首座铸币厂、军团营垒可建。
5. 能扩到 20 格以上并研究统一科技。
6. `checkAdvance()` 正确判定统一条件。
7. E1-E3 基线不被污染。
8. 存档迁移可读到 E4 状态。
9. 375px 与桌面 UI 不重叠。
10. 旧秩序、政体、官吏、法典不再出现在 E4 可执行路径中。

## 历史锚点

- 铁制农具与兵器扩散，为战国大规模常备军和工程能力提供物质基础。
- 商鞅变法（前 356、前 350 年）推动编户、军功爵和征兵制度，使战争动员改造内部结构。
- 秦于前 221 年并六国，随后统一文字、货币、度量衡并推行郡县制；这是 E4 的统一分界线。
