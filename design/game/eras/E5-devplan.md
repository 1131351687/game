# E5 远洋时代 · 开发任务清单

> **来源**：[`E5-maritime.md`](./E5-maritime.md)（设计规格，原「觉醒时代」，已按方案 B 更名「远洋」）＋
> [`E3-devplan.md`](./E3-devplan.md)（格式与粒度模板）＋ 代码现实（`demo/src`）
> **状态**：📐 **实施级规格（草案）** —— 拍板后即可按第八节的工作块开工
> **目标**：把 E5 实装为可玩的一代，**并且不破坏 E1/E2 既有基线**（1163s / 1920s 不得受影响）
> **基线**：`demo/` 当前代码 —— 已实装 **E1 + E2**，`SAVE_VERSION = 6`，`tsc` 0 error。
> E3（城市，v6→7）与 E4（帝国，门槛「钢铁」，v7）须**先于**本计划落地（见 §一、§五）。
>
> **本代的独特之处**：E5 是第一个**正反馈增长引擎** —— 知识复利。
> ① 印刷产能链（木材→纸张→典籍→研究点）② 知识复利（R(N)，上限 ×4.20）③ 识字率（复利的调节变量）
> ④ 远航探索（三环海图 / 新大陆 / 异域物产）⑤ 银行与信贷（忍耐期续命）⑥ 研究货币再次演进
> （E1/E2 经验 → E3 知识 → **E5 研究点**）。前三代的线性累加经验完全不适用，必须按下面的顺序推进。

> ⚠️ **铁律（全文贯彻，不另起章节）**：
> - **每代新动词**：E5 新动词 = **复制**（印刷术承载的"知识复制"）· **探索**（远航）。
> - **跃迁只新增不重置**：`transition.ts` 已是"只新增不重置"，E4→E5 交接沿用，资源/人口/建筑/岗位原样带过。

> - **不设时长目标**：节奏按体验阶段与比例定（忍耐期≈时代 1/3），不写绝对秒数。
> - **数字可解释**：所有倍率/上限都取自设计文档 §11 并标 `TODO(balance)`，悬停可见"为什么+4%"。
> - **所有新机制时代门控**：E5 子系统一律 `state.era === 'E5'`（或 ≥'E5'）才生效，否则 E1/E2 基线失真。

  - **研究点**取代「知识」作为 E5 的研究货币（E3/E4 用知识、E1/E2 用经验 —— 三者并存，按时代取用，旧字段不清零）
  - **识字率**是独立状态值（0–100%），**不**进 `RESOURCES`（避免被当成可消耗资源）
  - **验收**：`RESOURCES` 条目数与设计文档 §6 一致（5 新增资源）；`MATERIAL_RESOURCES` 分时代可得；`researchPoints` 标注 `era: 'E5'`

- [ ] **T1.2 岗位** `src/data/jobs.ts`
  - 新增 5 个：造纸工（耗 0.5 木→1.2 纸）/ 印刷工（耗 0.8 纸→0.6 典，需印书坊工位）/ 学者（耗 0.5 典→2.0 研究，需大学工位）/ 教师（人力→识字率 ×1.3）/ 水手（人力+补给→1.0 航海进度）
  - **五个新岗位全部不直接产出食物**（核心矛盾在岗位层的表达）；继承岗位（伐木工/农夫/矿工/工匠/官僚）降权但仍是链条一环
  - **验收**：`JOBS` 含 5 新岗位；造纸/印刷工/学者/教师的 `requires`（建筑+工位）能表达"需对应建筑解锁"

  - 成本递增：每多建一座同类 ×1.35（设计 §11.6）
  - **验收**：5 座建筑各对应一个瓶颈方向（原料/产能/转化/存储/探索）；白银进入成本是"强迫出海"的设计意图，不可删

- [ ] **T1.4 科技集**（新建 `e5-techs-{printing,gunpowder,sailing,conomy-knowledge}.ts`）← **本任务最重**

  - 复利 k 增量链：印刷术 0.05 → 金属活字 +0.01 → 大学制度 +0.01 → 印坊分工 +0.01 → 科学方法 +0.02 = 0.10

### T2 · 引擎层（`src/game/engine.ts` + 建议拆 `game/e5/*.ts`，纯函数优先）

> ⚠️ **铁律：所有新机制必须时代门控**（`state.era === 'E5'` 之类），否则会污染 E1/E2 基线（1163s / 1920s）与 SSR 字节一致性。

- [ ] **T2.1 研究货币再次演进（知识 → 研究点）**
  - `getResearchCurrencyId(state)`：E1/E2→`'experience'`；E3/E4→`'knowledge'`；**E5+→`'researchPoints'`**
  - E5 起关闭「知识」产出通道（学者改产研究点），但 `knowledge` 字段**保留不清零**（供 E6+ 跨时代保留率 §10.2 使用）
  - **知识 → 研究点 的共存方式（默认，见 §四推荐）**：**不自动换算**，`researchPoints` 在 E5 由学者从 0 开始产出；`knowledge` 作为历史/遗产字段保留。
  - **验收**：E1/E2 的 `calcExperienceOutput`、E3/E4 的 `knowledge` 产出行为逐字节不变；`canResearch`/`research` 按 `getResearchCurrencyId` 扣对应货币

- [ ] **T2.2 印刷产能链（木材→纸张→典籍→研究点）**
  - `calcPaperOutput` / `calcBookOutput` / `calcResearchPointOutput`：链式产出，投料不足时**按比例降速**（与 E3 冶炼缺料同理，不是报错）
  - 造纸工吃木、印刷工吃纸、学者吃典；典籍是**消耗品**（被读掉），不是积分（设计 §2.2）
  - **验收**：无木时造纸工产出为 0 且 UI 能说明"缺木"；无典时学者产出为 0（"乘数再大也乘不了 0"）

- [ ] **T2.3 知识复利（核心机制，R(N) 计算）** ← **本代最重**
  - `getNeff(N)`：分段递减映射 `N(≤20) / 20+0.5(N−20)(21–35) / 27.5+0.25(N−35)(>35)`，硬上限 32
  - `getCompoundK(state)`：基础 0.05 + 各科技增量（金属活字+0.01/大学制度+0.01/印坊分工+0.01/科学方法+0.02），终值 0.10
  - `getCompoundMultiplier(state)`：`R = 1 + k × N_eff`，**R 绝对上界 ×4.20**（k=0.10, N_eff=32）
  - `N = 本时代已解锁 E5 科技数`（从 0 起算；跃迁到 E6 归零 —— 闸门一：纪元内计数）
  - **验收**：N≤20 段严格线性（与 brief 公式逐字一致）；N_eff 超 32 时 R 锁 ×4.20 不再涨

- [ ] **T2.4 识字率（独立状态值）**
  - `getLiteracyUpperBound(state)`：`0.15 + 0.15 × 大学数`，硬上限 0.95
  - `tickLiteracy(state, dt)`：逻辑斯蒂增长 `基础增长 0.0008 × 印刷产能因子 × (1 − 识字率/上限)`；教师 ×1.3
  - `getLiteracyFactor(literacy)`：`0.70 + 0.60 × 识字率`（同作用于研究速度 r 与人口 r）
  - **验收**：无大学时上限锁 15%；大学越多上限越高（每座 +15%）

- [ ] **T2.5 远航探索（新动词「探索」）**
  - `tickVoyage(state, dt)`：航海进度 = 水手×1.0/s × 远航加成，累积到环目标值返航 → 抽事件表（§3.3）
  - 首次完成第 2 环 → 保底「发现新大陆」里程碑（异域物产+80 / 白银+300 / 研究点+5000 / 食物+15% / K+10%）
  - 远航单次净亏（期望白银 +20.5 < 成本 50），回报在里程碑（设计 §3.3）
  - **验收**：三环（60/180/480s，成本递增）都能跑通；首次第 2 环必触发新大陆；第 2 环可重复但新大陆只触发一次

- [ ] **T2.6 银行与信贷（忍耐期心理支持）**
  - `tickBank(state, dt)`：贷款按周期计息；「银行与信贷」科技解锁后在印刷投入期可预支白银
  - 贷款上限 = f(声望/建筑)，仅作续命，利息计入白银消耗
  - **验收**：贷款能补上印刷链前期物资缺口；利息可观测、可还清

- [ ] **T2.7 跃迁条件扩展（E4→E5→E6）**
  - `checkAdvance` 需支持 E5 条件：研究「蒸汽机」+ 白银≥5000 + 典籍≥20000 + 印书坊≥3 + 大学≥2 + 航海港≥1 + 人口≥800 + 完成 ≥1 次第 2 环远航
  - 复用 `minBuildings`；新增 `minResource`（白银/典籍）、`minVoyageRing`（第 2 环完成标记）条件类型
  - **验收**：八项条件在 UI 上逐条显示 ✅/⬜ 与进度

**T2 验收**：为以上七个子系统各写一段可跑的验证脚本（放进 `src/dev/`，跑完即删），证明"新机制正确"且"旧机制未变"。

### 3.2 引擎新增函数（签名与公式）

| 函数 | 公式 / 行为 | 边界情况 |
|---|---|---|
| `getResearchCurrencyId(state)` | E1/E2→`'experience'`；E3/E4→`'knowledge'`；E5+→`'researchPoints'` | 时代门控；旧货币字段不删除 |
| `getNeff(N)` | `N(≤20)` / `20+0.5(N−20)(21–35)` / `27.5+0.25(N−35)(>35)`；**硬上限 32** | 超 32 一律取 32（R 锁 ×4.20） |
| `getCompoundK(state)` | 基础 0.05 + 金属活字 0.01 + 大学制度 0.01 + 印坊分工 0.01 + 科学方法 0.02 = 0.10 | 未研究印刷术则无复利（R≡1） |
| `getCompoundMultiplier(state)` | `R = 1 + k × N_eff`；**绝对上界 ×4.20** | k=0.10, N_eff=32 → ×4.20 |
| `countEraTechs(state, 'E5')` | 本时代已解锁 E5 科技数 N（从 0 起；跃迁 E6 归零） | 只数 E5 科技，不含 E1–E4（闸门一） |
| `calcPaperOutput(state)` | 造纸工×1.2 ×(1+水轮捣浆0.4) × 造纸坊产能；缺木按投料比例降速 | 无木→0；UI 标"缺木" |
| `calcBookOutput(state)` | 印刷工×0.6 ×(1+双人压印机0.5) × 印书坊产能+20%；缺纸降速 | 无纸→0 |
| `calcResearchPointOutput(state)` | 学者×2.0 × 印刷科技乘数 × **R(N)** × 识字率因子；缺典降速 | 学者无典→0（"乘数乘不了 0"） |
| `getLiteracyUpperBound(state)` | `0.15 + 0.15 × 大学数`，**硬上限 0.95** | 无大学→0.15 |
| `tickLiteracy(state, dt)` | `0.0008 × 产能因子 × (1 − 识字率/上限) × (教师?1.3:1) × dt` | 达上限则停增 |
| `getLiteracyFactor(lit)` | `0.70 + 0.60 × lit`（lit∈[0,1]） | ×0.77(12%)→×1.27(95%) |
| `tickVoyage(state, dt)` | 进度 += 水手×1.0×加成×dt；达 target→返航→事件表 | 首次第2环→新大陆里程碑 |
| `tickBank(state, dt)` | 贷款按周期计息；「银行与信贷」解锁后可借 | 利息计入白银消耗 |
| `getBottleneck`（改） | E5：印刷链人力占比>30% 且 物资净增<0 → 忍耐期提示 | 复用 E1/E2 卡点逻辑 |

### 3.3 `doTick` 的执行顺序（重要：复利计算时机专门写）

```
1  资源产出（旧链：食物/木/石/经验；E5 新链：纸张/典籍/研究点；含季节、成本、投料）
2  资源消耗（人口吃粮；造纸工吃木 / 印刷工吃纸 / 学者吃典 / 水手吃补给）
3  人口 + 识字率增长（E5 环境因子：舒适度×识字率；识字率逻辑斯蒂增长，受大学上限约束）
4  远航结算（新动词「探索」：进度累积→返航→事件→白银/异域物产/研究点；首第2环→新大陆）
5  ★ 复利研究与科技研究点产出 —— 复利倍率在此计算（见下方"为什么放这里"）
6  银行与信贷结算（忍耐期续命）
7  消息与统计（含忍耐期红字提示判定）
```

> ⚠️ **复利倍率 R(N) 的计算时机（专门写）**：
> `getCompoundMultiplier(state)` 在**第 5 步**被调用，每 tick 重算。原因：
> ① R 依赖 `N = 本时代已解锁 E5 科技数`，而 N 只在玩家"研究完一项科技"那一刻变化（离散事件）；
> ② 把 R 的计算放在研究点产出之前（第 5 步），能保证"刚点完一项科技，下一 tick 的研究速度就立刻变大"——
> 这是复利手感成立的关键（玩家看到倍率数字实时跳动，才相信雪球在滚）。
> ③ 人口与识字率已在第 3 步更新，第 5 步用的 `识字率因子` 取最新值，二者同步。
> ④ R 绝不缓存到 state（避免跨 tick  stale）——它是 `N` 与 `k` 的纯函数，随时可重算，也便于 UI 直接调用显示。
>
> ⚠️ **为什么远航（第4步）在研究点（第5步）之前**：新大陆里程碑给的 +5000 研究点是一次性注入，
> 应计入本 tick 的研究点池之后第 5 步才结算产出速率，顺序无冲突；白银/异域物产先于研究点落袋，
> 避免"探索回报晚一拍"的失真（与 E3 贸易先于人口的考量同源）。

## 四、待拍板事项 · 推荐方案

> 每项给推荐与理由。**你只需回"按推荐"或指出要改哪条**，不用逐条写方案。

### 4.1 「知识 → 研究点」的转换/共存 → **推荐：共存不转换，旧字段保留**
- 理由：与 E3 的"经验→知识"完全一致（经验字段保留不清零），符合"文明积累不清零"铁律。
  研究点是 E5 的全新产出（学者消耗典籍），无需把知识折算进来；`knowledge` 字段保留供 E6+ §10.2 跨时代保留率判断。
- 备选：在 E5 跃迁时一次性换算 `researchPoints += knowledge × rate`。但 rate 量纲未知（见 §七 #6），
  且会模糊"文明积累不清零"，**不推荐**除非配平证明必须。
- 结论：**默认共存不转换**；若拍板要换算，换算率列为 `TODO(balance)`。

### 4.2 新建筑集合：银行是否独立建筑 → **推荐：银行作为科技效果载体，不单独建建筑**
- 理由：设计文档 §8 列 5 座建筑（造纸坊/印书坊/大学/航海港/图书馆），§9 把「银行与信贷」列为**经济/社会效率科技**（效果=可预支白银）。
  即"银行"是机制不是地块。brief 把银行列进新建筑，可能是概览性表述。
- 做法：`buildings.ts` 只加设计文档的 5 座；`银行与信贷` 科技解锁贷款能力，`BankPanel` 是 UI 不是建筑。
- 备选：若坚持要「银行」建筑作为贷款的物理前提，则建筑数变 6，需回写设计文档 §8。
- 结论：**按设计文档 §8 的 5 座落地**；银行=科技+UI。命名上把 brief 的"港口/船坞"对齐为设计文档的「航海港」。

### 4.3 起始人口口径 → **推荐：以"跃迁不重置"为准，E5 起始人口 ≈ E4 末态（约 180,000），非设计文档的 120**
- 理由：设计文档 §11.1 写"人口 120"，但同文档自述 E4 末态人口约 180,000，且铁律"跃迁只新增不重置"。
  120 是**旧时代划分**下的遗留值（E5 曾叫"觉醒时代"，那时 E4 的人口量级不同），与现行 E4 末态矛盾。
- 做法：`constants.ts` 的 `E5.START_POPULATION` 标 `口径待对齐`，实装时取 E4 末态人口（具体数待 E4 落地后回填），不写死 120。
- 结论：**不擅自采用 120**；等 E4 定稿后对齐，文档 §11.1 回写为对齐值。

### 4.4 三桅帆船是否独立核心科技 → **推荐：三支柱为叙事主题，科技树核心仍为「印刷术」，门槛为「蒸汽机」**
- 理由：设计文档 §9 明确核心 1 项=印刷术、门槛 1 项=蒸汽机；"三桅帆船"作为主题支柱，其具体科技落在效率分支（卡拉维尔帆船/星盘等）。
  若强行加「三桅帆船」为核心会改动 §9 的 35 项结构（影响 §11.7 成本表与配平）。
- 结论：保持 §9 的 1+5+28+1=35 结构；三桅帆船作为 UI 叙事标签，不新增科技条目。

## 七、风险与注意事项

| # | 风险 | 对策 |
|---|---|---|
| 1 | **知识复利是正反馈，极易数值爆炸** | 三道闸门全时代门控：纪元内计数(N 跃迁归零) + N_eff 硬上限 32(R≤×4.20) + 成本指数 1.12^n；任何一道单独失效都不崩 |
| 2 | **复利计算时机错 → 手感失真** | R(N) 在第 5 步每 tick 重算（见 §3.3），不缓存；N 只随研究事件变化 |
| 3 | **研究货币再次演进（知识→研究点）污染旧时代** | `getResearchCurrencyId` 时代门控；E1/E2 经验、E3/E4 知识产出逐字节不变 |
| 4 | **远航是随机系统，盲目上 UI 会返工** | 先在控制台跑通 `tickVoyage` 与事件表，再建 `VoyagePanel` |
| 5 | **忍耐期若不可感知，玩家会弃游** | 红字提示是强制 UI（§4.2），且史实锚定（古腾堡破产） |
| 6 | **⚠️ 跨代货币量纲倍数未知** | 经验/E1-E2、知识/E3-E4、研究点/E5 三套货币处于不同数量级（经验秒产~0.08×人口，研究点秒产~44→2046）。跨代保留率 §10.2 依赖 knowledge 存在性，但三套货币**绝对量纲不强制对齐**——若后续要"经验与知识合流"须单独拍板；本计划不擅自换算 |
| 7 | **⚠️ 跨代人口/资源口径错配（已知）** | E5 §11.1 起始人口 120 vs E4 末态 ~180,000，违背"跃迁不重置"。全文标 `口径待对齐`，实装取 E4 末态值，不写死 120（见 §四.3、§八） |
| 8 | **建筑集合歧义** | brief 列「银行、港口/船坞」vs 设计文档 §8 列「航海港、图书馆」。按设计文档 5 座落地，银行=科技+UI（见 §四.2） |
| 9 | 35 项科技 + 7 个子系统，体量过大 | 严格按 M1→M4 推进，每个里程碑独立验收 |
| 10 | 工作区可能有**他人未提交改动**（E3/E4） | 开工前与用户对齐处置，再动 E5 |
