# E8 · 信息时代（现代 / 约 1945–2010s）

> 当计算可以被外包给机器，人终于能从微观操作里抬头。
> **这是到现代为止的最后一代——现代即终局。** 它的终局不是"更强的计算机"，也不是"离开地面"，而是**把文明的管理彻底交给系统本身**：算力廉价到铺满世界、网络把万物连成一张网、自动化接管了一切常规操作，文明第一次不需要人也能够平稳运转。
> *注：本作时代划分到现代为止。若日后保留星海（离开地面）扩展，可顺延为 E9。*

**刻度**：材料：高纯硅 / 复合材料　能源：核电 + 电网（承接 E7 电气时代）　信息：计算机 · 网络 · 数据

> *刻度说明（为什么这样设计）：能源项特意标注"承接 E7 电气时代"，明确**电力不是本代独有起点**——电网与火电在 E7 已铺好地基，本代只做扩容与核电化，避免与 E7 重复定义"通电"。材料项"高纯硅"对应半导体核心科技，信息项点明三件套。*

## 🌟 核心科技：计算机 + 半导体 + 网络

| 维度 | 内容 |
|---|---|
| **发展方式** | **信息自动化型** —— 用数据购买自动化，逐步交出微观操作 |
| **核心矛盾** | 自动化需要数据，数据需要算力，算力需要能源 → **三重依赖链，任一环断裂则自动化瘫痪** |
| **新动词** | **计算 / 联网 / 自动化**（本代第一次让玩家从微观操作中"解放"出来：把管理外包给机器，把世界连成一张网） |
| **门槛 / 终局** | **终局（不设新代）**：算力与数据达量级 · 自动化覆盖率 ≥ 阈值 · 网络连接数达量级 · 系统稳定性达标（详见 §11.8）；现代即收束，不再跃迁。若日后开放 E9 星海，本代发射链可复用作其前置 |

> *为什么这样设计：铁律①要求每代必有新动词——本代的三件套（计算机/半导体/网络）对应三个动作：算（自动化引擎）、缩（单位算力成本指数下降，见 §1.5）、连（万物互联，见 §4.3）。"门槛/终局"一行是新规矩，明确本代以"现代终局"收口而非跃迁。*

**为什么核心矛盾是这个**：E1–E6 里，玩家的瓶颈始终是"人不够 / 物资不够"——瓶颈在**外部世界**。E8 第一次把瓶颈放到**玩家自己的操作**上：文明已经大到一个人管不过来了。计算机的承诺是"把管理外包给机器"，但机器不是免费的——它要数据喂养，要算力运行，要电力驱动。**你越自动化，链条越长，越脆弱。**

**发展方式的独特性**（对比前六代）：

| 时代 | 玩家优化什么 | 瓶颈所在 |
|---|---|---|
| E1 火 | 别让火灭了 | 外部环境 |
| E2 农业 | 攒够过冬的粮 | 外部季节 |
| E3 文字 | 让知识物资流动 | 外部地理 |
| E4 法典 | 扩张与维稳平衡 | 外部规模 |
| E5 印刷术 | 让研究滚雪球 | 外部传播 |
| E6 蒸汽机 | 把煤转成生产力 | 外部能量 |
| **E8 信息（计算机）** | **把自己从微观操作中解放出来** | **玩家自身的注意力** |

> **这是全作唯一一个"以玩家自己为瓶颈"的时代。** 前三代的主题是"征服自然"，E8 的主题是"征服复杂度"。它给出 **E9 星海** 的前提条件（若日后开放）：**只有先学会不亲手操船，才可能指挥一支舰队。**

### 1. 三重依赖链（核心机制）

#### 1.1 链条本身

```
   📊 数据  ◀────────  🖥️ 算力  ◀────────  ⚡ 能源
   （货币）             （引擎）              （地基）
      │                    │                    │
   购买自动化          运行自动化           驱动算力
```

**反向依赖（这才是难点）**：

```
   自动化 ──▶ 提升人力效率 ──▶ 更多发电/建造 ──▶ 更多算力 ──▶ 更多数据
```

**闭环成立，但链条每加一环，断点就多一个。** 玩家的整个 E8 都在这条链上找**当前最细的那一环**。

#### 1.2 四层公式（核心，必须能悬停展开）

```
① 能源层
   E_net = E_gen − E_pop − E_industry
   E_gen  = Σ(火电厂 × 15) + Σ(核电站 × 50)
   E_pop  = 人口 × 0.02
   E_industry = 非计算类工业用电（E6 继承）

② 算力层（供需取小 —— 这是三重链的第一道闸门）
   C_inst = Σ(计算中心 × 该世代单机算力)
   C      = min( C_inst , max(0, E_net) / e )
   e = 单算力功耗（随世代下降，见 11.2）

③ 数据层（算力换数据）
   D/s = C_data × k_d × (1 + 联网加成)
   C_data = 分配给"数据处理"的算力
   k_d = 0.06 数据/秒/算力

④ 自动化层（数据换自动化，算力是硬上限）
   N_run = min( N_owned , floor(C_auto / c_a) )
   C_auto = 分配给"自动化运行"的算力
```

**四层各有各的"断裂表现"**：

| 断在哪 | 现象 | 玩家看到什么 |
|---|---|---|
| 能源层断 | `E_net < 0` → 全文明降速 | 电力条变红，所有产出 ×0.5 |
| 算力层断 | `C < C_inst` → 算力被电力卡住 | "装机 800，可用 320 ← 电力不足" |
| 数据层断 | 算力没分给数据 → 数据停增 | 数据条不动，自动化买不起 |
| 自动化层断 | `C_auto < 需求` → 部分自动化停摆 | **降载级联**（见 1.4） |

#### 1.3 为什么用"取小"而不是"加权"

`C = min(C_inst, E_net / e)` 里的 `min` 是**刻意的非平滑设计**。

如果用电力和算力加权求和，玩家永远感觉不到"缺电"，只会感觉"慢一点"。用 `min`，**缺电时算力直接腰斩**——仪表盘上的数字会**跳变**，玩家立刻知道该建电厂了。

> **设计意图**：三重依赖链的价值在于**让玩家感到脆弱**。平滑曲线会让脆弱感消失。

#### 1.4 降载级联（本代最重要的失败状态）

当 `C_auto` 不足以支撑全部已购自动化时，系统按**玩家设定的优先级**依次暂停自动化：

| 优先级 | 默认 | 说明 |
|---|---|---|
| 1（最高，最后停） | 自动调度 | 停了人力会乱，最危险 |
| 2 | 自动建造 | 停了成长放缓，但不崩 |
| 3（最低，最先停） | 自动研究 | 停了只是慢 |

**玩家可自由拖拽排序** —— 这是 E8 里最重要的一个宏观决策：**断电时，你的文明优先保住什么？**

> ⚠️ **注意级联会自我放大**：停掉「自动调度」→ 人力分配混乱 → 发电岗位缺人 → 电力更低 → 更多自动化停摆。
> 这就是"三重依赖链"最残酷的一次教学。设计上**允许它发生**，并在 UI 上用红色箭头明确画出这个正反馈环。

### 1.5 半导体与集成电路（核心机制 · 算力从稀缺到廉价的真机制）

> *为什么这样设计：原文档把"算力"当成越大越好的线性资源。但信息时代的真机制不是"算力总量"，而是**单位算力成本随时间指数下降**——正是这条曲线让"算力从稀缺变廉价"，从而让自动化得以规模化。这是本代相对前代最本质的差异，必须单列为机制，也是把"半导体"提升为核心科技三件套之一的依据。*

#### 1.5.1 单位算力成本的指数下降

```
单位算力成本(t) = C₀ × 2^(−(t − t₀) / T)

C₀ = 基准单位成本（世代 1 电子管时代）
T  = 成本减半周期（取 18 个月，呼应摩尔定律的"18 个月"表述；⚠️ 见史实锚点争议）
t₀ = 起始世代时间
```

**这是什么意思**：每过约 18 个月，买"同样一份算力"花的钱（与间接占用的能源、硅料）**减半**。不是算力多了 2 倍，而是**同样的代价能买到 2 倍算力**。

**为什么这比"算力越大越好"更准**：
- 若只追求"算力总量"，玩家会陷入"堆更多计算中心"的线性苦工；
- 真实的文明跃迁来自**成本结构崩塌**——当算力便宜到可以忽略，自动化才从"奢侈品"变成"默认配置"。
- 这也解释了为什么本代的瓶颈会从"算力不够"转向"**数据与注意力**不够"（见 §4.3）：算力不再是约束后，新的稀缺才浮出水面。

#### 1.5.2 与算力世代表（§11.2）的对应

| 世代 | 单机算力 | 单算力功耗 e | 隐含"单位算力成本" |
|---|---|---|---|
| 1 电子管 | 20 | 0.50 | 基准（最贵） |
| 2 晶体管 | 60 | 0.20 | ≈ 1/3 |
| 3 集成电路 | 200 | 0.08 | ≈ 1/10 |
| 4 微处理器 | 600 | 0.03 | ≈ 1/30 |

> 功耗 `e` 的逐代下降（Koomey 定律）与单位算力成本的指数下降是**同一枚硬币的两面**：算力便宜，一半是因为芯片集成度（半导体），一半是因为它更省电（能源效率）。**半导体是这条曲线的物理载体。**

#### 1.5.3 设计落点

- 半导体（晶体管 → 集成电路 → 微处理器）是"单位算力成本下降"的**硬件实现**，因此被提升为核心科技三件套之一（与计算机、网络并列）。
- 这条曲线不直接给玩家"更多按钮"，而是**持续压低自动化的门槛**：世代越高，同样的数据/电力能跑更多自动化——这正是 §1 三重依赖链"越成功越脆弱"的反面：成本侧在持续给文明松绑。

### 2. 自动化系统（核心机制 · 本作最重要的体验升级）

#### 2.1 为什么这是 E8 的灵魂

规格书四层循环理论中，**「微观层自动化」是关键节点**：

```
   宏观层（战略）      ← 玩家永远应该待在这一层
        ▲
        │  自动化把玩家往上推
        │
   中观层（规划）
        ▲
        │
   微观层（操作）      ← E1–E6 里玩家 80% 的时间在这里
        ▲
        │
   基础层（资源）
```

**E1–E6 的放置游戏通病**：时代越往后，玩家要点的东西越多，**操作量线性上涨**，最后从"策略游戏"退化成"点击苦力"。

**E8 用自动化把这条曲线掰回来**：不是让你少玩，而是让你**换一层玩**。微观操作交给 AI 助手，你的注意力上移到"自动化之间如何配比、断电时保谁、核电要不要上"。

> **一句话**：E8 不是"更多按钮"，是"更少的按钮，更重的每一个"。

#### 2.2 分阶段解放（三条线 × 三级）

**只能按顺序买**：调度 → 建造 → 研究。这个顺序**不可跳过**，且每级的"解放程度"有质的差别。

##### 线 A · 自动调度（Auto-Assign）—— 先解放"分人"

| 等级 | 数据成本 | 占用算力 | 效果 | 玩家被解放了什么 |
|---|---|---|---|---|
| **Lv1** | 150 | 2 | 自动补足各岗位的人力缺口（保底：不让人力闲置） | 不用再手动点 +1/−1 |
| **Lv2** | 1,200 | 6 | 按**边际收益**最优分配（每 5 秒重算一次） | 不用再算"哪个岗划算" |
| **Lv3** | 9,000 | 18 | **预防性再平衡**：提前 30 秒预测缺口并预调 | 不用再盯变化 |

##### 线 B · 自动建造（Auto-Build）—— 再解放"盖房"

| 等级 | 数据成本 | 占用算力 | 效果 | 玩家被解放了什么 |
|---|---|---|---|---|
| **Lv1** | 600 | 4 | 自动建造**最便宜**的可建建筑 | 不用再逐个点建造 |
| **Lv2** | 4,800 | 12 | 按**收益/成本比**排序建 | 不用再算性价比 |
| **Lv3** | 36,000 | 36 | 自动**预留成本** + 建造队列（可排队 10 项） | 可以离开键盘 |

##### 线 C · 自动研究（Auto-Research）—— 最后解放"想"

| 等级 | 数据成本 | 占用算力 | 效果 | 玩家被解放了什么 |
|---|---|---|---|---|
| **Lv1** | 2,400 | 8 | 自动研究**当前最便宜**的科技 | 不用再点科技 |
| **Lv2** | 19,000 | 24 | 按**时代目标路径**优先（自动偏向门槛科技） | 不用再规划路线 |
| **Lv3** | 150,000 | 72 | **全局最优顺序** + 预测（模拟未来 5 项科技的收益） | 可以只做宏观决定 |

**全三线满级合计**：数据 223,150 / 占用算力 **182**

> **为什么"先分人、再盖房、最后研究"是这个顺序**：
> 分配的决策频率最高（每几秒一次）→ 先自动化收益最大；
> 建造频率中等（每分钟级）→ 其次；
> 研究频率最低（每几分钟一次）→ 最后。
> **按操作频率排序解放，而不是按重要性。** 这是"体验升级"的工程化表达——玩家最先感到轻松。

#### 2.3 自化的三条硬约束（防止它变成"一键通关"）

| 约束 | 机制 | 为什么 |
|---|---|---|
| **算力上限** | 每条线每级都占算力，`N_run ≤ C_auto / c_a` | 自动化不是免费的，它吃掉你本可以用来产数据的算力 |
| **数据货币** | 只能"买"，不能"解锁" | 数据本身要靠算力产，形成正反馈但也形成前期门槛 |
| **不处理危机** | 自动化**不会**应对随机事件（事故、断电、饥荒） | 自动化只做"常规操作"，**危机永远需要人** |

> **第三条最关键**：如果自动化能处理一切，游戏就结束了。设计上明确画一条线——**自动化管常规，玩家管异常**。玩家的注意力从"重复劳动"转移到"例外处理"，这正是 E8 想表达的文明状态。

### 3. 核能（新系统 · 高风险高回报 · 电力承接 E7 电气时代的电网）

#### 3.1 为什么需要核能

> *为什么这样设计：本代的电力**不是从零通电**，而是**承接 E7 电气时代已铺好的电网与火电**（见顶部「刻度：能源：核电 + 电网（承接 E7）」）。本代要做的不是"发明电力"，而是把电网推向更高密度、并用核电替代部分火电——避免与 E7 重复定义"电力起点"。*

算力增长是指数级的，火电是线性的。到中后期：

| 方案 | 支撑 1000 算力所需 | 占地/成本 |
|---|---|---|
| 火电厂（15 电力/秒，单机算力功耗 0.08） | **6 座** | 还烧煤，有污染 |
| 核电站（50 电力/秒） | **2 座** | 但有事故风险 |

到微处理器世代（单算力功耗 0.03），2000 算力需 60 电力/秒：
- 火电：**4 座**
- 核电：**2 座**（还余量）

**核能是唯一能让"算力瓶颈"真正松开的选项。** 这就是它的"高回报"。

#### 3.2 风险机制

```
单座核电站堆芯风险累积速率
  = 0.0015 /秒 × (1 + 废料堆积系数 0–2.0) × (1 − 维护覆盖率 0–1)

维护覆盖率 = 核工程师数 / (核电站数 × 8)，上限 1.0

累积风险 ≥ 1.0 → 触发事故
```

**无维护时**：`1 / 0.0015 ≈ 667 秒 ≈ 11 分钟`必出事 —— 这是刻意的**高压计时器**。
**满维护时**：0.0015 × (1+0) × (1−1) = **0**，安全。

#### 3.3 事故后果（分级）

| 等级 | 触发条件 | 后果 |
|---|---|---|
| **轻微泄漏** | 风险 1.0–1.5 | 该电站停机 120 秒；周边产出 −30% ×300 秒 |
| **堆芯熔毁** | 风险 1.5–2.5 | 该电站**永久损毁**；周边产出 −60% ×600 秒；人口 −5% |
| **灾难** | 风险 ≥ 2.5 | 电站损毁 + 连锁（相邻电站风险 +0.5）+ 该区域 **K 永久 −10%** |

> **核事故的 K 惩罚是永久的** —— 这是本条设计的关键。玩家会**长期**记得那次事故，而不是重建成原样就忘了。文明付出了不可逆的代价。

#### 3.4 废料：延迟的代价

核电站每秒产生 `0.002` 核废料，累积不清则：
- `废料堆积系数 = min(2.0, 废料总量 / 50)` → 直接抬高所有核电站的风险
- 废料还占用周边 K（每 10 废料 → 该区 K −1）

**所以核电不是"建了就完事"**——它要求玩家持续投入（核工程师岗位 + 后处理厂建筑 + 安全壳科技）。**高回报必须用持续的高维护来换。**

#### 3.5 史实锚点

| 事件 | 年代 | 用于设计 |
|---|---|---|
| 芝加哥一号堆 CP-1 首次自持链式反应（费米主持） | **1942-12-02** | 核裂变科技的解锁条件 |
| 三位一体核试验（人类首次核爆） | **1945-07-16** | 核能的"武器化"分支（本作不展开，仅作背景） |
| 奥布宁斯克核电站并网，**装机 5 MW**，世界首座商用核电站 | **1954-06-27** | 核电站建筑的解锁 |
| 三里岛事故 | **1979** | 「三里岛教训」效率科技（事故损失 −30%） |
| 切尔诺贝利事故 | **1986** | 灾难级事故的参考模型 |

> ⚠️ **争议标注**：核电站的事故概率在真实世界中**业界估算分歧极大**（从 1/10⁴ 堆年 到 1/10⁶ 堆年 不等，取决于是否计入设计基准外事件）。
> 本作取 **0.0015/秒（约 11 分钟无维护）** 是**游戏性取值，非史实推演**，目的是制造持续压力。**不要**把它当成对现实核电安全性的判断。

### 4. 联网（与历史演出：发射）（新系统 · 新动词：联网）

#### 4.1 联网（Network）—— 让算力突破单点上限

**史实锚点**：ARPANET 于 **1969** 年首次连接四个节点（UCLA、SRI、UCSB、犹他大学），是**世界上第一个运营的分组交换网络**；万维网由 Tim Berners-Lee 于 **1989 年 3 月**在 CERN 提交提案。

**机制**：网络节点建筑可连接分散的计算中心。

```
联网加成 = 0.15 × √(联网节点数)        节点数 1–16

数据产出   × (1 + 联网加成)
算力上限   = Σ各中心算力 × (1 + 0.5 × 联网加成)
```

| 节点数 | 联网加成 | 数据 | 算力上限 |
|---|---|---|---|
| 0 | 0 | ×1.00 | ×1.00 |
| 1 | 0.15 | ×1.15 | ×1.08 |
| 4 | 0.30 | ×1.30 | ×1.15 |
| 9 | 0.45 | ×1.45 | ×1.23 |
| 16 | 0.60 | ×1.60 | ×1.30 |

**为什么用 √**：网络的价值随节点数增长，但**每新增一个节点的边际价值递减**——因为已连接的节点越多，新增的那条链路带来的"新可达对"占比越小。这是**梅特卡夫定律（n²）的理性衰减版**——真用 n² 会爆炸，√n 保持"联网值得做，但别指望无限叠"。

> **联网的"质"作用**：联网是**跨站点共享算力**的前提。没有联网，每个计算中心的算力只能自己用；有了联网，全文明的算力汇成一个池子 —— 这是自动化能规模化运行的技术前提。

#### 4.2 发射（Launch）—— 历史里程碑（不再作为跃迁出口）

E8 的第三个新动词，原本被设计为"地面时代的终点"；在本版（现代即终局）中，发射链改为**历史成就演出**——它真实发生过，但不再作为跃迁出口。若日后开放 E9 星海，本链可复用作其前置。

| 里程碑 | 成本 | 效果 | 史实锚点 |
|---|---|---|---|
| **1. 发射场建成** | 钢铁 8,000 + 持续 300 电力/秒 ×120 秒 | 解锁发射任务队列 | — |
| **2. 卫星入轨** | 钢铁 2,000 + 占用算力 500 ×300 秒 | 联网节点 +1；解锁「卫星通信」科技 | 斯普特尼克 1 号，**1957-10-04**，拜科努尔，人类首颗入轨人造卫星 |
| **3. 载人航天** | 钢铁 5,000 + 数据 50,000 + 人口 −1 | 触发"文明里程碑"事件；人口管理因子永久 +0.2 | 东方一号，**1961-04-12**，加加林，人类首次载人轨道飞行 |
| **4. 月球着陆** | 钢铁 15,000 + 数据 200,000 + 算力 800 ×600 秒 | 解锁「轨道建造」的研究前置 | 阿波罗 11 号，**1969-07-20** |
| **5. 轨道建造** | 钢铁 20,000 + 数据 500,000 + 算力 1,000 ×600 秒 | **历史里程碑完成（若开放 E9 星海，则为其前置）** | — |

**发射的机制特色**：每次发射都**占用大量算力**（500–1000）持续数百秒。这意味着——

> **发射 = 主动制造一次算力危机。**
> 玩家必须在"继续自动化"和"向上发射"之间取舍：把 1000 算力交给火箭 10 分钟，自动化就得降载。
> **这是 E8 的终局考验（旧口径）：你准备好为了冲出地面，暂时放弃地面的舒适了吗？——本版中它保留为一段可选的历史演出，而非强制出口。**

**斯普特尼克冲击（事件）**：首次成功入轨后，触发一次**全文明事件**——「斯普特尼克时刻」：全科技研究速度 +25%，持续 600 秒（灵感来自 1957 年苏联发射后美国掀起的科研追赶）。⚠️ 事件效果为**游戏设计取值**。

### 4.3 网络与全球化（连接数增长 · 新瓶颈从算力转向数据与注意力）

> *为什么这样设计：原文档只把网络当成"算力池化"的工具（§4.1）。但信息时代的另一半真机制是**连接数的增长**——从 ARPANET 到 WWW 到移动网络，网络把"算力节点"变成"人与信息的节点"。当人人、物物都连上网，瓶颈就从"算力不够"换成了"数据与注意力不够"。这是本代必须补的一块，也是把"网络"列为核心科技三件套之一的依据。*

#### 4.3.1 连接数增长的三次跳变（史实锚点）

| 阶段 | 年代 | 连接对象 | 机制含义 |
|---|---|---|---|
| **ARPANET** | 1969 | 四个研究节点（分组交换网雏形） | 网络从"概念"变成"可运营"——对应 §4.1 的联网节点机制起点 |
| **万维网 WWW** | 1991（Berners-Lee 在 CERN 发布） | 文档 / 站点（信息可被任意检索） | 连接对象从"机器"变成"信息"——数据第一次能**全球流动** |
| **移动网络** | 2007（智能手机普及拐点） | 人人随身在线 | 连接对象从"场所"变成"人"——**注意力**成为被争夺的新稀缺 |

#### 4.3.2 新瓶颈：从"算力不够"到"数据与注意力"

当单位算力成本已指数下降（§1.5）、联网让算力池化（§4.1），**算力本身不再是约束**。文明遇到的是两种新型瓶颈：

| 新瓶颈 | 表现 | 玩家在游戏里看到什么 |
|---|---|---|
| **信息过载** | 数据太多，有效信号被噪声淹没 | 数据条在涨，但"有效指令"产出不变；需要**数据库 / 压缩 / 人机交互**等科技来提纯 |
| **系统性耦合风险** | 万物互联 → 一处故障沿网络瞬间接管全局 | 单点事故通过联网加成**放大**；UI 用红色回环画出"网络耦合导致的级联"（呼应 §1.4 的降载级联，但触发源从"缺电"变成"耦合"） |
| **注意力稀缺** | 玩家能管的宏观决策也有限 | 即便自动化接管常规，异常仍要人处理；移动网络时代"人人在线"反而让**人的注意力**成为最后瓶颈 |

> **这是本代相对前代的根本转向**：E1–E7 的瓶颈是"东西不够"（人/物资/能量/算力）；E8 的瓶颈是"**东西太多、连得太紧**"。文明第一次因为"丰裕"而遇到问题——这正是"现代即终局"的题眼：技术问题的答案，不再是更多技术。

#### 4.3.3 机制落点

- 联网加成（§4.1 的 `0.15 × √节点数`）在**本代**既是"算力池化"也是"连接数增长"的抽象；节点越多，产出越高，但耦合风险也越高——与 §4.3.2 的"系统性耦合风险"对应。
- 新增瓶颈**不设新资源**，而是把已有的"数据"重新解释为"**需提纯的有效信息**"，把"玩家注意力"明确为本代最终约束（呼应 §1 的"玩家自身的注意力"瓶颈）。

### 5. 计算机 — 人口 — 产出 的咬合

```
        💻 计算机（核心 · 自动化引擎）
        │ 提供算力 → 生产数据 → 购买自动化
        │ 自动化 → 解放人力 → 人力转向更高价值岗位
        │ 自动化管理因子 → 人口增长率 r ↑
        ▼
   👥 人口（引擎 · 群体增长，逻辑斯蒂）
        │ 人口 = 人力上限
        │ 人口 = 经验来源
        │ 人口 = 生活用电消耗（新：人口第一次成为"能耗负担"）
        ▼
   ⚡ 电力 / 🔩 钢铁 / 📊 数据（产出）
        │ 电力 → 驱动算力（回到顶层）
        ▼
   🚀 发射场 / 轨道建造（历史出口 / 现代之后扩展位）
```

**闭环（正向）**：
计算机 → 算力 → 数据 → 自动化 → 人力解放 → 更多发电与建设 → 更多算力 → …（指数螺旋）

**闭环（负向，本代特征）**：
自动化↑ → 算力需求↑ → 电力需求↑ → **若发电跟不上 → 降载级联 → 自动化停摆 → 人力混乱 → 发电更少**（死亡螺旋）

> **与前六代最大的区别**：E1–E6 的负反馈来自**自然**（火灭、冬天、资源枯竭），E8 的负反馈来自**玩家自己的成功**。
> **你越成功，链条越长，越容易崩。** 这是"信息自动化型"独有的体验。

**两个特殊项（不计入资源列表，是本代的仪表盘）**：

- **🖥️ 算力（Compute）** —— **容量型数值**，不是流量。它有"装机上限 `C_inst`"和"实际可用 `C`"两个值。**这是 E8 的核心仪表盘，地位等同 E1 的火种。**
- **☢️ 堆芯风险（Core Risk）** —— 0–2.5 的累积值，超过 1.0 触发事故。**第二个仪表盘。**
- **🔌 自动化槽位** —— 已购自动化线的运行状态（运行/降载/停摆）

> **数据 vs 算力的分工（关键设计）**：
> **数据是"花的"，算力是"占的"。**
> 数据一次性花掉买自动化；算力被自动化**持续占用**。
> 所以"买得起"和"跑得动"是两件事 —— **这正是三重依赖链在玩家操作层的体现**。

**公式**（沿用 E1，仅改 r 与 K 的构成）：

```
人口增长速率 = r × P × (1 − P / K) × 食物因子

r = 基础增长率 × 能源因子 × 自动化管理因子      ← 本代新增第二项
K = 基础上限 + Σ城市住宅区容量 + 自动化密度加成 − 核废料区惩罚
```

| 项 | 值 |
|---|---|
| 基础增长率 | **0.004 /秒**（比 E1 低，因基数大） |
| K 基础上限 | 320 |

|---|---|

**自动化管理因子**（本代的核心设计点）

```
自动化管理因子 = 1 + 0.20 × 自动调度等级
                   + 0.10 × 自动建造等级
                   + 0.10 × 自动研究等级
```

| 自动化状态 | 管理因子 | 说明 |
|---|---|---|
| 全无 | **1.00** | 320 人口已接近人工管理极限 |
| 调度 Lv1 | 1.20 | 人力不再闲置 |

| 三线 Lv3 | **2.20** | 文明几乎全自动运转 |

> **为什么自动化影响 r 而不是直接加人口**：自动化不是"多生人"，而是**让管理效率提升** —— 粮食调配、住房分配、公共卫生调度都更精准，于是人口能以更快的速率逼近上限。
> **这是"质变"而非"量变"**：它改的是增长**速率**，不是**上限**。上限仍由 K（住房）决定，玩家必须继续建住宅区。

**曲线示例**（K = 520，能源充裕，三线 Lv3 → r = 0.004 × 1.0 × 2.20 = 0.0088）

| 人口 P | 增长速率 | 阶段 |
|---|---|---|
| 320 | 0.56 /秒 | 起步 |
| 520 | 0.00 /秒 | 到顶 |

> 到顶了怎么办？→ **建城市住宅区抬高 K**。这与 E1 完全同构，玩家一看就懂。

#### 11.8 终局条件（现代即收束，不再跃迁）

> *为什么这样设计：原文档此处是"→ E8 星海"的跃迁条件。本版 E8 是到现代为止的最后一代，没有下一代入口，因此改为**终局条件**——文明在此达到"现代稳态"即收束。铁律②"跃迁只新增不重置"在此转化为：本代机制全部保留，不进入新代，而是作为现代文明的完成态。*

```
✓ 科技：研究「计算机 / 半导体 / 网络」全系核心与支撑科技（自动化框架成型）
✓ 自动化覆盖率：三线（调度 / 建造 / 研究）均达 Lv3，且自动化运行占比 ≥ 90%
   （证明文明已能"不亲手操作"地平稳运转 —— 呼应本代核心矛盾）
✓ 数据量级：累计数据 ≥ 1,000,000（算力廉价化后，数据已成为丰裕但需提纯的资源）
✓ 网络连接数：联网节点 ≥ 16（万物互联的规模化临界点，见 §4.1 / §4.3）
✓ 算力可用：可用算力 ≥ 1,000（证明系统能自主运转，不依赖人）
✓ 系统稳定性：在"降载级联 / 核事故"压力测试下，连续维持稳定一段周期（证明丰裕下的耦合风险可控）
```

**六项全部满足**后，本代进入「**现代终局**」状态：文明以"高度自动化 + 全球互联 + 算力廉价"的完成态收束。

> **为什么设这些终局条件而非"离开地面"**：现代即终局。衡量一个文明是否"进入现代"，不再是它能不能上天，而是它能不能**在地面把管理彻底交给系统**、并承受住"丰裕带来的新瓶颈"（数据与注意力，见 §4.3）。
> 原"算力 ≥1,000"这一条保留为终局条件之一——它本来衡量的就是"文明能自主运转"，叙事与机制统一，只是不再指向"指挥舰队"，而是指向"现代稳态"。

| **星海（离开地面）** | 发射链（卫星 / 载人 / 月球 / 轨道建造，§4.2）、核聚变研究（§9 航天与生物线） | 钩子保留，不实现；若开放则顺延为 **E9** |
| **生物科技** | DNA 双螺旋（1953，§9 航天与生物线） | 钩子保留，不实现 |
| **人工智能** | 人工智能（达特茅斯 1956，§9 自动化线）、自动化框架 | 钩子保留，不实现；AI 在本版是"自动化"的延伸，非独立代 |

> **明确边界**：本版 **不实现** 上述任何方向。E8 的终局就是"现代完成态"，不是"通往下一代入口"。这避免了与原文档"指向星海"的口径冲突，也避免了与并行开发的 E3–E6 骨架重复定义后续代。

---

### 12. 节奏曲线（不设时长目标）

> **设计原则**：本代要玩多久由终局条件与自动化上线的节奏自然决定，**不做人工时长规划**（铁律⑤：不设时长目标）。下表按**体验阶段**给出节奏参考，而非小时级时间线。

| 阶段 | 玩家在做什么 | 人口 | 算力 | 自动化状态 |
|---|---|---|---|---|
| **纯手工期** | 派数据录入员攒数据；研究图灵机 → 存储程序架构 | 320 → 340 | 0 | 无 |
| **第一次交出操作** | 建首座计算中心；买**自动调度 Lv1** —— 第一次交出微观操作 | 340 → 400 | 20 → 40 | 调度 Lv1 |
| **晶体管化** | 晶体管化；建冷却塔；买**自动建造 Lv1** —— 建筑开始自动排队 | 400 → 480 | 60 → 130 | 调度 Lv1 + 建造 Lv1 |
| **三线齐备** | 集成电路；联网（4 节点）；买**自动研究 Lv1** —— 三条线齐了 | 480 → 560 | 200 → 420 | 三条 Lv1 |
| **核电上线** | 核裂变 → **首座核电站**；派核工程师；**第一次堆芯风险警报** | 560 → 650 | 420 → 800 | 三条 Lv2 |
| **规模化 + 降载级联** | 微处理器；核电规模化；三条 Lv3；**第一次降载级联**（玩家手动保优先级） | 650 → 780 | 800 → 1,600 | 三条 Lv3 |
| **终局：现代完成态** | 发射链作为历史演出（卫星 / 载人 / 月球 / 轨道建造）；发射占用算力导致自动化临时降载；终局条件（§11.8）逐项达成 | 780 → 900 | 1,600 → 1,000（被发射占用） | 全自动（发射期降载） |

**体验曲线设计**：

| 设计事件 | 目的 |
|---|---|
| **纯手工录入数据**，慢得令人焦躁 | **制造"我需要机器"的渴望** —— 没有这段，自动化不会有快感 |
| **第一次自动化**（自动调度 Lv1） | **全作最强的正反馈时刻** |
| 自动建造上线 | 玩家开始敢于离开键盘 |
| 自动研究上线 | 三条线齐备 —— **"我终于可以只做宏观决策了"** |
| 核电站 + 第一声风险警报 | **引入新的恐惧**：自动化带来的能源，本身是危险的 |
| **降载级联** | **本代的核心危机体验**：三重链断裂的完整演示 |
| 发射占用算力，自动化被迫降载 | **历史演出取舍**：冲出地面是人类的高光时刻，但本版它不再是指向新代的出口 |
| 轨道建造完成 | 历史里程碑达成（旧口径的"出口"已关闭，现代即终局） |

> **关键节奏设计**：E8 的**纯手工期故意做得很难受**（慢、重复、无聊）。
> 这不是设计缺陷，而是**必要的铺垫** —— 玩家必须先体验"没有自动化的痛苦"，才会在买到第一级的瞬间产生**真正的解脱感**。
> 这也让 E8 与 E6 的"优化能量效率"在**手感上**彻底区分开：E6 是"算得更多"，E8 是"终于不用算了"。

### 13. UI 要点

| 元素 | 设计 |
|---|---|
| **🔗 三重依赖链环图** | 顶部三环并列（数据 / 算力 / 能源），**任一环断裂时该环变红并震动**；链条线在断点处显示断裂图标 |
| **⚡ 算力仪表盘** | 大号显示 `可用算力 182 / 装机 420`，**缺电时数字跳变**（不是平滑过渡）—— 制造"被掐住"的体感 |
| **🔌 电力平衡条** | 双向条：`发电 45 ←→ 消耗 62`，赤字时右侧溢出变红并闪烁 |
| **🤖 自动化面板** | 三条线 × 三级，**已运行/已降载/未拥有** 三态配色；每条线显示"占用算力 X" |
| **⬇️ 降载优先级** | **可拖拽排序**的三个卡片（调度/建造/研究）；玩家可用鼠标直接调序，改动即时生效 |
| **☢️ 堆芯风险条** | 每座核电站独立显示 0–2.5 的风险条；>1.0 变红并播放警报音；>1.5 闪烁 |
| **⚠️ 级联警告** | 当降载级联触发时，**画出一条红色正反馈回环**并高亮显示链条：`停电 → 算力↓ → 自动化停 → 发电岗缺人 → 停电` |
| **📊 数据流面板** | 显示 `数据 +12.5/秒（人工 0.0 + 算力 12.5）` —— **明确区分两个来源**，让玩家看到人工录入被淘汰的过程 |
| **❓ 悬停解释** | 每个数字都可悬停：*"可用算力 182：装机 420，受电力限制（可用电力 14.6 ÷ 单算力功耗 0.08 = 182）"* —— 落实"所有数字可解释"铁律 |
| **🎯 终局进度环** | 底部常驻"现代终局"进度：显示 §11.8 六项终局条件的完成度 |

**三个层次的视觉注意力分配**（关键）：

```
上方 1/4 屏幕  →  三重依赖链环图（宏观状态，一眼看全局）
中部 1/2 屏幕  →  自动化面板 + 降载优先级（玩家真正操作的地方）
下方 1/4 屏幕  →  发射（历史演出）/ 现代终局进度（长期目标）
```

> **E1–E6 的 UI 是"一堆岗位 + 一堆建筑"，玩家要在几十个按钮里找。**
> **E8 的 UI 应该只有三个自动化卡片在中间。** 因为到了这个时代，**文明已经大到一个屏幕装不下了** —— UI 本身也必须"被自动化"。

### 14. 终局：现代之后

> *为什么这样设计（终局口径）：原文档这一节是"与 E8（星海）的衔接"，把本代当成"离开地面的跳板"。本版 E8 是到现代为止的最后一代——**现代即终局**，不再有下一代入口。因此本节改为"现代之后"：明确本代收束为何，并把星海 / 生物·智能 列为**仅留扩展位、不实现**的方向（顺延为 E9）。铁律②"跃迁只新增不重置"在此兑现为：本代机制全部保留、不进入新代，文明以"现代完成态"收口。*

#### 14.1 本代如何收束（现代完成态）

| 维度 | 现代终局时的状态 |
|---|---|
| **自动化** | 三线满级、覆盖率 ≥90%，文明日常运转**不再需要人亲手操作**（呼应 §1 核心矛盾的解除） |
| **算力** | 单位算力成本已指数下降（§1.5），算力廉价到"默认配置"；可用算力 ≥1,000 |
| **网络** | 联网节点 ≥16，万物互联规模化（§4.1 / §4.3）；新瓶颈转为**数据与注意力** |
| **电力** | 承接 E7 的电网 + 本代核电化，能源不再是人类文明的主约束 |
| **核能风险** | 由持续维护（核工程师 / 后处理 / 安全壳）压住，作为现代基线的"可控代价" |
| **人口 / 数据** | 逻辑斯蒂增长 + 数据丰裕；数据成为需提纯的有效信息，而非稀缺资源 |

#### 14.2 后续扩展位（本版不实现，仅留钩子 · 顺延为 E9）

| 方向 | 本版已埋的钩子 | 状态 |
|---|---|---|
| **星海（离开地面）** | 发射链（卫星 / 载人 / 月球 / 轨道建造，§4.2）、核聚变研究（§9 航天与生物线） | 钩子保留；若开放则顺延为 **E9**，发射链复用作其前置 |
| **生物科技** | DNA 双螺旋（1953，§9 航天与生物线） | 钩子保留，不实现 |
| **人工智能** | 人工智能（达特茅斯 1956，§9 自动化线）、自动化框架 | 钩子保留，不实现；本版 AI 是"自动化"的延伸，不构成独立代 |

#### 14.3 收束提示文案（替代原"跃迁弹窗"）

> **现代终局弹窗**：
> *"地面时代，到这里就足够了。*
> *你不再需要亲手分配任何一个人力——那些在二十世纪被写下的自动化规则，已经接管了文明的日常。*
> *电力不再是你的枷锁，核裂变不再是你的赌注，网络把世界连成了一张安静的网。*
> *文明第一次，不需要人也能够平稳运转。*
> ***这不是结束，而是现代完成态——星海、生命、智能，留给后来者去开。***"

#### 14.4 一条明确留给 E9 的钩子

E8 中**「核聚变研究」是一项"永远不会完成"的科技**：

- 它可以被研究，但研究完成后**没有任何即时效果**
- 描述文字只有一行：*"理论上可行。需要的能量，这颗行星给不了。"*
- 若日后开放 **E9 星海**，它自动转化为**聚变反应堆**的前置

> **设计意图**：让玩家在 E8 结束时**已经知道"下一把钥匙"长什么样**，但**够不到**——既保留"门槛科技 = 下代核心科技"的情感钩子，又不破坏"现代即终局、本版不实现"的口径。
