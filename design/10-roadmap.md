# 10 · 开发路线图

## 1. 总体里程碑

```
W1-W2:  基础架构 + 核心系统
W3-W4:  核心玩法（资源 + 科技）
W5-W6:  扩展系统（政府 + 事件）
W7-W8:  重置 + 成就 + 打磨
W9-W10: 测试 + 部署 + 发布
```

**目标**：10 周 MVP，20 周 v1.0

## 2. 周计划

### W1：项目初始化

**目标**：搭建开发环境，完成项目骨架

**任务**：
- [ ] 初始化 Vite + React + TypeScript 项目
- [ ] 配置 Tailwind CSS
- [ ] 配置 ESLint + Prettier
- [ ] 配置 Vitest 测试框架
- [ ] 配置 Git 仓库 + .gitignore
- [ ] 搭建目录结构（core / game / state / ui / data）

- [ ] 部署到 Vercel（空项目）

## 4. 风险清单

| 风险 | 影响 | 概率 | 缓解措施 |
|---|---|---|---|
| 数值爆炸 | 后期游戏无法玩 | 高 | 从 W3 开始用 sqrt 递减 |
| 存档破坏 | 玩家数据丢失 | 中 | 从 W2 开始做版本迁移 |
| 内容密度过高 | 玩家困惑 | 中 | 4 阶段解锁，不一次性开放 |
| 性能瓶颈 | 后期卡顿 | 中 | W1 就规划代码分割 + 虚拟化 |
| 平衡性差 | 玩法失衡 | 高 | 每周做一次平衡性测试 |
| 本地化延期 | 国际玩家无法用 | 中 | MVP 先做中英文 |
| 存档体积爆炸 | 无法存档 | 低 | 监控存档大小，定期清理 |
| 浏览器兼容 | 某些浏览器打不开 | 低 | 测试 Chrome/Firefox/Safari |
| 移动端体验差 | 移动玩家流失 | 中 | W8 专门做移动端适配 |
| 开发者倦怠 | 项目延期 | 中 | 10 周 MVP，先做核心 |

## 5. 关键决策点

### 决策 1：技术栈（W1 前决定）

- **React 18 + Zustand**（推荐）
- Vue 3 + Pinia
- 纯原生 JS（不建议）

### 决策 2：内容范围（W2 前决定）

- **MVP**：5 大系统（资源/科技/政府/事件/重置）
- **完整版**：10 大系统（+ 太空/基因/城建/成就/多宇宙）

### 决策 3：发布时间（W8 前决定）

- **MVP 发布**：10 周（推荐，快速反馈）
- **v1.0 发布**：20 周（完整内容）
