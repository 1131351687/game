# 01 · 项目概述

## 1. 项目定位

**游戏名**：待定（候选：*Genesis* / *Origins* / *Ascension* / *Terra*）
**类型**：放置 + 文明进化（Incremental / Idle + Civilization Evolution）
**平台**：纯前端 Web（移动端 + 桌面端响应式）
**单玩家**：本地存档，无需账号系统
**参考**：Cookie Clicker（核心循环）+ Anomaly Game（数值与重置设计）

## 2. 核心体验目标

1. **前 10 分钟**：玩家理解"点击 → 资源 → 岗位 → 自动产出"的核心循环，并能主动点击和分配。
2. **1 小时内**：玩家完成第一次"文明升级"（重置），获得永久加成，开始追求第二条线。
3. **8 小时以上**：玩家解锁太空探索、政府治理、多宇宙等多级系统，进入长线深度。
4. **长线（>20 小时）**：玩家完成所有成就、通关所有重置线、进入"沙盒模式"自由调整参数。

## 3. 关键设计取舍

| 维度 | 常见做法 | 本项目方案 |
|---|---|---|
| 技术栈 | jQuery + Vue 2 时代的老架构 | React 18 / Vue 3 + TypeScript + Vite |
| 状态管理 | 单一可变 `global` 对象 + 手动重绘 | Zustand/Pinia 响应式 + 派生量缓存 |
| 打包 | 单文件 bundle，首屏全量加载 | Vite 多 chunk + 按 Tab 代码分割 |
| 存档 | localStorage + LZ-String（上限 5MB、同步阻塞） | IndexedDB（Dexie.js）+ 版本号迁移 |
| 时钟 | 主线程 `setTimeout`，后台标签页被节流、易漂移 | Worker + 三级循环 250ms / 1s / 5s |
| 随机 | `Math.random()`，不可复现 | 种子 LCG，可复现 |
| 消息过滤 | 消息无差别输出，噪音大 | 6-8 类 filter 分级 |
| 重置 | 单层重置，长线缺乏层次 | 3-4 级重置 |
| 本地化 | 文案硬编码，多语言需改代码 | JSON 覆盖 + string pack |
| 内容线 | 10+ 条并行，过密 | 精简为 4 阶段解锁 |
| 性能 | 50 资源 / 100 科技即接近瓶颈 | 目标 200 资源 / 500 科技不卡 |
| 移动端 | 弱响应式，桌面优先 | 强响应式，触屏优先 |

## 4. 不做什么（明确边界）

- ❌ 不做多人在线 / 排行榜
- ❌ 不做账号系统（纯本地）
- ❌ 不做付费 / 内购（开源、广告支持可选）
- ❌ 不做复杂 PVP 战斗（战争改为自动化资源战）
- ❌ 不做 3D / 引擎（纯 2D + DOM）
- ❌ 不做服务端校验（信任客户端，纯娱乐）

## 5. 成功标准

### 必须达成（MVP）
- [ ] 三级循环时钟稳定运行，无漂移
- [ ] 资源 / 岗位 / 科技 / 政府 / 太空 5 大系统可玩
- [ ] 3 级重置系统
- [ ] 存档 / 读档 / 离线收益 / 存档迁移
- [ ] 中英文本地化
- [ ] 移动端 + 桌面端可玩
- [ ] Lighthouse 性能分 ≥ 90

### 加分项（v1.0 后）
- [ ] 20+ 种随机事件
- [ ] 50+ 个成就
- [ ] 8+ 种语言
- [ ] 自定义主题
- [ ] 沙盒模式（编辑器）

## 6. 关键设计决策（已锁定）

1. **技术栈**：React 18 + TypeScript + Zustand + Tailwind + IndexedDB（详见 02）
2. **架构**：四层分层（core / game / state / ui / data），详见 03
3. **时钟**：Worker + 三级循环（250ms / 1s / 5s），详见 04
4. **存档**：IndexedDB + 版本号迁移，详见 04
5. **随机**：LCG 种子随机，可复现，详见 04
6. **重置**：3 级（资源 / 科技 / 文明），详见 05
7. **内容**：4 阶段解锁，详见 07

## 7. 风险预警

详见 10-roadmap.md 的"风险清单"部分。

**Top 3 风险**：
1. **数值爆炸**：放置游戏最大杀手，必须从第一版就引入平方根衰减
2. **存档破坏**：版本迁移设计不当会逼玩家删档，从第一天就做
3. **内容密度**：并行内容线开太多（10+ 条）会稀释每个阶段的焦点，是明确的负面教训，本项目必须阶段化
