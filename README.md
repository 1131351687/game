# 文明演进 · Civilis

一个纯前端、放置（idle / incremental）+ 文明进化类游戏的可运行 demo，附带一套完整的架构设计方案。

从原始生命起步，经由资源积累、岗位分工、科技突破、政体演进，一路走向长线重置成长。

## 已实现（demo）

- **Worker 低漂移时钟**：把定时器放进 Web Worker，避免浏览器后台标签页节流导致时钟漂移
- **三级循环**：`fastLoop` 250ms（资源累积）/ `midLoop` 1s / `longLoop` 5s（= 1 游戏日）
- **5 种资源**：食物 / 木材 / 石头 / 人力 / 研究
- **4 种岗位**：农夫 / 伐木工 / 矿工 / 科学家，产出用 `sqrt` 递减（防数值爆炸）
- **科技系统**：研究点消耗 + 全局加成
- **政府系统**：3 种政体，影响经济 / 科研 / 军事
- **重置系统**：`floor(sqrt(累计食物 / 1e6))` 计算重置点，每点 +5% 全局产出
- **消息日志**：支持「全部 / 重要」过滤
- **存档**：localStorage（自动存档 + 读档）

## 技术栈

| 层面 | 选择 | 理由 |
|---|---|---|
| 语言 | TypeScript（strict） | 数据表同构对象多，类型系统收益大 |
| 构建 | Vite 5 | 极速 HMR + 按需代码分割 |
| UI | React 18 | 组件化，避免字符串拼 HTML |
| 状态 | Zustand 4 | 极简 API，selector 订阅，高频更新友好 |
| 样式 | Tailwind CSS 3 | 原子类 + CSS 变量支持主题切换 |
| 时钟 | Web Worker + 三级循环 | 避开浏览器定时器节流与漂移 |

## 核心设计决策

1. **四层分层**：`core`（基础设施）/ `game`（玩法）/ `state`（状态）/ `ui`（视图），层间单向依赖，玩法层不碰 DOM
2. **响应式单一状态源**：状态变更自动驱动 UI，不手动触发重绘
3. **Worker 时钟**：80 样本抖动补偿，抵消 `setTimeout` 累积漂移；主线程只负责逻辑
4. **三级循环**：快 / 中 / 慢三档频率解耦，切后台回来可 catch-up
5. **sqrt 递减产出**：`sqrt(数量) × 基础速率`，防止后期数值失控
6. **种子随机**：线性同余伪随机，同一存档随机结果可复现
7. **存档版本迁移**：`version` 字段 + migration 链，从第一天就做，避免后期逼玩家删档
8. **阶段化解锁**：4 阶段（原始 → 文明 → 星际 → 终局），控制内容密度与上手难度
9. **消息过滤器**：分类过滤，避免日志爆炸淹没关键信息
